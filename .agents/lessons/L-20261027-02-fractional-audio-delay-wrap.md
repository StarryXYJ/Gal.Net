# 分数延迟的浮点环绕边界

状态：confirmed。来源：F-20261027-01-audio-mixer，PcmMixerTests 的混响顺序和稳态处理用例。

现象：部分 roomSize（包括默认 0.5）在混响延迟读取中出现 IndexOutOfRangeException，而另一组房间参数正常。

根因：float 计算得到接近 0 的负读位置，加缓冲长度后可能舍入成恰好等于缓冲长度；只检查负数不能保证数组索引落在区间内。

正确做法：分数位置用 double 计算，环绕后仍检查上边界；线性插值的第二个索引同样按长度环绕。不要在 native 音频回调外层吞异常后把持续静音误判为正常输出。

验证：真实混响默认参数、非默认参数、有序效果和连续处理/零分配测试均覆盖该路径。记录来自测试失败后修正，不把“只跑一个 impulse 参数”当成完整边界验证。
