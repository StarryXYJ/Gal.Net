# 局部集合删除也要重算全局位置快照

状态：confirmed
日期：2026-10-17
来源：F-20261015-02-editor-authoring-workspace / P3

现象：分支按稳定选项 ID 重排后，删除一个在全局边列表中间的选项，再 Undo，会被 BranchEdit 的预期状态校验拒绝；删除末项的测试却通过。

根因：分支编辑保留局部出边及其全局插入索引。删除一条边后，其后的全局索引前移，而预先生成的 After 快照仍保存旧索引，导致实际状态与历史预期不一致。稳定对象 ID 不能替代集合顺序快照的一致性。

正确做法：生成 After 时，每条保留边的全局位置减去在其前面删除的边数；Undo 使用 Before 中的原始全局位置恢复，其他节点的边保持原顺序。预期校验必须在所有写操作之前完成。

验证：p3-middle-edge-regression.trx 的 Choice/Condition 两用例稳定失败；修正后 p3-middle-edge-fixed.trx 的两种分支与真实控件用例共 3 项通过。用例从三个出口中删除原第二条边，再撤销两步并比较完整作者快照，不只比较局部连线目标。

适用范围：跨多个集合的局部增删、索引重映射、批量历史和投影同步。不能只测试尾部删除，也不能通过放宽状态校验掩盖错误索引。
