# 入队检查不能代替历史执行时的检查

状态：confirmed
日期：2026-10-21
来源：F-20261019-01-editor-game-localization / P5

异步历史通过 gate 串行执行，服务在调用 ExecuteAsync 前验证源值/预览仍可能过期：排在前面的语言切换或文本编辑会先改变状态。两个交错测试用 CallbackEdit 持有 gate，分别先排开发语言切换和先排译文修改；旧实现两个用例均未拒绝过期操作。

单元格在历史 RedoAsync 真正执行前检查开发语言、分类引用和原文基线，然后交给数据操作核对文件期望值。开发语言预览也在语言 edit 的 Redo 时重新验证证据。Undo 复原原值，Redo 重新核对提交前置条件；guard 只持有项目服务及数据，不持有控件。

修正后 i18n 定向 16 项通过，两个交错用例分别验证旧草稿不覆盖和旧预览不切换语言。不能只测试顺序 await 的正常路径，也不能靠忙碌 UI 按钮推断底层服务不会排队。关联：features/F-20261019-01-editor-game-localization/phase-5.md。
