# GalNet Skill Index

项目 skill 的可版本化源文件位于 `G:\program\GalDotNet\.agents\skills\`。当前推荐的 feature 工作流不是硬性门禁，skill 可以独立调用。

## Feature

- `galnet-feature-create`：新建 feature 并澄清需求。
- `galnet-feature-design`：形成设计文档。
- `galnet-feature-phase-plan`：拆分可验证的 Phase。
- `galnet-feature-implement`：按 Phase 实现并记录验证。
- `galnet-feature-review`：审核 diff、需求、设计、测试和文档。
- `galnet-feature-closeout`：总结、同步文档和沉淀经验。

## Agent 知识

- `galnet-agent-context`：读取和维护长期 agent 上下文。
- `galnet-capture-lesson`：开发过程中即时记录踩坑。
- `galnet-promote-lesson`：把可复用经验晋升为独立 skill。
- `galnet-sync-skills`：把仓库 skill 源文件同步到当前 Codex 的用户级发现目录。
- `galnet-sync-docs`：把已验证事实同步到给开发者看的正式文档。

## 晋升的项目经验

暂无。新增 skill 应在这里登记触发条件、状态和来源 lesson；被 supersede 的 skill 不应继续作为当前规则使用。
