# 剧情、分支、变量与角色

项目只有一张主 Graph；Group 保存线性条目，分支节点表达玩家选择或条件转移。章节可以在同一图入口按变量选择，不需要为每章再建一张主图。

## 编辑流程

1. 在 Graph 添加 Group 和分支，连接入口及后续路径；使用节点搜索、适配全图与定位选择整理流程。
2. 打开 Group，用添加/追加按钮选择条目类型，可按名称搜索和批量插入。
3. 行内编辑常用字段，选择条目后在 Inspector 编辑完整参数与执行条件；Timeline 专属内容在对应面板编辑。
4. 在变量面板分别管理 save/player 声明，在角色面板管理角色及姓名。点击应用后声明才进入工作版，Save All 保存已应用内容。
5. 检查当前内容，通过 Problems 或引用列表定位实际条目；不要仅凭显示行号猜测稳定身份。

`save` 变量随存档恢复，`player` 变量用于跨存档的玩家状态。条件依赖项目声明和运行值；角色姓名属于本地化文本，不应把显示姓名作为角色唯一身份。

多选复制会按内容语义处理内部身份与引用。跨 Group/节点操作后重新检查资源、角色、变量与场景目标；未知自定义语义可能使静态分析不完整。无错误但“不完整”不等于所有运行路径都已证明有效。

参数草稿、Save All 和角色/变量应用的区别见[工作区](projects-and-workspace.md)。精确行为见 [Graph](../../spec/editor/graph.md)、[Group](../../spec/editor/groups.md)、[变量](../../spec/editor/variables.md)和[本地化规范](../../spec/editor/localization.md)。
