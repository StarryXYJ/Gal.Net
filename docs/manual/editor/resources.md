# 导入与管理资源

在资源面板导入图片、音频、视频、字体或项目支持的其他类型。资源由稳定 ID 引用；文件路径用于组织与查找，不代替运行时资源身份。

## 常用操作

- 工具栏提供导入、新建、类型筛选和列表视图；搜索覆盖整个项目。
- 选择资源后在 Inspector 修改属性，下方展开预览；资源 ID 与路径可以选中复制。
- 剧情参数使用资源选择器选择对应类型，先导入资源再填写引用。
- 移动、复制和删除优先使用 Editor 支持的项目操作，并检查引用与 Problems；不要只移动文件而遗失 `.meta` 身份。

图片差分按[图集手册](image-variants.md)配置；演出 shader 与默认用途绑定见[默认视觉库](default-visuals.md)。音频预览需要可用的原生媒体后端；能导入资源并不等于目标设备能解码它。

导出按实际依赖收集资源；自定义结构中的隐式引用未必可静态分析，需显式声明依赖。详细限制见[内容打包](content-packaging.md)。作者目录、运行资源租约与 PAK 格式分别见[文件操作](../../spec/editor/project-and-files.md)和[资源规范](../../spec/content/assets.md)。
