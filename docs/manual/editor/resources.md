# 导入与管理资源

在资源面板导入图片、音频、视频、字体或项目支持的其他类型。资源由稳定 ID 引用；文件路径用于组织与查找，不代替运行时资源身份。

## 常用操作

- 工具栏提供导入、新建、类型筛选和列表视图；搜索覆盖整个项目。
- 选择资源后在 Inspector 修改属性，下方展开预览；资源 ID 与路径可以选中复制。
- `Assets/` 保存项目资源，`Buildin/` 保存可查看、编辑和复制的内置资源。固定内置资源及其父目录不能在编辑器内删除、移动或改名。
- 剧情参数使用资源选择器选择对应类型，先导入资源再填写引用。
- 移动、复制和删除优先使用 Editor 支持的项目操作，并检查引用与 Problems；不要只移动文件而遗失 `.meta` 身份。

图片差分按[图集手册](image-variants.md)配置；演出 shader 与预设默认资源见[默认视觉库](default-visuals.md)。音频预览需要可用的原生媒体后端；能导入资源并不等于目标设备能解码它。

导出按实际依赖收集资源；自定义结构中的隐式引用未必可静态分析，需显式声明依赖。详细限制见[内容打包](content-packaging.md)。作者目录、运行资源租约与 PAK 格式分别见[文件操作](../../spec/editor/project-and-files.md)和[资源规范](../../spec/content/assets.md)。

## 资源名称与鉴赏

所有资源均可在 Inspector 填写可选的“资源名称（开发语言）”和“鉴赏解锁 ID”。名称输入实际文本，编辑器内部生成稳定 key；i18n 页“资源名称”子面板集中编辑各语言，并可定位原资源。Graph 中选中 Group 后也可在 Inspector 编辑相同字段，并选择可选场景封面。普通节点显示名称与玩家看到的资源名称分别保存。

ID 留空不加入鉴赏，填写时须为全局唯一正整数，同时用于排序。修改现有 ID 会影响已有玩家解锁记录。未被目标应用实现的类型保留这些字段，但不显示在鉴赏中；名称可以被其他功能独立使用。清空名称或 ID 不自动删除已保存的翻译。名称、metadata 和翻译修改使用项目历史与保存边界。
