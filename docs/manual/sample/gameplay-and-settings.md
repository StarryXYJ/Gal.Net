# 游戏操作与玩家设置

默认玩家提供标题页、游戏页、设置、存读档和 Gallery。可用按钮随主题、项目内容及输入配置变化，开发版另有调试工具；自定义项目可以替换这些页面。

## 基本流程

首次启动选择可用语言，进入标题页后开始新游戏或读取已有存档。文本显示中继续推进会按实例规则补全文字/跳过当前批次，再继续剧情；等待选项时需要选择对应分支。

自动、快进和继续都通过同一运行机制协调，不能用界面看似停止推导 Engine 已终止。读档和重新开始会替换运行，离开游戏或退出应沿宿主关闭链正常结束。

输入绑定来自当前项目/玩家设置；键盘、鼠标、触控与手柄的可用范围不同。手柄还有设备、焦点和原生部署前提，见[平台支持](platform-support.md)，不要假定所有平台都具备相同按键。

## 设置

设置页由宿主的设置服务提供分类、编辑器和持久化。默认包含文本速度、播放行为、音量与静音等；读过文本的颜色标记可按玩家偏好启用。音量设置独立叠加于剧情 Track/Bus 混音。

窗口状态和显示恢复属于桌面适配；移动端不能沿用桌面窗口配置。退出确认或未保存提示出现时，完成确认后再验证应用正常结束。

存档、已读和历史说明见[存档与 Gallery](saves-history-and-gallery.md)；自己添加设置或变量见[设置扩展](../extensions/settings-and-variables.md)。
