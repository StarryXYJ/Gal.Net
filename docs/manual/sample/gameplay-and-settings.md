# 游戏操作与玩家设置

默认玩家提供标题页、游戏页、设置、存读档和 Gallery。可用按钮由项目页面、内容及输入配置决定，开发版另有调试工具；自定义项目可以直接编辑这些页面。

## 基本流程

首次启动选择可用语言，进入标题页后开始新游戏或读取已有存档。文本显示中继续推进会按实例规则补全文字/跳过当前批次，再继续剧情；等待选项时需要选择对应分支。

自动、快进和继续都通过同一运行机制协调，不能用界面看似停止推导 Engine 已终止。读档和重新开始会替换运行，离开游戏或退出应沿宿主关闭链正常结束。

输入绑定来自当前项目/玩家设置；键盘、鼠标、触控与手柄的可用范围不同。手柄还有设备、焦点和原生部署前提，见[平台支持](platform-support.md)，不要假定所有平台都具备相同按键。

## 截图

桌面截图可预览、选择保存目录与文件名，并决定是否包含对话框和操作栏。安卓 CrossPlatform Sample 不显示目录和文件名，自动命名并保存到系统相册的 `Pictures/<游戏名>`；弹窗根据屏幕调整预览大小，正式 PNG 不使用预览分辨率。保存失败会留在弹窗中，可重试或取消。Android 6–9 的旧式权限分支与 iOS 相册输出尚未完成设备验收。

## 设置

设置页由宿主的设置服务提供分类、编辑器和持久化。默认包含文本速度、播放行为、音量与静音等；读过文本的颜色标记可按玩家偏好启用。音量设置独立叠加于剧情 Track/Bus 混音。

“字号”提供小、较小、较大、大四档，同时调整标题、正文、角色名及操作/辅助文字的字号层级。首次使用时桌面默认较小、Android/iOS 默认较大；手动选择后保存到当前项目的玩家偏好，下次启动恢复。切换字号不重新播放当前对白。Logo 和开场公告演出使用独立排版。较大档可能改变长文本换行，移动端点击区域与页面响应式布局独立于字号档位，不随字号整体缩放。

## 移动端布局

Android/iOS 的普通页面按可用空间排版：设置较窄时标签移到控件上方，存档和鉴赏按宽度减列，标题菜单和长页面可滚动。调整布局保留当前设置值和正在录入的输入绑定。桌面窗口仍使用原设计布局，不因缩小窗口切换成手机界面。

游戏场景、立绘和对白等保留固定画布。底部操作条按屏幕实际大小提供触摸区域，居中且优先留在场景范围内，必要时使用黑边。完整操作放不下时保留快进、自动、历史和“更多”；更窄时历史也放入“更多”，存读档、设置、截图、隐藏 UI、返回标题等入口仍保留。返回先关闭已打开的菜单，切页也会关闭菜单。

场景截图和存档预览保持原尺寸；移动端勾选“包含界面”的正式截图使用当前内容视口尺寸，包含黑边和独立操作条。完整竖屏阅读构图与真机安全区/手指操作效果仍需单独验收。

窗口状态和显示恢复属于桌面适配；移动端不能沿用桌面窗口配置。退出确认或未保存提示出现时，完成确认后再验证应用正常结束。

存档、已读和历史说明见[存档与 Gallery](saves-history-and-gallery.md)；自己添加设置或变量见[设置扩展](../extensions/settings-and-variables.md)。

## 返回标题与桌面窗口

桌面 Sample 在确认关闭后，把正常窗口尺寸和最大化状态保存在当前游戏 profile 的 `window-placement.json`，自由拖动后的尺寸也会保留。启动时会在首次显示前读取窗口记录并按保存尺寸创建窗口；下次打开居中恢复。更换显示器或 DPI 后，过大窗口会按当前工作区缩小，并在必要时降低默认最小尺寸。窗口记录优先于设置页上次选择的固定尺寸；设置页仍可主动切换尺寸，全屏模式仍沿用原有显示偏好。最小化状态和位置不跨启动保存，移动端不读写此文件。

剧情工具栏的返回标题先打开模态确认，确认后才结束会话。确认期间主页面输入被阻断，自动和快进被取消；取消时恢复原来的自动播放，按住式快进需要重新按下。取消按钮默认获得焦点，Esc 或系统返回取消确认。不同用途的确认不会互相授权，宿主释放会取消待处理的确认。

桌面标题栏在三个窗口按钮左侧提供“适应画面比例”，保留自由拖动缩放。点击后按设计画布比例调整内容区，计算标题栏、窗口边框及当前屏幕 DPI，并尽量保持在屏幕工作区。设置中的“全屏窗口（无边框）”使用系统无边框全屏；全屏和最大化允许画面留边。全屏隐藏标题栏、适应按钮和窗口装饰，禁用缩放，并在 Windows 拦截原生移动及缩放命令；退出全屏恢复之前的窗口尺寸、位置和最大化状态。移动端不显示桌面窗口按钮。

`MainWindow.Chrome.cs` 在首次测量内容前，根据实际主题中可见系统按钮的测量宽度预留标题栏空间；系统按钮隐藏或恢复时重新测量。比例按钮不会等待游戏加载或 Loaded 事件后才避开关闭按钮，也不依赖固定像素宽度。

## 音频名称提示

`audio.play` 和 `audio.enqueue` 可启用 `announceName`（显示资源名称提示），默认关闭。名称在资源 Inspector 中填写并翻译；资源未命名时不提示；实际开始播放后在左下角用主题配色的半透明提示条显示名称，最小宽度 280 DIP，从左向右约 0.8 秒滑入后停留两秒，再用约 0.8 秒向左滑出并淡出，不抢焦点或拦截点击。连续切歌替换当前提示，循环、暂停恢复、读档重建和调试追赶不重复弹出。返回标题和会话释放会清理提示。新增字段属于作者契约，更新引擎后应同步契约并重新导出内容。

## 四种鉴赏

鉴赏包含应用已实现、且资源填写了解锁 ID 的分类，内置为图片、视频、音频和场景。入口的分类按钮水平居中、竖直排列。每类按解锁 ID 升序排列；卡片标题居中，未解锁项（包括音乐曲名）以 `???` 为标题，隐藏真实名称。名称 tooltip 支持悬浮与键盘聚焦；图片和视频详情顶部按需显示资源名。

音频每行显示曲名、可拖动进度与播放/暂停按钮，长曲名省略并提供完整 tooltip；进度条右下角、操作按钮左侧用主题次级色小字显示当前时长/总时长，窄窗口将进度与时长换到第二行。每首曲目保留自己的位置，切换只暂停上一首的逻辑预览，切回继续；尚未播放的曲目也可直接拖动，从选定位置开始播放。同一时间只播放一首，离开音频页停止播放，但本次会话中仍保留各曲目进度。

场景卡片可指定图片封面，进入后在独立运行状态中从所选 Group 开始，到 Group 结束即返回，不沿主线出口继续。无需原 Graph 中孤立，但 Group 应自行准备初始背景、角色和音频。回放变量、已读和解锁写入均不落入正式玩家数据；自定义模块的外部副作用仍需宿主提供适合回放的实现。退出及应用挂起会释放回放资源。

视频鉴赏在画面下方提供播放/暂停、可拖动进度条与当前/总时长；窄窗口将时长移到下一行，保留进度条可用宽度。暂停时可跳转，离开页面停止播放并释放播放器。
