# 存档、对白历史与 Gallery

## 保存与读取

从游戏页面进入存档页，在有效槽位保存或读取当前运行。默认存档恢复稳定剧情位置，不是任意 UI 帧、音频设备时钟或后台业务任务的进程快照。

已有有效存档的名称可以编辑，Enter 或失焦确认，Escape 放弃；清空恢复默认槽位名。名称最多 120 个字符，重命名不改变原存档时间、截图或剧情快照，覆盖保存会保留名称。

存档受内容构建与剧情包身份约束。缺少存档记录的剧情包或构建不匹配时，按实际校验报错；不能通过删字段强行恢复。玩家数据属于 profile，见[启动与内容](startup-and-content.md)。

## 对白历史与重播

默认配置可通过历史入口或滚轮向上打开当前路线历史，关闭后回到游戏。历史随宿主存读档恢复；滚动查看不会重新执行剧情。

具有同源语音关联的历史行可以重播语音。有效继续操作（包括补全文字）会停止重播；滚动列表或调音量不会停止。不是所有单独播放的音频都会自动成为对白语音。

已读标记属于玩家进度。设置可启用读过文本的颜色，默认关闭；读档恢复和已读状态承担不同职责。

## Gallery

Gallery 来自项目资源 metadata 的静态目录，实际解锁由玩家级变量保存，跨存档槽共享。没有可展示内容时入口不可用；多个类型时先选择类型，没有自定义类型的页面映射时显示诊断。

制作 Gallery 内容需要正确的类型注册、稳定 item ID 与资源身份；定制页面见[页面与主题扩展](../extensions/pages-and-themes.md)。快照规则与历史实现分别见[存档规范](../../spec/runtime/state-and-save.md)和[宿主契约](../../spec/presentation/game-host.md)。
