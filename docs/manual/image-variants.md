# 创建和使用图片差分图集

图集把一组完整立绘或场景图片作为一个资源，实例记住各维度选择，再显示匹配的一张图；它不进行纹理打包或图片叠加。

## 创建与配置

1. 在 Assets 面板导入图片目录，例如 `smile_coat.png`、`smile_skirt.png`、`idle_coat.png`、`idle_skirt.png` 和 `weap.png`。使用普通导入操作，让每张图片获得资源 sidecar。
2. 进入该目录，或选中目录，在菜单选择“从目录创建差分图集”。编辑器创建 `variants.variants` 和 sidecar；重名时使用新的文件名。默认图先按稳定顺序选择第一张。
3. 选中描述文件，在属性区用目录选择器选择 Assets 内的图片目录，并用唯一的“默认图片”下拉框选择已有图片。图片目录以相对描述文件的路径显示。
4. 文件名从左到右按 `_` 分段，最长名称决定维度数量。维度数量、顺序和选项自动计算，不能手工添加、删除或排序；每个位置可以修改显示名称，例如“表情”“服装”。位置标题使用本地化“维度 1、维度 2”，不显示内部 key。key 是稳定的剧情引用身份；新位置自动生成 `d1`、`d2` 等不冲突的 key。
5. 修改默认图片或显示名称后立即进入可撤销的项目工作版本，不需要点击应用；用“保存全部”写入磁盘。属性区不再内嵌 JSON 编辑器，损坏的描述可通过通用文件入口修复。

同一目录中不能有同名主干的多种图片，例如 `idle_coat.png` 和 `idle_coat.jpg`。下划线之间不能有空段，default 必须精确匹配已有主干。不同图片的段数可以不同；维度命名配置不决定实际维度数量。目录增长时自动补充位置，缩短时不展示多余位置；已保存的位置名称保留，以便图片恢复后继续使用。

原始描述示例：

```json
{
  "version": 1,
  "folder": ".",
  "default": "idle_coat",
  "dimensions": [
    { "key": "d1", "label": "表情" },
    { "key": "d2", "label": "服装" }
  ]
}
```

## 预览与回退

在属性区选择 `smile` 和 `skirt`，得到 `smile_skirt`；把第 1 维切为 `weap`，没有 `weap_skirt` 时显示 `weap`，但请求中的 `skirt` 保留。再切回 `smile`，恢复 `smile_skirt`。

面板分别列出请求和实际图片，并展示每一步候选。匹配失败时，从后向前累计去掉这次没有明确选择的维度，仍按原位置精确匹配；全部失败则使用显式默认图。回退不会把请求覆盖为实际图的选择，也不会隐藏缺组合的值。

扫描、切换预览和语言切换不写作者文件。Assets 文件新增、删除、改名和内容变化会经防抖通知自动重新扫描，不提供手动重新扫描按钮。刷新保留预览请求，失效时显示诊断，点击“重置预览选择”才重新从默认图开始。默认图片缺失时下拉框留空，扫描诊断说明缺失，不会静默换图或在扫描时改写配置；重新选择已有图片即可修复。候选削减链收在“匹配详情”中。

## 在剧情中使用

新增“显示差分图集”（`variants.show`），用资源选择器选择图集。初始选择字段列出全部维度；“使用默认选择”表示不覆盖该维度。变换、透明度、层级和显示模式沿用普通图层。

新增“切换图片差分”（`variants.select`），选择之前创建的图集对象，再选择维度和值。切换保持该实例的变换和连续属性动画。已知普通图层不会出现在图集对象候选中；分支导致来源不唯一时只提供保守对象候选，不猜测维度和值。已有未知值仍保留在手动输入中，需作者修正。

普通换图会清除对象的图集模式，隐藏会删除实例；再次显示图集重新初始化选择。Timeline 可以操作图集 Layer 的普通动画属性，但当前没有新增 Timeline 差分切换事件。

有效配置修改后，即使尚未保存到磁盘，剧情字段也会使用已提交的项目工作版本。无法通过校验的修改保留诊断，不能提交；外部修改描述文件仍遵循项目文件冲突处理，不覆盖未保存工作。刷新、换条目或关闭项目后，旧选项不能继续提交。

## 运行仓库示例

`GameTestCase` 的默认 intro 包含两个可直接运行的图集，拉取后需重新构建项目，旧 Output 不会自动更新：

- `Assets/Variants/xy.variants`：五张 `xy_表情.png` 立绘和一张复用 wink 图片的 `solo.png`。选择 shy → 第一维 solo 时削减显示 solo，再切回 xy 恢复 shy；Reduced 对话处可存读档。
- `Assets/Variants/classroom.variants`：两张原有 classroom 背景，按 `scene_mode_focus` 命名。选择 speech 时缺少 empty 组合，显示显式默认背景；再选择 teacher 显示讲台背景。Default 对话处可存读档。

隐藏再显示会恢复默认选择；后续 wink 切换发生在既有立绘循环动画期间。详细检查点、资源 ID 和构建命令见 [示例说明](../../GameTestCase/README.md#image-variants-walkthrough)。

标准导出包将图集编译定义与图片一起放入 PAK，运行不需要原始图片目录或作者 `.variants` 文件。自定义宿主需在创建执行模块前注册 decoder、准备图集 catalog，并传入 `AddBuiltins(imageVariants: ...)`。
