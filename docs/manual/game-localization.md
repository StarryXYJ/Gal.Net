# 编辑游戏文本与翻译

在视图菜单打开“游戏本地化”。左侧选择角色表、任意 GalGroup 或分支选项，右侧按语言显示文本；开发语言始终在最左列。普通剧情表单和角色表仍直接填写开发语言，移动条目不会改变译文身份。

在语言代码框填写如 en-US、ja-JP、zh-Hans-CN，然后点击“添加语言”。新列初始缺译，不会复制原文。列头左右箭头调整其他语言的位置；开发语言不能用箭头移走。

单元格支持多行：Enter 换行，Ctrl+Enter 或移出焦点提交，Escape 放弃当前输入。缺译和空字符串不同；对空单元格明确按 Ctrl+Enter 会保存空字符串。修改原文会保留其他语言，并使已有原文关联的译文显示“待复核”；检查后重新提交译文即可关联当前原文。“复核状态未知”表示缺少关联证据。

同分类内共享文本只显示一行，并提示引用数量；修改会影响共享位置。使用“定位引用”打开对应创作位置。表格横向滚动可查看更多语言，左侧分类和右侧文本行可独立纵向滚动。

需要更换项目开发语言时，先添加该语言，再在“开发语言”中选择它，点击“检查变更”。面板显示目标语言缺译数量；检查后点击“应用开发语言”。这不会自动翻译或复制文本，普通创作页随后使用新的开发语言。检查后文本发生变化时，需要重新检查。项目设置页面的开发语言仅显示当前值。

所有文本和语言操作支持项目撤销/重做，使用 Save All 保存。切换分类或关闭面板会保留未提交草稿；Save All 会尝试提交它们。遇到原文、译文、引用或 JSON 草稿冲突时，当前输入保留，请先检查现值；“放弃草稿”会清除面板中所有分类的待提交输入。项目关闭后不再接受旧面板写入。

当前阶段尚未提供模板导入导出；缺译数量也不能代替发布前完整检查。作者数据及扩展契约见 [游戏本地化规范](../spec/editor-game-localization.md)。
