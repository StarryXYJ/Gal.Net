# Avalonia 游戏页面与内容对接计划

## 目标

补全官方 Avalonia Sample 与 `GalNet.Avalonia.GameView` 中可复用游戏页面的功能，并让各项页面能力能够由游戏流程和资源内容驱动。

## 维护约定

- 当前阶段使用 `进行中` 标记；未开始阶段保留完整工作项。
- 某阶段完成、验证并提交后，将其详细工作项压缩为一条完成摘要，并标记为 `已完成`。
- 每个阶段单独提交 Git，提交信息以 `feat(game-page): ...` 为前缀；文档状态变更包含在该提交中。

## Phase 1：Layer 页面层级（已完成）

已完成：JSON `.galgroup` 编译、隐藏句柄的泛型动态实例管理、Layer 的 Transform/z/五种展示模式、`layer.replace`、场景恢复，以及 Sample/编辑器预览共享渲染链路。`hide` 会删除实例并立即使句柄失效；失效操作记录诊断后安全跳过。

## Phase 2：动画原语与转场（进行中）

当前增量先实现单条 `animate`：单句柄、单个浮点属性、默认 Replace、可选 `from`、曲线、阻塞、可跳过和 `batchId`。案例以立绘左移验证该最小链路；多轨 `AnimationPlan` 与转场编译在此基础稳定后再实现。

### 分层与编译

- `layer.show`、`layer.hide`、`instance.set` 是立即生效的场景原语；`hide` 仍立即使句柄失效。
- 新增 `animate` 属性插值原语：目标为场上实例句柄，参数为经实例类型注册的可动画属性，包含 `from?`、`to`、`duration`、`easing`、`blocking`、`skippable`、开发者提供的 `batchId?`，以及默认的 `Replace` 冲突策略。
- `from` 未填写时，在动画真正开始时读取实时显示值；填写时先瞬时写入 `from`，再插值至 `to`。后续再增加增量型动画策略，第一版只实现 `Replace`。
- 实例以特性声明可动画属性的名称、值类型、范围和编辑器元数据；Runtime 建立类型化注册表，负责安全读写、校验与插值，编辑器据此为句柄定位器提供可选参数。
- `layer.move`、淡入淡出和 `transition.*` 等编辑器级命令由 JSON 编译层展开为场景原语与 `animation.play`，Runtime 只执行原语和动画计划。

### 动画计划

- `animation.play` 接收 `AnimationPlan`：多个子动画各有相对开始时间、目标属性、起止值、时长和曲线；计划总时长为所有子项结束时间的最大值。
- 子项只允许属性轨道及 `show` / `hide` / `set` 场景提示，禁止任意流程 Entry，确保并发、跳过和存档行为确定。
- 交叉淡化编译为一个计划：时间 `0` 显示第二 Layer 并设透明度 `0`；两张 Layer 的透明度在同一时段交叉插值；计划结束时隐藏第一 Layer。
- `blocking=true` 等待计划完成；非阻塞计划进入活动动画管理器。`batchId` 省略时该计划单独成批；相同非空 `batchId` 的可跳过活动计划会被同一次左键一起完成。
- 冲突键为 `(handleId, property)`。默认 `Replace`：旧轨道取当前插值值后停止，后启动的轨道从该实时值继续；同一计划中的轨道按定义顺序校验，冲突报诊断。

### 稳定场景状态与存档

- 场景维护稳定状态与实时展示状态：直接场景原语同时更新两者；活动动画仅更新实时展示状态。
- 每个 `AnimationPlan` 拥有自己的稳定状态补丁。计划完整结束后才原子提交其最终属性/可见性变化；计划未完成、被跳过或被替换时，按最终完成结果提交或丢弃相应补丁。
- 存档只序列化稳定状态，不保存活动动画、时间轴进度或输入批次；读档后从最近稳定画面恢复，无半截动画。
- 新的 `show` / `hide` 或同属性 `Replace` 动画必须取消并清理涉及目标的旧活动轨道与稳定状态补丁，避免已取消动画在稍后重新写回状态。

### 验收

- Sample 的第一条分支使用非阻塞、可跳过的 `AnimationPlan` 完成背景交叉淡化；左键按 `batchId` 结束同批动画。
- 覆盖 `from` 缺省/显式、Replace、阻塞与非阻塞、跳过、无效句柄/属性、跨淡化结束隐藏、稳定状态存档与恢复。
- Timeline 作为后续编辑器多轨 UI，编译到同一 `AnimationPlan`，不成为 Runtime 的独立依赖。

## Phase 3：Effect 效果
