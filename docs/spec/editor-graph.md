# Editor Graph 编辑

当前实现：F-20261015-02 / P2、P3。作者数据在项目文档中，GraphNode/GraphEdge 是可观察投影。节点增删、改名、移动、连线、分支与粘贴记录只持项目数据和稳定 ID；关闭或重建 Workspace 不丢失这些操作的撤销能力。Entry 编辑使用项目作者服务，变量声明及引用意图见 [变量编辑](editor-variables.md)；Preview 只编辑运行时当前值。

## 图规则

- GUI 项目有且只有一个显式 Entry 根；基础界面不能删除或再创建 Entry。
- 每个输出口最多连接一个目标；替换连接只替换该输出口的旧边。同一目标可以接受多个前驱，GUI 与 CLI 使用相同规则。
- 不允许自连接、连接到 Entry 或使用不存在的输出口。加载失败报告错误，不通过丢弃边或补样例节点修复。
- 节点 ID、显示名和 Group 源路径独立。改显示名不会重命名文件。

## 用户操作与持久化

| 操作 | 当前行为 |
| --- | --- |
| 新建 Group | 生成稳定 ID 与 `Graph/groups/<id>.rawgalgroup` 空源，不插入任意默认 Entry；节点与源文件通过结构计划立即发布 |
| 从输出口新建节点 | 新节点和连接合为一条历史；撤销恢复原输出边 |
| 删除 Group 或包含 Group 的选择 | 同一结构计划删除节点、关联边和源文件；一次撤销恢复相应顺序、关联边与内容 |
| 新建/删除纯 Branch 选择 | 普通内存内容编辑，保存全部后写盘 |
| 改名、连线、断开 | 普通内容编辑；可撤销，保存全部后写盘 |
| 拖动一个或多个节点 | X/Y 为界面预览，作者坐标直到松手才提交；一次手势记一步。Escape、丢失捕获、页面脱离取消预览 |
| 选择、框选、平移缩放 | 不进入内容历史；视口通过独立 view-state 保存 |
| 分支项增删、重排、文本或条件修改 | 使用稳定项 ID，整次操作进入项目历史；删除中间项只删除其出边，其余连线跟随原项并映射到新 outlet |
| 复制粘贴 | 复制所选非 Entry 节点及内部边，Group 内容深复制；整批粘贴和源文件一次撤销/重做 |

Group 文件结构操作分别变换 Working 和 Saved：删除前未保存的条目保留在 Working 撤销材料中，磁盘恢复使用 Saved 材料。等待已有保存完成后，才在发布门内捕获两者；再次删除重新捕获当前基线，避免覆盖后来保存的内容。工作版本恢复保留已有作者对象身份，以便已有条目绑定继续指向实际内容。关闭时 Discard 不反向撤销已经发布的文件结构操作。

Workspace 根据文档事件增量协调节点、分支项与边，页面释放时解除监听；被移除边释放节点事件订阅。名称和分支字段在作者变更前进入历史，不通过属性监听补记。投影保留已有分支 DTO 和编辑控件身份，输入刷新不会重建整个 Inspector；锁定 Inspector 的节点删除后停止展示旧目标，撤销后按 ID 绑定恢复的节点。连接器保留分支项 ID，排队从输出口创建节点时再次按该 ID 定位出口；Working 与 Saved 顺序不同的情况下分别解析该 ID，不顺带保存重排。空分支没有可连接出口。尚未迁移的条目监听在项目历史执行时停止记账，并在结束后刷新前值。

## 复制边界与键盘

画布使用系统文本剪贴板保存版本化选择快照；当前版本为 1，粘贴入口最多接受 1000 个节点、16 MiB 文本。每次粘贴重新生成节点、边、分支项和 Entry 稳定 ID，并为 Group 生成独立源路径；相对位置保留，外部入边/出边不复制，Entry 根始终不复制。重做使用历史保留的副本，不再依赖剪贴板或源内容。无效格式在修改前拒绝。当前字段契约未声明额外 Graph 引用类型，已重映射的结构关系是边端点和 Group 文件归属；自定义参数中的字符串/JSON 原样保留，粘贴后状态提示作者检查这些引用，不猜测替换。

画布 Ctrl+C/V/A 分别复制、粘贴和全选，Delete 删除选择，F 定位选择（没有选择时显示全图），Home 显示全图；Ctrl/Shift 点击追加选择。这些 Graph 专用键位当前固定，右键菜单显示相应操作和键位，未接入编辑器设置中的自定义手势。文字输入框先消费本地操作，再由页面处理项目快捷键；正在拖动或连线时只有 Escape 取消交互。定位、选择和视口不改变作者内容或历史。

文件外部变化或发布失败会报告错误，失败不推进历史；批量粘贴与撤销的中段文件发布失败使用相同事务补偿并可重试。保存、补偿与恢复语义见 [项目历史与保存](editor-history-and-save.md)。项目文件界面及完整参数草稿按后续 Phase 实施；原生桌面完整人工验收尚未进行。

Group 页的类型搜索、批量插入、空格快速插入、折叠拖放和选择行为见 [Group 编辑交互](editor-groups.md)。P5c 独立变量面板、P5d 条目字段历史绑定和 P5e 未完成作者草稿保存已验证；复杂参数编辑与状态查询继续按 P6 推进。
