# Editor Graph 基础编辑

当前实现：F-20261015-02 / P2。作者数据在项目文档中，GraphNode/GraphEdge 是可观察投影。基本节点增删、改名、移动与连线记录只持项目数据和稳定 ID；关闭或重建 Workspace 不丢失这些操作的撤销能力。分支字段、条目和变量的旧记录仍按 P3/P5 迁移。

## 图规则

- GUI 项目有且只有一个显式 Entry 根；基础界面不能删除或再创建 Entry。
- 每个输出口最多连接一个目标；替换连接只替换该输出口的旧边。同一目标可以接受多个前驱，GUI 与 CLI 使用相同规则。
- 不允许自连接、连接到 Entry 或使用不存在的输出口。加载失败报告错误，不通过丢弃边或补样例节点修复。
- 节点 ID、显示名和 Group 源路径独立。改显示名不会重命名文件。

## 用户操作与持久化

| 操作 | 当前行为 |
| --- | --- |
| 新建 Group | 生成稳定 ID 与 `Graph/groups/<id>.rawgalgroup` 空源，不插入任意默认 Entry；节点与源文件通过结构计划立即发布 |
| 从输出口新建节点 | 新节点和连接合为一条历史；撤销恢复原输出边 |
| 删除 Group 或包含 Group 的选择 | 同一结构计划删除节点、关联边和源文件；一次撤销恢复相应顺序、关联边与内容 |
| 新建/删除纯 Branch 选择 | 普通内存内容编辑，保存全部后写盘 |
| 改名、连线、断开 | 普通内容编辑；可撤销，保存全部后写盘 |
| 拖动一个或多个节点 | X/Y 为界面预览，作者坐标直到松手才提交；一次手势记一步。Escape、丢失捕获、页面脱离取消预览 |
| 选择、框选、平移缩放 | 不进入内容历史；视口通过独立 view-state 保存 |

Group 文件结构操作分别变换 Working 和 Saved：删除前未保存的条目保留在 Working 撤销材料中，磁盘恢复使用 Saved 材料。等待已有保存完成后，才在发布门内捕获两者；再次删除重新捕获当前基线，避免覆盖后来保存的内容。工作版本恢复保留已有作者对象身份，以便已有条目绑定继续指向实际内容。关闭时 Discard 不反向撤销已经发布的文件结构操作。

Workspace 根据文档事件增量协调节点与边，页面释放时解除监听；被移除边释放节点事件订阅。基本名称不再通过属性监听补记历史。尚未迁移的条目/分支监听在项目历史执行时停止记账，并在结束后刷新前值，避免页面重建后撤销又生成新记录。

文件外部变化或发布失败会报告错误，失败不推进历史。保存、补偿与恢复语义见 [项目历史与保存](editor-history-and-save.md)。当前提供基础 Graph 创作，复制粘贴、分支完整交互、项目文件界面及完整参数草稿按后续 Phase 实施；原生桌面完整人工验收尚未进行。
