# Editor 变量面板

“查看 → 变量”打开项目内唯一的变量 Dock 面板，可关闭、重开和浮动；不默认开启游戏预览。面板内以玩家变量/存档变量页签区分作用域。玩家变量跨游戏存档持久化，存档变量随游戏存档保存/恢复；此处只编辑声明和初始值，运行期当前值由后续预览工具负责。

## 草稿与项目历史

左侧列出当前作用域的变量，右侧编辑名称、类型、默认值和说明。输入保留在面板草稿，点击应用才提交；还原草稿只重读当前声明，不产生历史。切换选中或作用域重新加载对应声明。外部声明刷新不静默覆盖同一选中项的未应用草稿，提交时按原声明快照检查冲突；发生冲突可还原后重新编辑。

新增、应用和删除各是一条项目历史，变量稳定 UID 不随改名/类型变化改变；关闭面板仍可撤销。Graph 的 playerVariables/saveVariables 为唯一作者来源，settings 中同名列表由保存派生，不由面板另外维护。新面板采用显式项目意图，旧 Preview 变量编辑仍待预览阶段整理，不能据此宣称所有旧绑定已经移除。

名称在两个作用域间唯一、区分大小写；使用 ASCII 字母或下划线开头，后续允许字母、数字和下划线。表达式关键字及 Gallery 生成名称保留。类型包括 Bool、Int、Float、String：切换类型把默认值草稿重置为相应零值；Bool 默认值使用 CheckBox，Int/Float 使用 NumericUpDown（步长分别为 1 和 0.1），String 使用 TextBox。数字输入使用固定小数点格式，应用时 Int 限 Int32，Float 必须有限，String 为无需 JSON 引号的原文。说明是作者内容，不翻译。非法输入不写作者文档，不追加历史。

## 引用检查

检查覆盖 Graph 选项/分支条件、当前项目全部作者 Group（包括未打开页面）的 Entry 条件，以及契约 schema 标注为 VariableName/Expression 的参数。

- 变量名字段匹配精确名称以及 player./save. 前缀，重命名保留原前缀。
- 表达式先按与现有校验相同的 NCalc 语法检查，再按词法边界替换方括号参数与裸标识符；跳过引号和日期字面量、函数名与非支持限定表达式。不是全字符串替换。
- 普通条目参数、选项文本、不能可靠处理的表达式只列候选位置，不自动修改。候选可能是普通文本出现同名片段，不承诺它确实是运行时引用。

重命名同时更新明确引用，定义及引用可一次完整撤销/重做。明确引用存在时禁止删除；候选不作为强制阻止条件，删除前可在引用列表查看；删除不自动修改候选文本。改名返回的候选会继续显示，供作者检查旧名称。引用位置目前为逻辑路径，不包含 P7 的完整 Problems 定位体验。

项目意图按稳定 UID/节点 ID/Entry ID 查找，不持有关闭的面板；修改前检查实际声明和引用，失败不移动历史游标。通知失败尝试恢复声明与引用，恢复再次失败进入项目 RepairRequired。已打开 Group 的条件、参数投影、变量候选及诊断在编辑和历史执行后刷新。四语覆盖面板、错误和历史标题。

当前实现与验证范围见 F-20261015-02 / P5c。CLI 旧变量重命名策略没有借此切片变为相同策略；后续统一入口时须另外处理。
