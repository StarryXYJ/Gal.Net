# Editor 场景目标查询

音频效果现在使用同一作者快照、Graph/条件/固定点和前缀分析机制，结果使用独立的音频状态与完整性，详见文末“音频效果域”。

`Editor.Shared.Services.SceneTargetAnalysis` 对作者 Graph 和 Group 快照进行纯分析，不创建游戏、不执行 Entry，也不读取或修改玩家数据。项目 scope 的 `ProjectSceneTargets` 是场景状态查询入口，按当前内存作者快照复用一代分析，包含 Group 入口事实；修改、撤销、重做或拓扑改变后整体换代，保存相同内容复用原代。项目 scope 释放时清除缓存并使旧查询选择失效。场景分析仍为同步纯计算，没有增量前缀缓存；效果声明与已编译图集定义的资源读取和解析在后台准备，完成后发布不可变快照并推进查询代次。

普通查询位置是某个 Group 的某个稳定 Entry **执行前**，null 表示 Group 末尾；`AtTimeline` 查询指定 Timeline 的帧或事件前位置。目标来源为 Group ID、创建者稳定 Entry ID 和输出槽位组成的 `SceneLocator`，Timeline 事件创建者另有事件身份，内部解析到运行时 handle。返回对象种类、来源、资源提示、能力、唯一可知数值与存在性；候选的存在性只有一定存在、可能存在。没有入口或尚未分析到的位置返回不可分析结果，不伪造空场景已经完整分析。

生产项目的查询服务订阅作者成功提交结果，捕获完整作者版本并发布 Changed；普通删除及撤销不再需要借助资源刷新才能通知查询消费者。Timeline 同时按提交结果读取最新作者内容，不用历史忙碌或保存状态变化代替内容事件。当前仍采用整作者快照代次，查询依赖/结果的局部版本尚未接入。

所有可达 Graph 边参与保守合并，不求变量表达式的具体值：确定集合取交，可能集合取并；属性初值只有在所有输入都确定存在且数值相同时保留。空条件或字面量 true 执行，字面量 false 跳过，其他条件合并执行与跳过两路。循环工作队列求有限事实固定点；预算耗尽时只发布可能候选并标记不完整，不把未收敛状态当确定事实。

两条分支若手工复用同一底层身份却产生不同对象类型，合并后保留为可能的未解析目标，不宣称其中一种类型一定存在，也不提供推测出的属性能力。

当前支持：

| 作者操作 | 分析行为 |
| --- | --- |
| layer.show / showColor | 按 handle 创建或替换来源，提供 Core 的变换/不透明度能力和可知初值；show 的有效 flipbook 另提供索引能力 |
| layer.hide / move / replace | 按层语义删除、更新变换、替换资源，保留实例身份 |
| particle.play / stop | 使用纯粒子定义解码和 Core 声明的 float 能力，创建/删除目标 |
| effect.apply / stop | 创建/删除效果目标，保留 Core progress，并从 program metadata 或 legacy catalog 增补支持的标量能力 |
| video.play / stop | 视频可能自然结束，创建后仅标可能存在；停止移除层候选 |
| animation.animate | 保留场景对象存在性，清除相关对象的唯一数值；额外提供可定位的播放候选 |
| animation.stop | 立即完成时移除播放候选；本轮结束后停止只保留可能候选，不推测当前显示值 |
| 已知对白、音频、变量等中立条目 | 保持场景候选事实 |
| timeline.play | 阻塞 Once 向后传播事件与轨道终态；非阻塞/循环保守保留入口、终态和中途创建者的可能集合 |
| 六种内置转场 | 复用内置契约的纯编译展开，按阻塞 Timeline 终态传播新层、删除旧层；临时遮罩/覆盖层在终态移除 |
| 自定义或未支持语义 | 已知目标降为可能，清除唯一数值并提示分析不完整；不执行它们获取结果 |

候选缺失不清空既有轨道，无法匹配的引用显示为未解析对象。查询是作者辅助，没有改变编译或运行时的参数校验规则。

layer.show 的非空、有效 FlipbookDefinition 提供 Core 的 flipbook.index 属性及可写的原始浮点初值；静态图片、null、颜色层和视频不提供此能力。显式空对象使用 Core 的 1×1 默认定义。索引不取整，也不以 FrameCount 设置动画上限；格子显示的 floor/clamp 仍由渲染路径负责。无效布局保留基础层事实、移除索引能力并标记不完整；负值或非有限索引没有可写初值。无法解码的 JSON 使条目分析退回保守输入，不发布新层。

Move/Replace 保留已创建对象的 flipbook 能力，重新 Show 静态层移除；分支合并取共同属性能力，可能存在的对象不发布唯一数值。Timeline 事件创建、未来候选、帧内与终态采样使用同一能力，未来候选保留能力但不提供当前数值。源定义变更使旧行失效，既有轨道保留供作者修正。此分析只读取作者 JSON，不读取图片尺寸或编译效果程序。

内置转场只通过固定内置契约目录调用纯编译器，不加载或运行项目自定义条目。展开结果和无效输入按不可变快照代次缓存，条件在原条目边界合并；缺失旧层不阻止创建新层。无效参数保留保守输入事实并标记不完整，不发布部分展开对象。未知作者扩展不参与临时编译投影，原 JSON 保留，严格项目编译仍执行原校验。转场输出的 Locator 使用原 Group/Entry 及 newHandleId/toLayerHandleId 输出槽位，不使用编译生成事件或瞬态对象的身份。

## 效果能力与资源快照

非空 program 使用 shader 注释的 Core `ShaderEffectMetadataParser` 声明，优先于 legacy id；空 program 才使用宿主 `IEffectCatalog`。两种来源均检查目标 stage。Core `ShaderEffectAnimationProperties` 与渲染器共用转换，只增补 animatable 的 Float/Integer 标量，不把 bool、颜色、向量或纹理臆造为 float 轨道。

标量初值优先取 parameters 中的有限数值，其次取 metadata 默认值或 0，再按声明范围夹取。无效静态值保留属性能力但不发布唯一初值；重复参数同样保守处理。Core 自带的 progress 仍单独保留：EffectRequest 已提供初值 0，先于 shader 静态值/默认值；metadata 声明同名属性时使用与 Core 0..1 的共同范围，不能共同接受 0 时不显示可写初值。

同步查询只使用已经准备的资源事实，并排队后台准备；`PrepareAsync` 可等待资源就绪。准备直接读取 IGameFile 源字节，不借用 renderer decoder 缓存、不执行项目自定义代码、不编译 GPU shader。普通 effect.apply 及 Timeline 事件中的 program 引用共用快照；每个作者快照最多准备前 256 个不同 program，每份源码上限 1 MiB。错误类型、缺失、读取失败、坏 UTF-8/metadata 和超出预算均不推测 shader 能力；失败缓存至下一次资源刷新。

缺声明的效果仍具有已知身份和 Core 能力，按目标标记 CapabilitiesComplete=false。对外结果汇总当前能力完整性，内部组合查询仍保留语义完整性：停止此效果可以消除能力缺失，不会抹掉上游未知语义。条件、分支、Timeline 事件/未来候选和采样沿用同一声明；未来或可能对象不提供唯一当前数值。

资产目录 Changed 通知使资源快照失效并重新准备。完成、刷新和项目释放都推进查询代次；旧资源加载不能覆盖新代，旧 Locator 选择、属性行和手势不能提交。取消单个 PrepareAsync 调用只取消该调用方的等待；刷新或项目释放才取消共享加载。Timeline 订阅变化并更新属性菜单/行，既有轨道与未知作者 JSON 保留，查询和刷新不写内容历史。没有实时游戏预览。

## Timeline 帧内查询

`SceneTimelinePosition(Frame, BeforeEventIndex, IncludeFuture)` 描述第一次正向行程；事件按帧、再按作者数组原序处理。通常先应用截至当前帧的事件，再用共享 `TimelineSampler` 采样；事件前查询不执行该事件及同帧后续事件，也不猜测尚未采样的轨道属性值。事件索引是查询边界，不是 Locator 身份。

`TimelineEventCapabilities` 统一内置十种允许事件和参数规范化入口，契约校验与查询共同使用。缺目标操作跳过。未知或无效语义使分析不完整；Additive 与对象事件组合的基值不能证明时清除唯一值。非阻塞/循环后的剧情位置不能假定某个动画时刻，包含仅在中途创建又删除的可能对象；不模拟实时播放生命周期。

`IncludeFuture` 额外返回之后才创建的对象，标注创建帧、可能存在、尚未存在且没有当前值；不会将未来未知事件误用于降级当前已知存在性。事件 Locator 优先使用作者 `editorId`，缺省按输出槽位和声明输出身份定位，不补写作者 JSON、不依赖数组下标；重复显式事件身份视为不完整数据。查询有一万事件/关键帧预算。

Timeline 对象“＋”选择器使用当前帧并包含未来候选，普通字段仍使用 Entry 前位置。新增属性的第 0 帧初值与当前帧值分别查询；中途事件改变后的值不会回填成第 0 帧初值。选择 lease 包含查询位置，资源标签/语言刷新保留该位置，切换帧使 Timeline 旧草稿失效。查询、搜索和选择对象本身不写作者内容。

Timeline 事件作者界面使用独立事件行，按帧和同帧作者顺序显示；事件与属性轨道共用播放头、缩放和横向位置。有限类型选择器只提供十种受支持事件，确认后在当前帧新增，同帧顺序在已有事件之后；显式新增生成 editorId 和创建者内部输出身份。

事件画布复用共享选择/框选/整帧拖动，多事件可以在同一帧，帧 0 事件也可以移动；不使用属性关键帧的碰撞替换或首键限制。拖动仅预览，松手把移动和需要的时长延长合成一次内容历史，负帧拒绝、Escape 取消。事件右键支持同帧提前/延后和批量删除，未知事件保留原 JSON，可移动和删除，禁止进入不受支持的表单。

事件参数弹窗通过 `DtoEditorHost` 使用同一个 `EditorRegistry`：整 DTO、成员及默认类型控件均可复用。Editor 外观由 Group 与事件弹窗共同引用 `AuthorFormStyles.axaml`；图片/效果程序成员复用资产选择控件，目标成员复用场景选择控件。输出身份隐藏；目标候选使用该事件执行前的位置，不包含同帧后续或未来创建者。表单修改先进入可取消草稿，点击应用才以单次历史 patch 参数；未改字段、未知扩展和作者大小写保留。帧/目标/相关作者版本改变或关闭后旧草稿不可提交，查询、打开、取消和语言切换均不写内容。实时预览仍不在范围内。

GUI 新增内置层、视频、粒子、效果创建条目时分配新的内部 GUID；animate 和六种内置转场同时分配播放身份，Timeline 有根定义时也分配根播放身份。换类型按统一声明的逻辑输出角色、身份域和目标种类保留相容身份，包括不同输出字段名和 Timeline 根播放路径；新增或不相容角色分配新身份。转场输入对象仍由作者选择，打开作者内容不会补写身份。

Group 条目粘贴先为批内创建者和 Timeline 播放/事件输出分配身份，再按已声明的引用槽位重映射批内引用。Graph 粘贴使用覆盖全部选中 Group 的同一批次映射，因此跨 Group 的对象、播放、Timeline 轨道/事件引用一起指向复制后的创建者。转场的输入引用仅在输入创建者也被复制时改写，转场输出和播放身份独立更新。外部引用、资源 ID、不相关 JSON 字符串、未知自定义条目的同名参数保留。重复粘贴生成不同身份，同次粘贴的身份随 Undo/Redo 保留。

转场表单的输入成员复用场景 Picker，只列出转场前的层候选；输出对象和播放身份复用共同的输出声明隐藏，不要求作者输入内部 ID。播放停止字段已接入下述播放实例 Locator；这不表示所有未来扩展字段都已隐藏内部身份。

## 图片差分图集事实

`variants.show` 创建 Layer 候选，来源槽位仍为 `handleId`。`SceneTarget.Resource` 表示实际 sprite；可选 `Variants` 单独记录可能的图集资源 ID、图集来源是否唯一以及可知的不可变选择结果。选择结果包含完整请求、保护维度和回退链，使用与运行时相同的 `ImageVariantsResolver`；查询不执行游戏。`variants.select` 更新可知的图片与选择事实，保留对象 Locator、存在性、连续属性能力和已知数值。普通 show/color/video/replace 清除图集身份；hide 移除对象，再次 show 使用新初始选择。

合并不同请求的分支时保留共同的图集来源，但不选择其中一条路径的请求；不同图集来源合并为可能 ID 集合，不提供唯一来源。条件性普通换图也会使图集模式仅为可能。此时后续 select 不推测实际图片，结果标记不完整；未知场景语义清除图集绑定。对象是否存在与图集来源是否唯一是独立事实。Timeline 可定位此前创建的图集 Layer 并采样原有动画属性，这不增加 Timeline 的差分切换事件类型。

项目查询仅异步读取编译 payload，不同步扫描作者目录；每代最多准备 256 个图集引用，每个 payload 最多 1 MiB，超出部分保持不完整。缺失、类型错误或坏定义缓存为失败，直到资源刷新。资源刷新或项目释放取消该代读取并使旧选择失效，迟到结果不能发布进新代；取消一个查询者的等待不取消项目共享准备。

GUI 的 `variants.show` 资源字段筛选 `image-variants`，变换复用既有控件；`variants.select` 对象字段复用场景 Picker，包含已知可能属于图集的 Layer，排除已知普通图层。来源不唯一的候选显示路径差异提示。创建者内部身份自动分配且隐藏，复制统一重映射 show/select 及 Timeline 轨道引用，不改资源 ID 和维度值。选择确认进入一条内容历史，撤销/重做及保存重开保留未知 JSON。

show 的初始选择按定义提供所有维度与全部值，空选项表示继承默认图的选择；修改一个维度以一次参数 patch 保留其余选择和未知键，JSON 修复入口继续可用。select 的维度和值跟随对象来源及当前维度联动，并保留手动文本入口；既有未知值不会因刷新自动清空。来源不唯一或定义未准备时不伪造确定选项。资源准备完成和语言变化刷新控件，旧控件的提交检查作者参数、当前资源结果代次与字段有效性。

项目已跟踪图集文本的工作版本提交或撤销/重做使资源查询换代；后台准备使用该次捕获的工作字节重建定义，不读取尚未提交的文本草稿。原始目录和图片事实沿用作者扫描规则，未知或失效的请求不因配置变化自动迁移。冷启动选择器等待同一作者快照和同一资源代次的准备完成后可更新结果快照；等待期间若发生作者修改、资源刷新或 scope 关闭则保持过期。详见 [图集作者流程](../manual/image-variants.md)。

## 播放实例 Locator

`SceneTargetResult.Targets` 仍只包含场景对象；`Playbacks` 单独返回播放控制候选，复用 SceneTarget 数据和 Locator，但没有可动画属性或唯一数值。停止动画字段查询 Playbacks，Timeline 对象选择和属性树继续使用 Targets。两种查询共用同一项目作者快照、资源代次及过期保护，选择 lease 保留查询域，语言刷新不会把播放候选换成场景对象。

Animate 的来源槽位是原条目的 playbackHandleId；Timeline 的来源槽位是 timeline.playbackHandleId。非阻塞 Once、Loop 和 PingPong 在后续剧情位置只标可能存在，不推测自然完成、替换或并发时刻。阻塞完成的 Once 和零时长 Once 不新增后续候选。Timeline 内部第一行程的非终点可确定当前播放存在，终点和零时长保持可能；查询不是实时播放状态。

CompleteImmediately 停止移除候选，AfterIteration 只请求结束当前迭代，不能当作已经停止，也不会据此猜测对象终值。条件、Graph 分支/循环与分析预算沿用保守规则。重复播放身份指向不同创建者、或与场景身份冲突时不提供可解析的播放选择；空身份不自动生成，不修改作者 JSON。

animation.stop 的播放字段使用共享卡片选择器，显示本地化播放类型、原 Group/Entry 来源和存在性；支持本地化名称及原英文类型 ID 搜索，底层 handle 不展示。既有未解析引用原样保留，显式重选或清空才写入一条内容历史。复制时来源和停止引用继续使用统一身份重映射，其他字符串及未知字段不变。此切片不改变运行时播放或停止语义，也未完成所有缺目标路径的独立运行核验。

## 查询与选择控件

查询服务只接受剧情位置并返回场景事实，不拥有控件或弹窗。Editor 的 `SceneTargetCatalog` 将事实适配为资源名、类型、创建来源和存在性候选，并通过 Locator 解析内部 handle；`SceneTargetSelection` 捕获位置、候选身份与分析代次，提交前重新检查有效性。普通条目字段和 Timeline 都使用这一查询入口，筛选条件由调用方提供。

共享 Avalonia `ResourcePickerPanel` 提供搜索、卡片、可选缩略图、方向键高亮、Enter 确认和 Escape 取消；原 Assets Picker 与 Editor 的 `SceneTargetPicker` 均使用此面板。资产文件与场景创建实例是不同的数据源，场景中使用同一资源的两个对象分别显示。搜索无结果时清除当前选择，不会确认上次目标；语言切换不写作者数据。

内置 layer.hide/move/replace、video.stop、animation.animate 的目标，effect.apply 的目标层，以及 effect.stop、particle.stop 的实例字段通过 DTO 成员映射使用场景选择控件，不为所有字符串注册同一控件。创建者的内部输出身份从普通生成表单中隐藏，尚未解析的既有引用显示提示并保留原值；重选或清空才修改参数。effect.apply 的空目标显示“整个场景”。播放停止字段复用同一控件并使用独立的播放查询域；转场输入字段仅提供层候选。

选择器展示一定存在与可能存在两类候选；不完整分析显示提示，仍允许作者选择可能目标。控件自行管理展示和焦点，字段与 Timeline 各自保存结果；没有统一弹窗调度服务。普通字段确认是一条项目内容历史，候选查询、搜索、取消均不写内容。切换/删除条目、改变写入方参数或相关查询结果、关闭项目后，旧选择不能提交；无关作者修改、名称/语言刷新和保存相同作者内容不使选择失效。相关变化后再撤销不会复活旧选择。

验证记录见 [P6e1](../../features/F-20261015-02-editor-authoring-workspace/phase-6e1.md)、[P6e2b](../../features/F-20261015-02-editor-authoring-workspace/scene-locator-plan.md) 与 [P6e4a](../../features/F-20261015-02-editor-authoring-workspace/phase-6e4.md)。

## 作者关系与引用诊断

Editor.Shared 的 `SceneAuthoringSemantics` 集中声明内置 Entry 的输出逻辑角色、JSON 字段、对象/播放身份域、引用允许的目标类别及图集/全局目标约束。自动身份、复制重映射、普通输出字段隐藏、目标筛选和引用索引共用此声明；场景中立类型也由该目录明确列出。值约束继续由原 schema 负责，具体状态转换继续使用已有纯分析和 Core 能力，不执行项目提供的扩展代码。

`SceneReferenceIndex` 扫描所有 Group，包括未打开和不可达的 Group，记录 `(GroupId, EntryId)`、JSON Pointer、原始身份、定义/使用槽位、Timeline 帧/事件位置及覆盖诊断。Timeline 外壳成员按既有大小写规则处理，事件参数遵循对应 Entry 的 wire 字段。对象身份和播放身份分域；复制只改已声明槽位和批内同域引用，不替换资源 ID、普通字符串和未知 JSON。同一原始身份可以有多个候选定义，索引不声称某个消费者唯一依赖其中一个创建者。

`SceneReferenceAnalysis` 在实际引用位置调用场景分析，分别报告缺少目标、仅可能存在、无法完整判断和不可达；未知类型、关系结构及预算不足单独报告覆盖不完整。索引遍历有 10,000 步预算和八层 Timeline 嵌套保护，达到上限保留已知事实并明确标记不完整。Timeline 轨道检查第 0 帧的目标可用性，事件在其执行前位置检查；诊断不是运行期每帧监控。

可选的操作影响报告通过比较前后场景快照得到，既比较剩余引用，也比较可达 Group 的出口状态。因此删除创建者、删除 hide/stop、同名输出的来源变化和跨 Group 后继均能进入影响结果；同批删除的消费者不作为外部断引报告。未知内容或分析不足不能被解释为没有影响。报告按需计算，Group 页面直接提交操作，不显示影响确认；Problems 从当前作者快照自动刷新引用警告，不要求先执行检查。场景推断警告不替代严格编译/构建的数据校验。

普通托管查询根据作者提交范围捕获不可变 Group 快照；已知 Entry 编辑只克隆受影响 Group，不在每次查询/IsCurrent 时序列化全项目。结构/未知范围和外部重载完整捕获，绕过作者服务直接修改 DTO 的调用必须显式通知文档服务。没有 journal 的独立查询保留快照比较回退。

分析复用入口和内容均相同的 Group 出口，并在变化组复用相同前缀检查点，每代最多 128 份检查点；新代不保留旧分析对象。Graph 固定点仍遍历可达节点，出口相等时不重复传播；循环预算与保守降级不变。最多保留 256 个位置查询；结果事实版本、写入方上下文版本和全局诊断来源版本分别使用。每次提交核对已有位置，因此不会因错过中间查询而复活旧 lease；缓存淘汰后的新查询也使用新版本。Timeline 继续核对自身根值、对象身份、帧和查询结果，无关编辑不会丢失现有数值输入。

`ProjectSceneTargets.Diagnostics()` 在项目当前作者/资源代次上生成带版本的结构化诊断。Problems 显式检查后显示这些警告，随后内容提交、撤销/重做及资源查询刷新更新场景诊断，保留作者位置和 JSON Pointer 供导航及检查使用。缺目标和不完整分析均不新增保存/编译门禁，也不清空、重绑或删除已有作者引用。

摘要与 Picker 使用相同来源描述适配。摘要的只读检查复用纯分析和前缀缓存，不占用交互选择 lease 的位置缓存，因此滚动/筛选大量条目不会仅因摘要读取淘汰已打开的选择。资源名后台准备与作者/查询版本分离，迟到的旧资源名称不会覆盖新资源代次；名称和语言更新不改变作者内容。

## 音频效果域

`SceneTargetResult.AudioEffects` 独立返回音频挂载候选，`AudioComplete` 独立于视觉/播放候选完整性。`AudioEffectKey` 包含 scope、targetId、instanceId，候选保留可能的创建来源和类型集合。它们不进入可动画场景对象列表。`SceneAuthoringSemantics` 的 `AudioEffect` 身份域同时供自动分配、输出隐藏、引用索引和复制重映射使用；同一字符串在不同挂载目标不串改，Track/Bus 声明 ID 与算法类型 ID 不参与实例重映射。

apply 创建/更新精确键；stop 删除单个精确键，all 显式清空一个目标；update 不创建对象、不改变类型或存在性。音源停止和混音音量修改保留挂载效果。分支合并确定集合取交、可能集合取并，并保留多来源/多类型；未知语义和预算耗尽降级完整性，未来创建者不会进入普通字段候选。未知算法/无效参数仅作为不完整的可能候选，不宣称 Runtime 成功创建。音频效果目录在无输出设备时也可用于创作。

`ProjectSceneTargets` 在同一项目 scope 上查询各域，并为音频结果维护独立 AudioRevision；写入方上下文继续共用 ContextRevision。配置目标变化重新分析。`SceneTargetCatalog` 适配类型名称、创建来源和 Track/Bus 过滤，复用来源描述及查询有效性检查；摘要检查不占交互位置缓存。音频字段使用 ComboBox 和共享数值字段，不在控件中扫描 Graph。普通输出身份隐藏；stop 的 all 状态由实例选择器原子写入，不独立展示一个容易冲突的开关。

参数类型来自 ISEffectCatalog；范围和默认值与契约/DSP 共用元数据。选择类型同时提交类型键和初始参数，为一次作者历史。stop/update 先选范围和目标，再列出直接挂载实例；Track 不显示所属 Bus 的挂载实例。同类多个效果按来源区分，类型歧义的 update 不生成猜测字段。参数编辑保留未改字段与未知 JSON；未知类型和失效引用不因刷新自动改选。

选择提交检查位置、结果版本和写入方上下文；相关修改使旧候选失效，撤销不会复活旧选择。更换更新目标时清空原参数 patch，避免把另一算法的参数带入新目标；参数字段的草稿随所选目标/实例/类型变化失效。该扩展未新增 Timeline 音频事件或音频参数动画。
