# Editor 项目文件操作

GUI 的文件操作进入项目统一内容历史，每次完整意图占一条记录。`ProjectFileAuthoringService` 接收创建文件/目录、导入、复制、移动、改名、删除和资源 metadata 修改请求；改名是指定完整目标路径的移动。项目文件面板和资源 Inspector 使用该入口，普通文本页共用项目作者状态、历史和保存事务。

## 文件面板

左侧树显示目录层级，右侧网格显示当前目录的文件与子目录。父项展开并生成子目录行时，先检查这些目录是否含有可见子目录；空目录、只有文件或只有隐藏/链接子目录的项不显示展开三角，刷新后重新判断。树选择、双击目录、地址栏内的目录块和项目相对路径导航使用同一当前目录；后退/前进与返回上一级分开。目录展开、选择、筛选和缩略图大小只影响视图，不产生内容历史。刷新保留未改变的网格项，避免监听通知打断选择或改名。

原生列表支持 Ctrl/Shift 多选；Enter 打开，F2 改名，Ctrl+C/X/V 使用项目内部剪贴板，Ctrl+D 创建副本，Ctrl+A 全选，Ctrl+F 定位全局搜索，Backspace 返回父目录，Alt+左右键前后导航。文本输入控件先处理自己的快捷键。右上搜索在整个可浏览项目中按文件名连续子串匹配，忽略大小写；不解析 `t:`。非空时显示圆形 × 按钮，清空搜索或点击该按钮时，有选中结果则导航到首个选中结果的父目录并保留选择，否则回到开始搜索的目录。类型筛选在查询接口中保留，目前没有类型或范围控件。当前不包含收藏夹、保存搜索或 Unity 资源导入管线。

可从文件网格多选后拖到网格中的目录、左侧目录树、地址栏中的目录块或当前目录空白处；Ctrl 拖放复制，普通拖放移动。原生外部文件/目录拖入或文件选择器导入使用复制。目标占用、跨类别和受保护入口由统一事务拒绝，不覆盖原内容；复制/导入碰撞时为副本生成不重复的名称。资源与 sidecar 组合显示，`.galnet`、版本控制、IDE、bin/obj 隐藏；Output/Temp 默认隐藏，但可通过相对目录路径查看。

地址栏默认显示可点击目录块，点击空白切换路径输入，Enter 导航，Escape 或失焦返回目录块。导入和创建通过右键菜单进入，“新建”二级菜单包含文件夹与文本；刷新位于底部缩略图滑条右侧。网格 tooltip 显示完整文件名。

删除先显示所选路径、关联 Group 和引用候选；确认后才执行。关联 Group 删除和候选字符串放行各自需要显式勾选；确定引用始终受保护。固定路径仍可浏览，并显示禁用操作原因。受 Graph 管理的 Group 打开专属页面，settings/graph 固定入口打开对应编辑界面；其他文件进入通用文件页。

## 普通文件页

项目拥有稳定文件 ID 和缓冲，Dock 页面只持有视图。关闭标签不会丢弃未保存文本，再次打开复用缓冲；移动/改名更新同一缓冲的路径与标题。删除使页面只读，撤销删除恢复工作文本和原先保存文本的各自版本。文本修改提交为一次项目历史操作，Save All 将其与 Graph/Group/settings 一起写盘；文件结构操作不会顺带保存文本草稿。保存后再撤销文件移动保留最新保存文本。

最多 2 MiB 的普通文本支持严格 UTF-8（有/无 BOM）、带 BOM 的 UTF-16 LE/BE 和 UTF-32 LE/BE。先验证解码后能逐字节往返，保留 BOM 与输入中的换行，不猜测其他编码或统一换行。已知二进制、无法确认无损编码、大文件、受保护文件和未绑定 Graph 的 Raw 源以只读信息/文本显示，并提供路径、大小和外部打开。孤立 Raw 的专属创作入口仍待 Group 编辑阶段。

Apply 或失焦提交输入，Cancel input 只取消当前输入；文本控件保留本地撤销。项目撤销和保存前提交有效输入，关闭项目时未保存缓冲参与脏检查。正在发布保存时，首次打开新的文件缓冲返回忙状态，避免将新身份加入旧捕获版本；已有缓冲可继续存在。跨重启不恢复这些标签或 Undo 栈。

监听发现文本被外部修改时保留当前缓冲并提示；保存和结构操作复核保存基线及目标不存在条件，拒绝覆盖外部文件。当前没有三方合并或交互式重载：需要关闭项目、核对两个版本后重新打开。

## 支持范围

| 路径 | 当前规则 |
| --- | --- |
| `Assets/**` | 原始文件与相邻 `.meta` 整体操作，禁止单独操作 sidecar；移动保留 ID，复制/导入分配新 ID |
| `Graph/**` | 仅在 Graph 内移动；受管理 Group 的 source path 同步修改，Group/Entry 身份不变；关联源删除需显式选择同时删除节点及关联边 |
| `I18n/<culture>/**`、`I18n/External/<culture>/**` | 同一文化子目录内操作，跨文化/内外源移动被拒绝；文化根和 catalog 受保护 |
| 其他项目内文件 | 原样保留字节与目录信息；不分析未知格式的内部语义 |
| `settings.json`、`Graph/graph.json`、`Assets`、`Graph`、`I18n` 根 | 固定入口，通过专属领域编辑，禁止普通文件改名/移动/删除 |
| `Contracts/`、`Output/`、`Temp/`、`.galnet/`、版本控制及 IDE 内部根目录 | 禁止普通文件修改 |

预检拒绝根路径逃逸、链接/重解析点、非法名称、自目录移动、目标占用、跨类别移动和批次目标冲突。选中父目录和它的子项时折叠成一次目录操作；Windows 支持仅修改大小写并恢复实际文件名拼写。空目录也参与撤销。

资源 metadata 通过项目的 `IResourceTypeCatalog` 与 `AssetMetaCodec` 处理，保留 Gallery 和未知扩展字段。移动保留 Gallery 身份；复制/导入时，已被项目或同批内容占用的 Gallery ID 为副本重新分配，保留 type/title，避免生成重复解锁身份。无法完整类型化的 metadata 拒绝重写；检查受影响资源与其他 sidecar 的 ID 冲突。Assets 索引仅负责读取、缩略图与通知，不在刷新/监听时创建或改写 metadata。

剧情资源字段只以 sidecar 的资源 ID 关联资源；名称、目录和扩展名不参与身份，不能在 ID 缺失时按同路径的新文件自动重新绑定。移动/改名保留资源 ID，复制/导入分配新 ID。已挂载的 Entry 资源字段和打开中的选择面板随资源代次刷新名称、路径和候选，保留当前 ID 与搜索条件；过期结果和旧候选不能提交。读取失败与确实缺失分别显示，不把索引错误表示为 Missing。

EditorAssetManager 每代共享一次资源索引任务，以 ID 查询并拒绝重复身份；调用者取消只结束自己的等待，失败索引允许重试。资源变更或项目切换推进代次，自定义 decoder/provider 注册保留，旧代在活动查询和资源租约结束后释放。选择器按代次和 ID 复用候选及缩略图，单面板最多缓存 128 张宽 128 像素的图片缩略图，其余显示图标；代次变化、解绑或销毁时取消旧加载并释放 bitmap。

## 文档与引用

文件结构操作立即发布。相同结构意图分别应用于工作版本与最近保存版本，磁盘只写变换后的保存版本，未保存文本不被顺带保存。Group source path 改变后仍使用同一会话文档；之后保存再撤销路径操作，保留刚保存的文本。放弃未保存内容不会撤销已完成的文件操作。详见 [历史与保存](editor-history-and-save.md)。

删除预检检查所有已加载作者 Group，包括没有打开页面的 Group。按字段 EditorId 声明识别的完整资源值匹配是确定引用，不能通过候选确认绕过。普通字符串/嵌套 JSON 的路径或 ID 匹配、工作版 settings、已跟踪文本缓冲的工作版和未被缓冲覆盖的磁盘 `UI/ui.json` 的匹配仅是候选；默认拒绝删除，调用者必须显式允许候选后才可继续。关联 Group 同批删除时忽略该 Group 自己的引用。此检查不代表能发现所有自定义格式引用，也不执行猜测性字符串重写。

CLI 的现有资产命令使用同一文件计划与发布机制，执行前加载并校验作者文档；Graph 等作者文件损坏时返回失败，保留文件。CLI 不保留 GUI 撤销记录，也不允许与文档命令混为一个批次。`UpdateReferences` 不再进行未知字符串的全局替换。

## 图片差分图集作者界面

Assets 文件面板可从当前或选中的图片目录创建 `.variants`，使用现有 CreateFile 事务生成描述及 sidecar。只读取已导入图片，按稳定顺序选择第一张作为显式 default，维度省略时由文件名推断；不在扫描时修复或补建图片 metadata。导入图片仍使用既有 Import 事务。

图集属性区提供只读相对路径与目录选择器、唯一的默认图 ComboBox、自动位置的只读 key 与可编辑显示名称，以及重新扫描按钮。移除默认图自由文本、维度增删/重排/重新推断、应用按钮和内嵌 JSON。数量、顺序和选项由图片文件决定，源 dimensions 仅保存位置的稳定 key/label；额外位置命名休眠保留，新位置自动推断。显示名称不参与剧情引用身份。

配置仍通过项目 `ProjectTextBuffer` 与内容历史提交：有效修改自动提交工作版本，保存全部负责写盘；失败保留草稿和诊断。未知 JSON 字段/坏结构保留原文并禁用类型化改写，可用通用文件入口修复。默认图失效时显示缺失名称，允许从现存图片中重新选择，不静默选择其他默认图。资源类型按扩展名或 sidecar 声明识别，支持图集描述被改为自定义扩展名。

扫描使用与编译相同的相对路径、metadata codec 和 Core builder，拒绝越界和链接。Assets 的文件监视器经防抖发出资源变更通知，Inspector 重新扫描；手动刷新使用相同路径。刷新不改写作者配置、不生成历史。预览保留请求与保护维度，失效时诊断并允许显式重置；分别展示请求、实际图和结果原因，候选削减链放入折叠详情。异步图片读取和旧预览行按代次失效，面板释放时释放 bitmap 并解绑事件。图片移动/改名继续由既有资源事务预检维护或拒绝无效关系。操作见 [图片差分图集](../manual/image-variants.md)。

移动描述文件或图片目录时，`folder` 按目标位置重算，并在同一结构事务中分别作用于工作内容和最近保存内容，包括已打开的图集文本缓冲。未保存配置不被顺带保存；保存后撤销/重做移动会重算当前配置的路径，保留最新保存的其他配置。预检分别验证工作版与保存版的资源关系，不能只验证磁盘快照。

## 事务、撤销材料与恢复

普通文件备份在 `.galnet/editor/history/<operation-id>/`，导入的重做读取保留副本，不再依赖外部源。文件复制和 SHA-256 通过磁盘/流处理，不将普通大文件整体读入托管内存；作者 JSON 和小型 sidecar 仍需要序列化。保留字节计入项目历史软预算，记录淘汰、redo 截断和项目关闭时释放。活动记录持有独占 owner lock；项目打开后清理已失去所有者的历史材料。Undo 栈不跨重启恢复。

每次正向、撤销和重做发布都复核当前文件哈希及目录状态，目标被外部内容占用时拒绝覆盖。文件与作者数据在同一 `.galnet/editor/transactions/<id>/` manifest 下暂存，记录文件哈希、目录前后状态和大小写改名中间路径。失败补偿后历史游标不变；补偿失败保留材料并禁止继续写入。打开项目先核对未完成事务，遇到未知外部内容停止恢复。事务内大小写中间对象也可在异常退出后恢复。

这不是跨进程隔离或断电原子性保证。文件 staging 当前在结构发布调用内同步执行，大型项目的交互性能仍需后续性能验收。

## 资源面板常用入口

导入、新建文本和新建文件夹在工具栏直接可见，原右键菜单仍可用。类型筛选与缩略图/列表视图只影响浏览；搜索明确覆盖整个项目。空目录、搜索或筛选无结果、读取错误分别呈现，不把加载失败当作空文件夹。排队刷新使用已捕获的项目内容服务，不在 scope 释放后重新解析服务。浏览与布局不进入作者历史。
