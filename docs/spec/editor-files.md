# Editor 项目文件操作

GUI 的文件操作进入项目统一内容历史，每次完整意图占一条记录。`ProjectFileAuthoringService` 接收创建文件/目录、导入、复制、移动、改名、删除和资源 metadata 修改请求；改名是指定完整目标路径的移动。现有 Assets 面板和资源 Inspector 已使用该入口，完整项目文件浏览及普通文本编辑页面尚未接入。

## 支持范围

| 路径 | 当前规则 |
| --- | --- |
| `Assets/**` | 原始文件与相邻 `.meta` 整体操作，禁止单独操作 sidecar；移动保留 ID，复制/导入分配新 ID |
| `Graph/**` | 仅在 Graph 内移动；受管理 Group 的 source path 同步修改，Group/Entry 身份不变；关联源删除需显式选择同时删除节点及关联边 |
| `I18n/<culture>/**`、`I18n/External/<culture>/**` | 同一文化子目录内操作，跨文化/内外源移动被拒绝；文化根和 catalog 受保护 |
| 其他项目内文件 | 原样保留字节与目录信息；不分析未知格式的内部语义 |
| `settings.json`、`Graph/graph.json`、`Assets`、`Graph`、`I18n` 根 | 固定入口，通过专属领域编辑，禁止普通文件改名/移动/删除 |
| `Contracts/`、`Output/`、`Temp/`、`.galnet/`、版本控制及 IDE 内部根目录 | 禁止普通文件修改 |

预检拒绝根路径逃逸、链接/重解析点、非法名称、自目录移动、目标占用、跨类别移动和批次目标冲突。选中父目录和它的子项时折叠成一次目录操作；Windows 支持仅修改大小写并恢复实际文件名拼写。空目录也参与撤销。

资源 metadata 通过项目的 `IResourceTypeCatalog` 与 `AssetMetaCodec` 处理，保留 Gallery 和未知扩展字段。无法完整类型化的 metadata 拒绝重写；检查受影响资源与其他 sidecar 的 ID 冲突。Assets 索引仅负责读取、缩略图与通知，不在刷新/监听时创建或改写 metadata。

## 文档与引用

文件结构操作立即发布。相同结构意图分别应用于工作版本与最近保存版本，磁盘只写变换后的保存版本，未保存文本不被顺带保存。Group source path 改变后仍使用同一会话文档；之后保存再撤销路径操作，保留刚保存的文本。放弃未保存内容不会撤销已完成的文件操作。详见 [历史与保存](editor-history-and-save.md)。

删除预检检查所有已加载作者 Group，包括没有打开页面的 Group。按字段 EditorId 声明识别的完整资源值匹配是确定引用，不能通过候选确认绕过。普通字符串/嵌套 JSON 的路径或 ID 匹配、工作版 settings 和当前 `UI/ui.json` 的匹配仅是候选；默认拒绝删除，调用者必须显式允许候选后才可继续。关联 Group 同批删除时忽略该 Group 自己的引用。此检查不代表能发现所有自定义格式引用，也不执行猜测性字符串重写。

CLI 的现有资产命令使用同一文件计划与发布机制，执行前加载并校验作者文档；Graph 等作者文件损坏时返回失败，保留文件。CLI 不保留 GUI 撤销记录，也不允许与文档命令混为一个批次。`UpdateReferences` 不再进行未知字符串的全局替换。

## 事务、撤销材料与恢复

普通文件备份在 `.galnet/editor/history/<operation-id>/`，导入的重做读取保留副本，不再依赖外部源。文件复制和 SHA-256 通过磁盘/流处理，不将普通大文件整体读入托管内存；作者 JSON 和小型 sidecar 仍需要序列化。保留字节计入项目历史软预算，记录淘汰、redo 截断和项目关闭时释放。活动记录持有独占 owner lock；项目打开后清理已失去所有者的历史材料。Undo 栈不跨重启恢复。

每次正向、撤销和重做发布都复核当前文件哈希及目录状态，目标被外部内容占用时拒绝覆盖。文件与作者数据在同一 `.galnet/editor/transactions/<id>/` manifest 下暂存，记录文件哈希、目录前后状态和大小写改名中间路径。失败补偿后历史游标不变；补偿失败保留材料并禁止继续写入。打开项目先核对未完成事务，遇到未知外部内容停止恢复。事务内大小写中间对象也可在异常退出后恢复。

这不是跨进程隔离或断电原子性保证。文件 staging 当前在结构发布调用内同步执行，大型项目的交互性能仍需后续性能验收。
