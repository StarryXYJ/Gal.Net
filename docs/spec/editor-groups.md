# Editor Group 编辑交互

Group 页面编辑项目会话中的作者条目，使用项目统一内容历史与 Save All。交互由 F-20261015-02 / P5a、P5b 验证，变量面板见 P5c，条目字段提交见 P5d，作者草稿保存见 P5e；共享 DTO 参数控件基础见 [Schema 字段表单](control.md#schema-字段表单)。P6b 接入普通复杂值表单，P6d 接入 Timeline Dock，P6e1 接入基础场景查询和属性轨道树，P6e2 接入关键帧画布和时间编辑，P6e2b 接入共用场景对象选择及 Timeline 两步添加对象/属性；未知 schema 的整参数 JSON 修改器、其余状态语义及曲线工具仍待后续切片。

## 条目字段提交

类型、条件和参数编辑通过项目级意图修改作者数据，再通知投影刷新；Workspace 不再监听 Entry PropertyChanged 补记历史。生成表单直接读取作者 JSON 并提交字段 patch；文本、资源与表达式专属控件按同一契约转换输入，提交后刷新。Parameters 字符串字典只是显示投影，不能通过修改返回字典绕过提交。

字段提交记录 Group ID、Entry 稳定 ID 和前后作者值，不持有页面或控件；类型与完整参数一次恢复，条件及未知 JSON 参数保留在快照中。相同值不增加历史，跨 Group 编辑按项目顺序撤销，关闭页面后仍能执行 Undo/Redo。新增条目复用项目级批量服务，不使用 Workspace 的事后闭包记录。

打开、重建或切换语言不清理作者参数，也不把默认值自动写成已提供值；缺省和显式 null 在内存及 Raw 文件中分开保留。表单在条目移除、换类型、页面关闭或项目关闭后失效；撤销删除/换类型不会让旧字段绑定重新获得提交权。局部参数提交保留 partial 校验，专属文本/资源/表达式字段也只更新自己的 JSON 值，不重解析其他作者参数。

GUI 使用仓库 Authoring 模式，允许缺必填参数、错误类型的参数值、未知类型/参数及未完成条件表达式保存重开；不会 Normalize、插入默认值或把未知内容静默删除。未知类型显示当前契约无编辑表单的提示；已知类型的未知参数显示保留提示。作者可以复制、换类型、撤销或保存，完整语义错误留待检查/编译修复。设置草稿和变量声明的既有规则不因此放宽。

作者模式仍拒绝损坏 JSON、重复 JSON 属性/稳定 ID、未知顶层或 Entry 信封字段、非对象参数、无效 Graph 拓扑及不安全/重复归属的源路径，并保留外部文件冲突检查。共享仓库默认 Complete，CLI 写入与 validate/group compile 继续完整校验；预览编译路径亦保持原有严格契约。保存草稿成功不等于能构建或运行游戏。

字段历史执行前检查当前作者值，发现外部变更则拒绝覆盖并保持历史游标。Entry 操作直接更新作者数据，成功后按 [作者内容提交通知](editor-history-and-save.md#作者内容提交通知) 同步投影；可观察列表不再写回作者文档。投影订阅者异常单独记录，不回滚已经提交的作者内容和历史。真正的内容操作失败仍按原历史补偿规则处理，补偿再次失败进入 RepairRequired。

Group 完整验证与构建共用一次编译分析。分析保留逐条目的参数/展开诊断，只在整个 Group 成功时提供编译文档和 SourceMap；CLI 单 Group 编译及项目构建直接消费本次结果，不重新展开同一份作者文档。原始 JSON 的结构检查与宽松作者草稿读取仍保留各自边界。

## 普通复杂值表单

### 属性行与常用专属编辑器

Group 的生成字段及资源、文本等专属字段使用统一 FieldEditorRow：宽面板为标签/值/操作三列，标题左上对齐，重置在第一行右侧；窄面板把值区移到下一行，标题与重置仍同行。错误只在存在时显示。Group 不显示常驻省略、null 和草稿恢复按钮；Escape 取消未提交输入，已提交内容使用项目 Undo。

有声明默认值时，重置显式写入默认值；无默认值的可选字段恢复缺省，必填且无默认值禁用并说明原因。普通字符串清空保存空字符串；可选数字等非字符串输入清空恢复缺省，必填无默认值的空草稿显示错误，不写成 0。清空可选资源选择恢复缺省。已有显式 null 不因打开/失焦变成缺省。这些简化策略属于 Editor，不改变 Sample 设置表单。

Builtins 的 Transform/ToTransform 通过成员注册展示位置 X/Y、角度和缩放 X/Y；LayerTransform 类型本身也有默认工厂，列表元素可复用。编辑按实际键名更新单个成员，保留大小写、未知字段和原有对象/JSON 字符串表示，不将视觉展开改为参数层级扁平化。缩放缺省为 1。源值异常时提供高级源码修复入口，正常结构不显示额外源码按钮。

颜色字段通过成员注册使用色块、十六进制输入与支持 alpha 的 ColorPicker。新值使用 `#RRGGBB` 或 `#AARRGGBB`，打开旧值不自动重写；非法输入保留草稿和错误。拾色器内改变颜色不写作者数据，确认一条项目历史，取消不写；外部值改变或字段失效取消旧选择。

Timeline 参数常态为“打开时间轴”及帧数/FPS/轨道数摘要。点击按当前字段来源的 Group/Entry 身份定位，选中对应 Entry 后激活项目单实例 Dock；关闭后可重开。缺省/null 不因打开创建空 Timeline，创建仍由 Dock 的明确动作完成；无默认定义的重置禁用。异常定义显示诊断并提供源码修复，旧绑定失效后不得导航。

生成 DTO 的对象字段按展开创建嵌套表单，常用一维数组/List 支持逐元素编辑、添加、删除与上下移动。三层 registry 在嵌套处仍有效；没有专属工厂时，没有 schema、字典、复杂转换器、超过八层或 200 元素的结构使用明确的多行 JSON 回退。成员覆盖与自定义类型工厂优先于显式 EditorId；无覆盖时显式 EditorId 决定常规工厂，不强行展开声明为 JSON 的字段。JSON 使用 Ctrl+Enter 或失焦提交，Escape 恢复未提交输入。

`effect.apply` 在 Group 条目行内只展示 shader `program` 资源选择；Inspector 保留适用的外层字段。选择了 program 时隐藏仅供内置效果工厂使用的 `id`；未指定 program 时显示 `id`。项目 shader 元数据可用时，Inspector 从 `@gal.effect` 参数声明生成数字、布尔、选项、颜色、向量与纹理字段，逐字段提交到原 `parameters` JSON 对象。`vec2`/`float2`、`vec3`/`float3`、`vec4`/`float4` 分别使用固定 2、3、4 个数值输入，提交时整体更新对应向量。选择 shader 后不再显示原始 JSON 参数编辑区；元数据不可用时显示提示。切换 program 只刷新表单，不自动写入默认值或删除旧参数；未知键及未修改成员保留，旧 program 的字段租约在选择或元数据更新后失效。未指定 program 的内置 effect 路径仍使用原参数编辑方式。`preset.speedLines` 与 `preset.impact` 的参数字段也使用同一 shader 元数据与字段控件，编译器接管的 `time`、`speed`、`flicker` 不列为自定义参数。`preset.motion` 的 Transform 与 `transition.reveal` 的 Center 分别使用已有 Transform 与二维向量控件。

`preset.shake` 和 `preset.impact` 各使用单个 `handleId`，通过共用场景目标选择器选取前文图层；多个目标由多个预设条目分别表达。仍保留 JSON 字段的明确范围：`video.play` 的跳过时间数组、粒子参数模块，以及没有 shader program 的内置 `effect.apply` 参数。跳过时间数组已有固定结构，可继续做专属列表控件；粒子参数按模块和曲线组织，需要独立的分组表单。其他 Transform、Variants 选择、Flipbook 和 Timeline 已由专属控件处理。

选中 shader 的 `effect.apply` Inspector 将预览区固定在底部，与上方字段滚动区分离，沿用图片资源 Inspector 的可调整分隔条和折叠预览。预览在 192×192 示例贴图上用当前 `program`、`parameters` 和声明的额外纹理，经游戏使用的 SkSL 编译与纹理效果路径离屏渲染；修改参数、切换 shader 或刷新资源会重新生成，过期生成结果不覆盖新选择。预览图片只属于 Inspector 会话，不写入作者数据或内容历史；shader 无法编译、资源缺失或参数值异常时显示诊断。

缺省、显式 null 与显式采用默认值在作者文档中独立保留；Group 操作入口按上述简化策略展示。短 DTO 对象默认展开，其余对象/列表可按需展开；组标题本地化，列表元素不重复显示 element 标签，控件按元素类型继续分派。展开不写默认值；对象局部编辑保留未知成员，按当前序列化配置使用实际属性名。每次成功提交通过原字段作者意图产生一条项目历史；列表结构变化取消旧索引绑定，Undo 不使旧绑定复活。折叠对象释放其子控件；Editor 的未提交字段草稿、已提交内容和历史仍属于项目会话。

共享表单不查询游戏状态；Timeline 专属会话使用独立的[场景目标查询](editor-scene-targets.md)。通用 Locator 字段、Timeline 曲线和其他复杂专属控件仍待后续切片。

## Timeline Dock

Timeline 是项目级单实例面板，打开后与资源、日志在底部同组；新用户的剧情布局按需打开，动画布局默认激活，可从查看菜单重新打开。它跟随当前活动 Group 页的活动 Entry，多选时使用最后活动项；无选择、普通条目和无效 Timeline 分别显示提示。聚焦工具面板不改变来源，关闭非活动 Group 页不会清除另一页的选择。

树只显示已有属性轨道、当前面板中选择的对象及等待初值的属性草稿。顶部“＋”仅打开场景对象选择器，卡片/搜索/确认与普通字段和 Assets Picker 使用相同组件，不包含属性或初值表单。确认对象后出现对象行；行左侧“＋”弹出尚未加入的属性列表，选择一个属性加入重载，随后直接在叶行编辑当前帧值和绝对/叠加模式。

属性当前值已知时，选择属性直接创建必要的第 0 帧和当前帧键，一次选择是一条项目历史；已经存在的属性不重复列出。值未知时先展示空值草稿行，明确输入数值后才创建轨道；绝对模式使用输入作为缺失的第 0 帧初值，叠加模式首帧为 0。新增属性时展开所属对象。只选对象、取消选择以及等待初值均不写空对象或不完整轨道，面板草稿不进入内容历史/持久化，切换 Entry 后清除；已提交轨道正常保存并支持撤销/重做。

对象、属性组和属性叶行右键打开“取消重载”菜单：属性移除自身轨道，对象/属性组移除全部后代轨道，整次操作只产生一条项目历史；Undo 整体恢复。空对象和等待初值的属性只移除面板草稿，不写历史。菜单捕获的旧树行在来源、帧或作者数据版本改变后失效，不能通过旧索引删除新的轨道。目标查询与字段适配见 [场景目标查询](editor-scene-targets.md#查询与选择控件)。

当前以对象→属性组→属性叶节点展示入口候选及已有轨道；显示创建来源和一定/可能存在，未解析引用保留为编号，不显示底层 handle。属性来自 Core 已声明能力，折叠与选择不进入内容历史，播放头变化保留折叠状态。帧输入不修改作者数据；叶值使用 NumericUpDown，Enter 或失焦确认，Escape 恢复未确认输入。当前帧有键时只更新值、保留切线和插值；没有键时按帧序插入，继承原区间插值和曲线导数。每次确认产生一条项目内容历史，可跨页撤销、保存和重开，未知 JSON 成员保留。

统一从对象行“＋”添加属性，从右键菜单取消重载；不提供属性勾选、可添加属性模式或更换对象按钮。添加未知初值属性后，确认叶值写入必要的 0 帧与当前帧键，当前帧为 0 时只建一键；绝对模式采用已知初值，否则明确输入值同时用于第 0 帧；偏移模式非零帧创建时首键为零。不因获得焦点或初始化绑定建轨道，重复对象/属性不会新增。

每个叶属性的模式下拉框始终显示“绝对值 / 叠加偏移”。已有轨道切换模式只修改整条轨道的混合方式，保留所有键的数值、插值、切线和未知字段，产生一次项目历史；不自动换算基础值。绝对值不满足已知属性范围时拒绝切换并显示错误。未建轨道时只是本地创建选项，不因选择模式自动建轨道。

缺失或 null 的 timeline 仅在明确点击创建后写入空定义；打开或选择不会补默认值。切换条目、帧、类型，关闭面板、相关根值或场景事实改变会取消旧行输入并使其失效；撤销删除不会使旧行恢复提交权。保存、场景事实和根值均未变的无关更新及切换语言保留当前本地输入。项目拥有会话和已提交历史，面板关闭只取消本地输入。

属性树按展开状态生成可变高度的可见行（普通行 38、叶属性展开额外增加 176 的值图区域），与右侧关键帧画布共用纵向滚动；折叠父行显示后代关键帧汇总，汇总可选择和拖动：移动该汇总点所在时间的所有后代键，包括折叠隐藏的子项，其他时间的键不变。拖动沿用单历史、首帧和碰撞保护。时间区域支持缩放条、水平滚动条、Ctrl+滚轮锚定缩放及 Shift+滚轮平移；拖动顶部标尺时只重绘播放头预览线，松手后定位并更新属性采样一次，不在每个鼠标移动事件中重建属性行。Escape、捕获丢失、换来源或版本失效取消预览；点击同样在释放时定位，仅改变编辑帧。

画布支持单选、Ctrl 多选、框选、整帧横向拖动、Delete 删除、Insert/按钮在当前帧加键及上一键/下一键定位。加键使用所选键的轨道，或左侧最后点击的属性轨道；已有键只选中，不重复写入。拖动只更新预览，松手一次提交项目历史；越过结束帧时自动延长，撤销同时恢复所有选中键和结束帧。Escape、源变化或捕获丢失取消旧手势。0 帧键不能移动或删除，负帧及整数溢出拒绝；目标碰撞保持非法预览，需明确替换碰撞键或取消，不能覆盖 0 帧键。

结束帧与 FPS 使用 NumericUpDown，Enter 或失焦各自确认，Escape 恢复未确认草稿。FPS 修改保留帧号与切线，只改变播放速度；结束帧下限为最后一个关键帧或事件，输入更小值时钳制到下限，不删除内容。没有保留秒数、应用或裁剪按钮，也不保留旧重定时/裁剪路径；同帧事件顺序和未知 JSON 保留，一次确认一条历史，无变化不增加历史。整体时间缩放另作后续明确操作。

每个已重载属性都有展开按钮，展开后在该属性下显示内联值曲线，与原时间轴共用横坐标、播放头、选择和横向缩放/滚动；下方属性随同一行高移动，左侧当前帧值仍可编辑。图形纵坐标表示值，Ctrl 多选后拖动按相同时间/值增量移动所选键，保留键之间的差值。选中 Hermite 键后显示存在的入/出切线柄；Alt+滚轮按鼠标处数值缩放，Alt+拖动平移值域，“适应值域”包含 Hermite 区间极值。这些摄像机/展开状态不写作者历史，值域不钳制既有 overshoot。

右键未选关键帧会先选中它，右键已选关键帧保留多选集合。菜单提供出段 Step/Linear/Hermite、双侧/入侧/出侧切线模式（自由、平坦、线性、自动贝塞尔）、联动/断开及“编辑数值…”弹窗。固定独立详情区已移除；弹窗使用 NumericUpDown 精确输入值、入/出切线，可按秒显示斜率，混合值留空。Enter/失焦确认，Escape 恢复未确认草稿；批量设绝对值与曲线增量拖动是不同动作。任一已知绝对属性端点不满足范围就整批拒绝，不在 Editor 单方面新增区间极值拒绝规则。

曲线键/柄拖动只更新本地预览，松手一条项目历史；Escape、捕获丢失、选择/帧/条目/源版本变化取消旧手势。非法曲线手势释放时取消，不隐式覆盖碰撞键；普通时间轴仍保留原显式碰撞替换。第 0 帧可改值和切线，不能横移或删除。未知 JSON、同帧事件顺序和根字段大小写保留；保存重开及跨页面撤销/重做保持作者内容。

键的 Editor 专用 `editorTangents` 保存 incoming/outgoing（Free/Flat/Linear/Auto）和 linked；运行时继续消费原有值/帧斜率，不解释编辑模式。修改值或增删/移动邻键时，自动/线性/平坦派生斜率与当前动作在同一 patch 中重算；无模式的键默认自由且断开，打开页面不补写。平坦为零；线性采用各自相邻段斜率；自动使用前后邻键中心斜率，局部极值为零，其他内部键限制在相邻同号斜率较小绝对值的三倍内，端点用相邻段斜率。此为非加权自动贝塞尔，保存的是 Hermite 等价斜率，不宣称复制其他产品的内部算法。

单侧模式选择会断开联动；联动先取已有入/出斜率平均并转自由模式，之后手动拖柄/精确输入同步另一侧。Step/Linear 保留未使用的切线与模式，切回 Hermite 可继续使用；非有限导数拒绝整批修改。切线保存单位为值/帧，按秒显示乘 FPS，改 FPS 保留原始斜率。旧菜单/弹窗草稿在来源改变后不能提交，保存和切语言保留有效草稿。

曲线绘制直接调用 Core TimelineSampler；精确内部关键帧采用自身值及出段语义，包括前段为 Step 的情况，不通过绘制时偏移帧号绕过采样边界。

偏移是叠加值：基础 X 为 100、轨道值为 20 时结果为 120；普通模式的轨道值 20 表示目标 X 为 20。FPS 例如将 60 改为 30，第 60 帧仍是第 60 帧，从第 1 秒变成第 2 秒。Timeline 内复选框及说明垂直居中，数字框长按上下按钮在 250ms 后以 30ms 间隔重复，单次步长不变。

没有候选或既有轨道时提示先在前文创建场景对象，无效作者内容可通过条目 JSON 修复。事件、加权曲线与其他剩余语义仍待后续；实时场景预览不在阶段计划中。内联曲线和切线验证见 [P6e3](../../features/F-20261015-02-editor-authoring-workspace/phase-6e3.md)。此前验证记录见 [P6d](../../features/F-20261015-02-editor-authoring-workspace/phase-6d.md)、[P6e1](../../features/F-20261015-02-editor-authoring-workspace/phase-6e1.md)、[P6e2](../../features/F-20261015-02-editor-authoring-workspace/phase-6e2.md)。

## 类型选择

行内类型选择器、顶部插入选择器和 Space 快速插入共用 EntryTypePicker。弹窗打开后清空旧查询并直接聚焦搜索框；按当前语言显示名、原英文 ID 忽略大小写匹配，叶项同时显示显示名与英文 ID，缺译回退为 ID。语言切换重新筛选当前查询，不修改作者内容。

内置常用类型提供轻量全拼/首字母别名，自定义 EntryTypeOption 可传 SearchAliases；没有泛化汉字转写、模糊拼音或多音字推断。当前支持的内置别名见 picker 的 SimplePinyin 表，不能据此承诺任意类型均能拼音查询。

输入改变后清除高亮。首次 Up/Down 均选首个叶结果，之后前后移动并在边界停住，跳过分类标题，滚动到高亮结果；Enter 确认高亮，鼠标点击叶项确认。没有高亮或没有结果时 Enter 不提交，Escape/外部关闭不修改条目。IME 有预编辑文本时先交给输入法。搜索框中的文字按键用于查询，不执行原单字母类型快捷键；原类型快捷键仅在选择器非搜索状态使用。

行内确认只修改当前条目的类型与参数，完整意图为一条历史，Undo 恢复原类型和全部原参数。插入选择器用明确确认事件触发新增，不能监听 SelectedValue 改变来新增，因此重复选择同一类型仍可连续添加。

## 添加、追加与快速插入

顶部排列为添加条目、追加条目、数量、插入类型选择器，窄窗口允许换行；原底部数量/追加区域已移除。

- 添加条目按数量在所选条目后插入，无选择时追加末尾；追加条目按数量始终在末尾添加。数量取 1–1000 的整数。
- 直接确认顶部类型或 Space 弹窗时只新增一条，与数量无关。新建后选中新项，批量新增选中最后一项并滚动到可见区域。
- 普通按钮使用已确认的插入类型，初始为 dialogue.text；契约不含该类型时先打开选择器，保留原按钮的数量与添加/追加意图。不会默认创建 catalog 第一项。
- 每次插入在条目加入列表前确定类型和参数，分配新稳定 ID，批量一条项目历史；Redo 复用该次操作保留的身份。

弹窗打开时捕获稳定插入锚点，切换焦点不会改变锚点。目标在弹窗期间被删除时取消此次插入并提示；以该行作为 Popup target 时，控件自动关闭也会清理待执行意图。没有选择的追加不依赖旧末项的存活，确认时取当前末尾。

列表或 Group 编辑区自身获得键盘焦点时，Space 在所选条目附近打开插入选择器；无选择时先滚动到列表尾部再打开。关闭快速插入恢复列表焦点。文字/数字/条件输入、按钮、ComboBox 和已有 picker 先处理自己的按键；不从其他 Dock 页抢占空格。Shift+A 和 Ctrl+Shift+A 沿用添加/追加入口，数量规则相同。

## 选择、折叠与拖放

列表内容末尾有约 64 DIP 可滚动留白，不使用伪条目占位。点击列表背景取消选择；行内控件、工具栏、滚动条不误取消，其他 Dock 页不会通过全局点击监听清除此页选择。无选择时后续新增从末尾开始。

参数展开状态由页面按 Entry StableId 保存，通过投影的 IsParametersExpanded 驱动行与拖动预览；它不进入作者 JSON、内容历史或 dirty。移动事件不重新配置字段表单，避免拖动/重排重建参数控件。拖放、重排和同页 Undo 保留折叠，面板重新打开默认展开，不跨重启保存。

关闭/重建列表容器不改变条目稳定身份。条目序号仅为展示顺序，重排后可重新编号，不能作为插入锚点或折叠状态的 key。持久化与失败撤销规则见 [历史与保存](editor-history-and-save.md)。

## 多选与剪贴板

列表支持 Ctrl 点击增减选择、Shift 点击连续范围、Ctrl+A 全选；最后活动项作为添加/粘贴锚点，复制与删除按列表顺序处理。背景或 Escape 清空选择，无选择时粘贴追加末尾。工具栏直接插入后选中新项；粘贴/副本选中新插入的全部条目。

右键菜单及快捷键提供复制 Ctrl+C、剪切 Ctrl+X、粘贴 Ctrl+V、创建副本 Ctrl+D、删除 Delete。文字、数字、条件输入保留本地快捷键，菜单不覆盖这些控件自己的编辑菜单；右击未选中的行先单选该行，右击已选中的行保留集合。行内删除按钮仅删除该行，Delete/菜单删除处理当前集合。

剪贴板为 GalNet.Entries / Version 1 JSON，最多 1,000 条和 16 MiB UTF-8 文本；与 Graph 剪贴板区分。复制保留作者参数 JSON、条件、条目顺序和省略/显式 null，粘贴及副本产生新稳定 ID，不猜测或替换 JSON 中的普通字符串。GUI 粘贴保留目标契约暂不支持的类型/字段，以作者草稿保存；格式错误或超限仍整批拒绝。Graph 复制也保留所含 Group 的未知或不完整条目；当前不提供未知 schema 的通用 JSON 编辑。

粘贴、批量删除和所选集合移动各为一条项目历史。多选时拖动其中一项会按原相对顺序移动整个集合；拖动未选中项先单选该项。折叠状态沿用稳定 ID，不随集合移动展开。Undo 恢复删除项的原位置，Redo 复用本次粘贴的身份；页面关闭不影响这些项目历史。

剪切等待系统剪贴板写入成功后只标记待移动，不删除原条目、不记内容历史；工具栏和原条目显示标记，Escape 或取消移动撤销标记。成功粘贴时以一条历史重排或跨 Group 移动，保留场景输出和播放身份。目标 Group 有 Entry ID 冲突时只分配新的作者 Entry ID，提交结果包含双向地址迁移，Undo/Redo 使用同一组确定的身份。过期、其他项目或重复粘贴票据按普通复制并提示；观察到其他剪贴板内容时取消原移动凭据。剪贴板写入失败或等待期间来源变化保留原条目，变化后再 Undo 成相同 JSON 也不复活旧凭据。异步粘贴使用开始操作时的稳定锚点，锚点删除时拒绝；页面销毁或换绑后不执行晚返回。

嵌套字段提交仍经过根字段的值契约与宿主 partial 校验；其他已有子值使整个对象无法类型化时，失败诊断会显示高级源码入口，可切换 JSON 模式一并修复，当前不绕过根值校验。

## 常用字段与 Inspector

“显示图层”的翻页动画使用列数、行数、总帧数和从 0 开始的当前帧数值输入框；总帧数不能超过网格容量。仅在明确提交时修改对应成员，保留原有字段大小写与未知 JSON 成员；无效旧数据保留高级修复入口。静态图片无需配置此字段，连续播放由 Timeline 的 `flipbook.index` 轨道驱动。

音频播放、停止、队列操作、音效处理及带语音文本的音轨字段统一使用 ComboBox，候选来自当前项目音轨配置，显示名称与 ID，提交音轨 ID。项目设置变化会刷新候选；既有未配置 ID 保留显示，不因打开表单或刷新候选自动替换作者值。

Group 页面默认在行内展示 DTO 标记为 Common 的根字段，折叠后保留内容摘要。选中与展开独立；单击条目选择，展开箭头不隐式更改作者选择。条件在完整 Inspector 编辑，非空条件在行内显示摘要。工具栏支持内容/类型/条件搜索、输入显示序号定位，以及全部展开/折叠；搜索结果重排按当前作者顺序映射，不把过滤后的索引当作原始索引。

Inspector 为活动条目创建自己的字段控件和绑定租约，显示 Group、条目序号、类型、条件及完整可见参数。锁定时保留目标并持续显示锁定状态；日志、Timeline、Problems 等无自身 Inspector 的辅助工具不会清空作者详情。关闭 Group 页面使原页面字段绑定失效，锁定的 Inspector 使用自己的绑定；项目草稿不随页面释放。多选只沿用已有批量操作，不隐式批量修改详情参数。

详情跟随 Dock 的标签激活和面板焦点：从资源区返回已处于活动状态的 Group，仍会恢复条目 Inspector。后台资源/节点选择刷新不抢走当前详情；无 Inspector 的辅助工具也不替换用于解锁恢复的最近作者目标。

字段草稿、源冲突和校验问题通过条目问题标记及 Problems 面板可见。Problems、变量引用和节点查找使用稳定作者身份导航；失效目标不按旧行号重定向。完整参数仍保留未知类型/参数提示，不因 Common 筛选丢弃作者数据。

## 直接编辑与问题诊断

Group 页面上的删除按钮、Delete 键、右键删除、移动粘贴以及换类型直接执行，不显示场景影响确认窗口。保留原消费者引用，引用缺失、目标不可用及分析不完整等诊断在 Problems 中随作者修改、Undo/Redo、资源更新和项目重开自动刷新，无需先点击检查。诊断提供稳定作者身份导航及条目问题标记，不自动弹窗或改绑引用。

准备操作仍绑定原 Graph 文档实例及 Graph/Group 作者内容，提交时在现有历史串行门内检查来源，拒绝过期或重复消费的计划。成功执行是一条现有内容历史，保留输入归档及 Undo/Redo。影响报告按需计算，普通页面操作不预先计算引用变化。

作者编辑允许暂时不完整。Problems 的检查入口提供完整作者校验；现有编译、内容构建及调试准备继续拒绝确定的契约、参数或结构错误。场景静态推断诊断仍为警告，不直接作为编译门禁，避免将分支、未知扩展等不确定性当作确定错误。活动输入冲突、归档写入失败等已有数据保护继续生效。

换类型通过统一语义目录按逻辑输出角色、身份域和目标种类迁移相容身份；字段名不同也可相容，例如普通层 handleId 与转场 newHandleId/toLayerHandleId，普通动画 playbackHandleId 与 Timeline 根播放身份。新增或不相容角色分配新身份，不自动改绑旧消费者。旧参数仍由类型变更历史保留以支持 Undo；旧表单失去提交权。引用规则见 [场景目标查询](editor-scene-targets.md#作者关系与引用诊断)。

## Entry 输入归档与恢复

Entry 作者操作删除目标、换类型或跨 Group 移动时，将相关未提交输入存入项目输入恢复区，并撤销旧输入的提交权；Undo 新增/粘贴时移除目标也走同一路径。同 Group 重排保留现有输入。归档为中立地址、类型、字段路径、根值基线、原始文本及校验状态，不保留旧控件或 ViewModel。

归档和恢复请求不参与 Save All。撤销恢复作者内容后，Problems 提供恢复按钮及可复制的原始文本；作者明确请求后，由新字段绑定核对来源、类型、路径、字段类型和根值基线后接收。尚未打开或展开的子字段继续留在恢复区，真正恢复为活动输入后才重新参与保存。已有源冲突的归档不能直接恢复，但可以复制或明确丢弃。

输入恢复文件位于 `.galnet/editor/input-archive.json`，独立于游戏作者文件和撤销栈，保存项目、清空历史及关闭重开均保留。默认最多 1,000 条且序列化不超过 16 MiB；不足时在修改作者内容前拒绝操作，Problems 提供查看/复制/丢弃。载入时发现恢复文件损坏则保留原文件并阻止需要写入的新归档，不静默覆盖。普通活动草稿及直接源冲突仍遵守原保存门禁。

整 Group 删除、撤销 Group 创建及文件树删除关联 Group 也归档目标的未提交输入。结构服务先完成等待、候选和双版本校验，再在实际同步发布边界捕获最新输入；归档失败不会开始作者文件发布。文件删除准备提交其他有效草稿时，明确排除即将归档的 Group 输入，因此目标中的无效文字不会先阻止删除。Working/Saved 继续分别恢复，Undo 不自动激活归档输入。

作者 incarnation 只随删除、换类型和离开原 Group 等作者生命周期变化推进；页面关闭只释放字段表单，不推进作者代次，因此常用字段与 Inspector 的有效草稿仍跨页面共享。旧控件不会因 Undo 恢复提交权。历史与恢复协议见 [历史与保存](editor-history-and-save.md#entry-输入草稿与保存反馈)。

## 派生呈现与对象释放

搜索声明依赖类型、摘要、条件和显示序号；这些属性改变以及 Undo/Redo 时，已挂载的筛选列表重新求值。摘要和场景 Picker 共用来源描述：显示资源名、Group/Entry 来源或未解析提示，不直接展示输出/目标 handle。资源名称在后台读取，最多缓存 512 个名称、并发准备 64 项；资源刷新使旧准备失效，关闭项目取消准备。语言和标签变化只刷新呈现，不推进作者历史或取消有效输入。

活动 Group 投影拥有活动 ViewModel。移除后只留有限弱缓存（每 Group 最多 512 个 Entry、项目最多 64 个已退出 Group），用于仍被借用对象的短期复用；Undo 可以从中立 DTO 重建。文档服务也只弱跟踪退出的 Group 文档，仍有外部持有者时保持其文档身份。项目输入仓库弱持有干净字段，强持有未完成输入；输入记录通过中立作者数据和项目适配提交，不长期强持有 ViewModel。清空或淘汰历史不会隐式丢弃归档文字，已删除的 ViewModel 即使历史尚在也可回收。

Problems 的旧检查结果保留过期状态，删除目标的旧错误不再展示为活动条目问题；归档恢复提示不计入活动错误数。场景诊断继续按当前作者版本刷新。
