# Editor Group 编辑交互

Group 页面编辑项目会话中的作者条目，使用项目统一内容历史与 Save All。交互由 F-20261015-02 / P5a、P5b 验证，变量面板见 P5c，条目字段提交见 P5d，作者草稿保存见 P5e；共享 DTO 参数控件基础见 [Schema 字段表单](control.md#schema-字段表单)。P6b 接入普通复杂值表单，P6d 接入 Timeline Dock，P6e1 接入基础场景查询和属性轨道树，P6e2 接入关键帧画布和时间编辑，P6e2b 接入共用场景对象选择及 Timeline 批量添加/更换对象；未知 schema 的整参数 JSON 修改器、其余状态语义及曲线工具仍待后续切片。

## 条目字段提交

类型、条件和参数编辑通过项目级意图修改作者数据，再通知投影刷新；Workspace 不再监听 Entry PropertyChanged 补记历史。生成表单直接读取作者 JSON 并提交字段 patch；文本、资源与表达式专属控件按同一契约转换输入，提交后刷新。Parameters 字符串字典只是显示投影，不能通过修改返回字典绕过提交。

字段提交记录 Group ID、Entry 稳定 ID 和前后作者值，不持有页面或控件；类型与完整参数一次恢复，条件及未知 JSON 参数保留在快照中。相同值不增加历史，跨 Group 编辑按项目顺序撤销，关闭页面后仍能执行 Undo/Redo。新增条目复用项目级批量服务，不使用 Workspace 的事后闭包记录。

打开、重建或切换语言不清理作者参数，也不把默认值自动写成已提供值；缺省和显式 null 在内存及 Raw 文件中分开保留。表单在条目移除、换类型、页面关闭或项目关闭后失效；撤销删除/换类型不会让旧字段绑定重新获得提交权。局部参数提交保留 partial 校验，专属文本/资源/表达式字段也只更新自己的 JSON 值，不重解析其他作者参数。

GUI 使用仓库 Authoring 模式，允许缺必填参数、错误类型的参数值、未知类型/参数及未完成条件表达式保存重开；不会 Normalize、插入默认值或把未知内容静默删除。未知类型显示当前契约无编辑表单的提示；已知类型的未知参数显示保留提示。作者可以复制、换类型、撤销或保存，完整语义错误留待检查/编译修复。设置草稿和变量声明的既有规则不因此放宽。

作者模式仍拒绝损坏 JSON、重复 JSON 属性/稳定 ID、未知顶层或 Entry 信封字段、非对象参数、无效 Graph 拓扑及不安全/重复归属的源路径，并保留外部文件冲突检查。共享仓库默认 Complete，CLI 写入与 validate/group compile 继续完整校验；预览编译路径亦保持原有严格契约。保存草稿成功不等于能构建或运行游戏。

字段历史执行前检查当前作者值，发现外部变更则拒绝覆盖并保持历史游标。投影通知失败会恢复原作者值和投影；恢复再次失败进入 RepairRequired。

## 普通复杂值表单

生成 DTO 的对象字段按展开创建嵌套表单，常用一维数组/List 支持逐元素编辑、添加、删除与上下移动。三层 registry 在嵌套处仍有效；没有 schema、字典、复杂转换器、超过八层或 200 元素的结构使用明确的多行 JSON 回退。显式 EditorId 仍优先决定普通工厂，不强行展开声明为 JSON 的字段。JSON 使用 Ctrl+Enter 或失焦提交，Escape 恢复未提交输入。

缺省、显式 null 与显式采用默认值是独立操作，按字段 required/nullable/default 决定可用入口。展开不写默认值；对象局部编辑保留未知成员，按当前序列化配置使用实际属性名。每次成功提交通过原字段作者意图产生一条项目历史；列表结构变化取消旧索引绑定，Undo 不使旧绑定复活。折叠对象释放其子控件与未提交草稿，已提交内容和历史仍属于项目会话。

共享表单不查询游戏状态；Timeline 专属会话使用独立的[场景目标查询](editor-scene-targets.md)。通用 Locator 字段、Timeline 曲线和其他复杂专属控件仍待后续切片。

## Timeline Dock

Timeline 是项目级单实例面板，默认与资源、日志在底部同组，可从查看菜单重新打开。它跟随当前活动 Group 页的活动 Entry，多选时使用最后活动项；无选择、普通条目和无效 Timeline 分别显示提示。聚焦工具面板不改变来源，关闭非活动 Group 页不会清除另一页的选择。

树默认显示已有属性轨道和当前面板中选择的对象；“显示可用属性”可额外展示尚未创作的候选。顶部“＋”仅打开场景对象选择器，卡片/搜索/确认与普通字段和 Assets Picker 使用相同组件，不包含属性或初值表单。确认对象后出现对象行；行左侧“＋”弹出尚未加入的属性列表，选择一个属性加入重载，随后直接在叶行编辑当前帧值和绝对/叠加模式。

属性当前值已知时，选择属性直接创建必要的第 0 帧和当前帧键，一次选择是一条项目历史；已经存在的属性不重复列出。值未知时先展示空值草稿行，明确输入数值后才创建轨道；绝对模式使用输入作为缺失的第 0 帧初值，叠加模式首帧为 0。新增属性时展开所属对象。只选对象、取消选择以及等待初值均不写空对象或不完整轨道，面板草稿不进入内容历史/持久化，切换 Entry 后清除；已提交轨道正常保存并支持撤销/重做。

父对象行的“更换对象”整体替换该对象下的轨道引用，保留键、插值、切线和未知 JSON；目标必须支持全部现有属性，且不能与已有对象产生重复属性轨道。不静默删除或合并轨道，整批替换是一条项目历史。打开弹窗取消未确认的数值输入和画布手势，但保留点击行的挂载状态；位置或作者内容改变后旧弹窗失效。目标查询与字段适配见 [场景目标查询](editor-scene-targets.md#查询与选择控件)。

当前以对象→属性组→属性叶节点展示入口候选及已有轨道；显示创建来源和一定/可能存在，未解析引用保留为编号，不显示底层 handle。属性来自 Core 已声明能力，折叠与选择不进入内容历史，播放头变化保留折叠状态。帧输入不修改作者数据；叶值使用 NumericUpDown，Enter 或失焦确认，Escape 恢复未确认输入。当前帧有键时只更新值、保留切线和插值；没有键时按帧序插入，继承原区间插值和曲线导数。每次确认产生一条项目内容历史，可跨页撤销、保存和重开，未知 JSON 成员保留。

勾选属性创建轨道，取消勾选明确移除轨道，均为一次可撤销操作。未加入轨道的叶值确认也可直接创建：一次写入必要的 0 帧键与当前帧键，当前帧为 0 时只建一键；Replace 有唯一有效初值时采用该初值，否则提示将输入值同时用于第 0 帧。偏移模式在非零帧创建时从零偏移开始。没有明确初值时勾选拒绝且恢复未勾选显示，要求先输入数值；不因获得焦点或初始化绑定而建轨道。重复对象/属性轨道不会新增。

每个叶属性的模式下拉框始终显示“绝对值 / 叠加偏移”。已有轨道切换模式只修改整条轨道的混合方式，保留所有键的数值、插值、切线和未知字段，产生一次项目历史；不自动换算基础值。绝对值不满足已知属性范围时拒绝切换并显示错误。未建轨道时只是本地创建选项，不因选择模式自动建轨道。

缺失或 null 的 timeline 仅在明确点击创建后写入空定义；打开或选择不会补默认值。切换条目、帧、类型，关闭面板、相关根值或场景事实改变会取消旧行输入并使其失效；撤销删除不会使旧行恢复提交权。保存、场景事实和根值均未变的无关更新及切换语言保留当前本地输入。项目拥有会话和已提交历史，面板关闭只取消本地输入。

属性树按展开状态生成固定高度的可见行，与右侧关键帧画布共用纵向滚动；折叠父行显示后代关键帧汇总，汇总可选择，移动需展开到属性行。可隐藏未加入轨道的属性。时间区域支持缩放条、水平滚动条、Ctrl+滚轮锚定缩放及 Shift+滚轮平移；拖动顶部标尺时只重绘播放头预览线，松手后定位并更新属性采样一次，不在每个鼠标移动事件中重建属性行。Escape、捕获丢失、换来源或版本失效取消预览；点击同样在释放时定位，仅改变编辑帧。

画布支持单选、Ctrl 多选、框选、整帧横向拖动、Delete 删除、Insert/按钮在当前帧加键及上一键/下一键定位。加键使用所选键的轨道，或左侧最后点击的属性轨道；已有键只选中，不重复写入。拖动只更新预览，松手一次提交项目历史；越过结束帧时自动延长，撤销同时恢复所有选中键和结束帧。Escape、源变化或捕获丢失取消旧手势。0 帧键不能移动或删除，负帧及整数溢出拒绝；目标碰撞保持非法预览，需明确替换碰撞键或取消，不能覆盖 0 帧键。

结束帧与 FPS 使用 NumericUpDown，Enter 或失焦各自确认，Escape 恢复未确认草稿。FPS 修改保留帧号与切线，只改变播放速度；结束帧下限为最后一个关键帧或事件，输入更小值时钳制到下限，不删除内容。没有保留秒数、应用或裁剪按钮，也不保留旧重定时/裁剪路径；同帧事件顺序和未知 JSON 保留，一次确认一条历史，无变化不增加历史。整体时间缩放另作后续明确操作。

关键帧详情区支持单选/多选的值、出段 Step/Linear/Hermite、入/出切线。未选择时禁用并保留布局空间，避免框选或拖动中画布跳动；混合值显示为空，输入后统一设置所有选中键。数字 Enter/失焦确认，Escape 恢复未确认草稿，插值选择立即确认。一次批量修改是一条项目历史；批量设值时，任一已知属性端点范围不满足就整批拒绝。首帧可改值/切线，仍不能移动或删除；切到 Step/Linear 不清理切线，切回 Hermite 继续使用原值。

切线保存单位为值/帧；“按秒显示”按当前 FPS 换算为值/秒，显示选项不写作者数据。平坦（入/出均 0）、线性（相邻区间斜率）、平滑（前后邻键连线斜率，端点用相邻区间）、对齐（当前入/出斜率平均）为一次性操作，会切换选中键的出段为 Hermite，不持久化自动切线模式。非有限导数拒绝整批修改。改 FPS 不换算已保存的值/帧，按秒显示相应变化。旧详情在换选择、帧、根文档或项目后失效；保存和切换语言保留有效草稿。图形曲线与拖柄仍待 P6e3b。

偏移是叠加值：基础 X 为 100、轨道值为 20 时结果为 120；普通模式的轨道值 20 表示目标 X 为 20。FPS 例如将 60 改为 30，第 60 帧仍是第 60 帧，从第 1 秒变成第 2 秒。Timeline 内复选框及说明垂直居中，数字框长按上下按钮在 250ms 后以 30ms 间隔重复，单次步长不变。

没有候选或既有轨道时提示先在前文创建场景对象，无效作者内容可通过条目 JSON 修复。事件和曲线/切线工具仍待后续；实时场景预览不在阶段计划中。验证记录见 [P6d](../../features/F-20261015-02-editor-authoring-workspace/phase-6d.md)、[P6e1](../../features/F-20261015-02-editor-authoring-workspace/phase-6e1.md)、[P6e2](../../features/F-20261015-02-editor-authoring-workspace/phase-6e2.md)。

## 类型选择

行内类型选择器、顶部插入选择器和 Space 快速插入共用 EntryTypePicker。弹窗打开后清空旧查询并直接聚焦搜索框；按当前语言显示名、原英文 ID 忽略大小写匹配，叶项同时显示显示名与英文 ID，缺译回退为 ID。语言切换重新筛选当前查询，不修改作者内容。

内置常用类型提供轻量全拼/首字母别名，自定义 EntryTypeOption 可传 SearchAliases；没有泛化汉字转写、模糊拼音或多音字推断。当前支持的内置别名见 picker 的 SimplePinyin 表，不能据此承诺任意类型均能拼音查询。

输入改变后清除高亮。首次 Up/Down 均选首个叶结果，之后前后移动并在边界停住，跳过分类标题，滚动到高亮结果；Enter 确认高亮，鼠标点击叶项确认。没有高亮或没有结果时 Enter 不提交，Escape/外部关闭不修改条目。IME 有预编辑文本时先交给输入法。搜索框中的文字按键用于查询，不执行原单字母类型快捷键；原类型快捷键仅在选择器非搜索状态使用。

行内确认只修改当前条目的类型与参数，完整意图为一条历史，Undo 恢复原类型和全部原参数。插入选择器用明确确认事件触发新增，不能监听 SelectedValue 改变来新增，因此重复选择同一类型仍可连续添加。

## 添加、追加与快速插入

顶部排列为添加条目、追加条目、数量、插入类型选择器，窄窗口允许换行；原底部数量/追加区域已移除。

- 添加条目按数量在所选条目后插入，无选择时追加末尾；追加条目按数量始终在末尾添加。数量取 1–1000 的整数。
- 直接确认顶部类型或 Space 弹窗时只新增一条，与数量无关。新建后选中新项，批量新增选中最后一项并滚动到可见区域。
- 普通按钮使用已确认的插入类型，初始为 dialogue.text；契约不含该类型时先打开选择器，保留原按钮的数量与添加/追加意图。不会默认创建 catalog 第一项。
- 每次插入在条目加入列表前确定类型和参数，分配新稳定 ID，批量一条项目历史；Redo 复用该次操作保留的身份。

弹窗打开时捕获稳定插入锚点，切换焦点不会改变锚点。目标在弹窗期间被删除时取消此次插入并提示；以该行作为 Popup target 时，控件自动关闭也会清理待执行意图。没有选择的追加不依赖旧末项的存活，确认时取当前末尾。

列表或 Group 编辑区自身获得键盘焦点时，Space 在所选条目附近打开插入选择器；无选择时先滚动到列表尾部再打开。关闭快速插入恢复列表焦点。文字/数字/条件输入、按钮、ComboBox 和已有 picker 先处理自己的按键；不从其他 Dock 页抢占空格。Shift+A 和 Ctrl+Shift+A 沿用添加/追加入口，数量规则相同。

## 选择、折叠与拖放

列表内容末尾有约 64 DIP 可滚动留白，不使用伪条目占位。点击列表背景取消选择；行内控件、工具栏、滚动条不误取消，其他 Dock 页不会通过全局点击监听清除此页选择。无选择时后续新增从末尾开始。

参数展开状态由页面按 Entry StableId 保存，通过投影的 IsParametersExpanded 驱动行与拖动预览；它不进入作者 JSON、内容历史或 dirty。移动事件不重新配置字段表单，避免拖动/重排重建参数控件。拖放、重排和同页 Undo 保留折叠，面板重新打开默认展开，不跨重启保存。

关闭/重建列表容器不改变条目稳定身份。条目序号仅为展示顺序，重排后可重新编号，不能作为插入锚点或折叠状态的 key。持久化与失败撤销规则见 [历史与保存](editor-history-and-save.md)。

## 多选与剪贴板

列表支持 Ctrl 点击增减选择、Shift 点击连续范围、Ctrl+A 全选；最后活动项作为添加/粘贴锚点，复制与删除按列表顺序处理。背景或 Escape 清空选择，无选择时粘贴追加末尾。工具栏直接插入后选中新项；粘贴/副本选中新插入的全部条目。

右键菜单及快捷键提供复制 Ctrl+C、剪切 Ctrl+X、粘贴 Ctrl+V、创建副本 Ctrl+D、删除 Delete。文字、数字、条件输入保留本地快捷键，菜单不覆盖这些控件自己的编辑菜单；右击未选中的行先单选该行，右击已选中的行保留集合。行内删除按钮仅删除该行，Delete/菜单删除处理当前集合。

剪贴板为 GalNet.Entries / Version 1 JSON，最多 1,000 条和 16 MiB UTF-8 文本；与 Graph 剪贴板区分。复制保留作者参数 JSON、条件、条目顺序和省略/显式 null，粘贴及副本产生新稳定 ID，不猜测或替换 JSON 中的普通字符串。GUI 粘贴保留目标契约暂不支持的类型/字段，以作者草稿保存；格式错误或超限仍整批拒绝。Graph 复制也保留所含 Group 的未知或不完整条目；当前不提供未知 schema 的通用 JSON 编辑。

粘贴、批量删除和所选集合移动各为一条项目历史。多选时拖动其中一项会按原相对顺序移动整个集合；拖动未选中项先单选该项。折叠状态沿用稳定 ID，不随集合移动展开。Undo 恢复删除项的原位置，Redo 复用本次粘贴的身份；页面关闭不影响这些项目历史。

剪切先等待系统剪贴板写入成功，再删除原条目；写入失败或等待期间原条目发生变化则保留原条目并提示。异步粘贴使用开始操作时的稳定锚点，锚点删除时拒绝；页面销毁或换绑后不执行晚返回。操作失败保持错误反馈，相关提示与历史标题支持四语。

嵌套字段提交仍经过根字段的值契约与宿主 partial 校验；其他已有子值使整个对象无法类型化时，需要切换 JSON 模式一并修复，当前不绕过根值校验。
