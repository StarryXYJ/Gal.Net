# 快速开始

从下面选择目标；命令均在仓库根目录运行，除非页面另有说明。源码与发行包的能力以各自版本为准。

1. **先体验游戏**：[检查环境](requirements.md)，然后[运行自带 Sample](run-sample.md)。无需先创建项目。
2. **制作自己的剧情**：[创建第一个项目](first-project.md)，完成编写、检查和外部玩家调试，再导出内容。
3. **开发引擎或工具**：[首次源码构建](build-from-source.md)介绍启动 Editor 和 CLI；完整验证见[构建与测试](../manual/development/build-and-test.md)。
4. **已有发行包**：完整解压后启动；纯 Sample 还需要匹配的游戏内容，参见[发行包说明](run-sample.md#使用发行包)。
