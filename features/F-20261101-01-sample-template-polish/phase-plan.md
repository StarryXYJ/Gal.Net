# 快速通道阶段计划

P1/P2/P3 verified（范围内），2026-11-01；完整回归的既有失败、延期平台与本机 Browser 哈希差异保留在执行记录和总结。P1 因公开便利入口和时长属性转普通 feature 流程，接口决策见 design.md。每个切片取得证据后单独提交；没有扩大到公开包拆分或全局契约变更。实际证据见 [execution.md](execution.md)。

## P1：统一启动接线与项目视觉策略

前置：实现授权；核实无需公共 API 变更的可行路径，否则转普通设计。

目标：项目命令不重复准备/启动协议，项目选择加载与公告展示时长。涉及 Sample 命令/组合、GameLaunchFlow 和 PlayerSurface 的现有接线。

验证：新游戏/继续/读档的顺序；准备取消、切页失败与等待收束；项目业务前后动作；默认/自定义时长；确认期间公告抑制及焦点/输入恢复。优先沿用已有 Presentation/Integration 回归，新增测试只覆盖本轮边界。

文档：更新实际接入说明和执行证据，不提前改正式规范。

退出条件：默认行为保持，运行协议仅一份，改变项目展示时序不要求改内置机制，无新增失败。

## P2：统一普通游戏与重播布局来源

前置：P1 verified。

目标：同一项目布局选择覆盖普通游戏和重播，状态与运行生命周期分别拥有。

验证：替换游戏视图后两个入口均使用该布局；主游戏 state/VM 与重播不相同，普通页面工厂与运行 surface 身份一致；重播关闭、启动取消与 scope 释放不重复释放、不影响玩家进度。包含实际场景渲染和现有 Gallery 定向回归。

文档：记录项目创建入口与独立状态约束。

退出条件：没有重播绕过布局选择的硬编码路径，没有额外公共工厂框架，相关生命周期和渲染用例通过。

## P3：独立包消费与收尾

前置：P2 verified；确认当前发布/锁图参数。

目标：同一个 Sample 可按明确文件清单复制到仓库外，无需手改项目 XML 构建和定制。

依赖核查：按 [依赖分析](dependency-review.md) 检查根 Import、中央版本、平台 targets/native 与 Branding 资源；以实际 Desktop 外壳证明可交付。核实并验证移除未使用 LibVLCSharp.Avalonia 与中央 Markdown 版本残留的候选，保留真实使用的媒体核心。补充此次闭包边界断言；不扩大到 Editor 并行改动或公开调试/后端拆包。

验证：使用真实同版本本地包，在仓库外复制规定文件后还原/构建；无引擎 ProjectReference；标题按钮、命令、新页面、配色/局部模板和游戏布局定制；Player/Developer 依赖隔离、locked restore 和严格契约闭包。按实际受影响平台运行构建及原生定向 smoke，不重新承诺已延期的设备验收。

文档：更新 Sample README、定制手册及实际涉及的 spec；生成 summary.md，区分新增失败、既有失败和未验证；自审与 diff 检查后提交。

退出条件：复制/构建步骤可复现，单一应用源码和项目/内置边界保持，必要测试/发布检查及文档齐全。未取得证据的项保留真实状态。
