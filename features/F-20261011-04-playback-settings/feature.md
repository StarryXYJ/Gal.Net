# 玩家快速与自动播放、追帧跳过和分类设置

## 原始目标与已确认需求

2026-10-12 工具栏交互补充：自动/快速仅选中时显示背景，再次点击取消；其他工具栏按钮平时透明，悬浮淡色背景、按下背景加深。三布局与三配色统一使用主题色。

2026-10-12 范围收敛：用户明确 Editor 不用管。后续仅实现 Sample 的宿主接入及所需共享能力，不继续扩展 Editor 设置或把 Editor 接入作为验收前置；保留已完成改动，不擅自回退工作树。

游戏页面提供互斥的快速模式、自动模式 ToggleButton，以及带确认提示的跳过按钮。快速模式完整显示文本，按可配置间隔推进，可跳过的阻塞快速完成；自动模式正常播放，当前阅读单元需要等待的呈现全部结束后才开始自动间隔。跳过沿当前剧情路径追帧到下一段未读文本或下一个选项。

设置采用分类列表及类型化配置项，分类内部切换使用 TabControl 或等价的局部选择，不加入页面导航历史。默认分类为游戏、画面、音频、控制，开发者可以增删分类和设置项，各主题统一提供设置 UI。控制/快捷键功能以后另做，本期不显示无功能的空分类。

用户已确认：

- 2026-10-11 补充：不考虑向后兼容；删除旧接口/旧格式适配，不迁移旧已读数据。其他项目兼容代码经确认仅用于历史格式后可清理；正常扩展与平台能力不属于兼容层。

- 勾选“快速模式仅限已读文本”时只允许已读文本快速；不勾选时已读、未读均可快速。
- int 与 int range 合并为整数设置项，double 与 double range 合并为浮点设置项，通过编辑方式成员区分 Slider / NumericUpDown。
- Step 只是操作调整步长，不参与合法性校验，不要求值是 Step 的倍数。
- Choice 候选项变化导致当前值失效时回退默认值。
- 可见性、可用性与原因说明可动态变化；原因保存本地化 key。
- 不使用 AutoSettingUI。
- 原语分别处理 Normal / Quick / CatchUp 调用；快速和追帧可由基类回退正常调用，不重复执行逻辑。
- 自动等待采用动态 IsAutoBlocking 与状态变化事件；Engine 按实例 identity 维护阻塞集合，清空后在有效推进边界开始间隔。无需文本与语音配对。
- 接受类型化值访问、主题模板、自定义编辑控件、验证/应用/保存职责、开发者默认值与强制值区分等前期讨论结论。

## 当前问题与事实

- Engine 在 dispatch `dialogue.text` 时标记已读，尚无运行时 `IsRead` 消费者；需要避免当前句的本次写入改变快速资格，并覆盖 NVL 文本。
- 编译文档已经具有源条目派生的字符串 ID，但 Runtime Entry.Id 为顺序整数；当前已读记录使用该整数。需核对内容加载边界并保留稳定身份，防止插入条目后错配进度。
- 对白与 NVL 打字结束后仍 blocking，等待推进；只有 blocking/completed/skippable 状态无法直接表达自动计时起点。
- 当前音频原语立即完成，语音播放结束没有参与自动推进等待；需补齐关联播放的结束/失败/停止通知语义。
- `GameSettings` 有自动间隔、快速间隔、SkipMode 预留字段，但没有播放策略消费者。
- 当前设置服务提供扁平的 Choice / Range 设置列表；Sample 仅恢复和持久化语言、文本速度。
- 三个内置主题分别拥有普通页面和游戏工具栏布局，普通设置模板由主题提供。
- F-20260929-15 的追帧存档方案已暂缓，没有统一原语追帧实现。本 feature 使用向前跳过的追帧语义，不恢复该存档方案。

## 范围

### 播放模式与输入

- 单一播放模式状态保证手动、快速、自动互斥；两个 ToggleButton 允许均未选中。
- 快速模式完整显示当前文本，跨过文本内部手动 skip 分段；对可跳过阻塞使用其明确定义的完成语义，不可跳过阻塞按声明等待或停止。
- 快速间隔以阅读单元为单位，不在每条即时 primitive 后添加间隔。
- 自动模式不主动截断正常呈现。当前阅读单元的文本、关联语音和其他声明参与等待的有限播放都结束后，才开始自动间隔。
- 循环 BGM、长期动画、持续粒子等不因全局仍在运行而阻止自动推进；选项不被自动选择。
- 所有原语具备明确的正常、快速、追帧及自动等待语义；可由共享能力/默认规则覆盖，不要求每个原语重复配置全套模式参数。
- 在游戏交互范围内左键操作取消旧快速/自动状态，并取消其待执行计时。点击模式按钮后仍能开启该按钮选择的新模式。
- 模式、计时和旧运行续跑在读档、退出、会话替换、运行结束等生命周期边界正确取消。

### 已读与追帧跳过

- 已读跨会话持久化，不随存档槽回滚；普通对白、NVL 和语音文本编译结果均正确关联文本身份。
- 当前句快速资格基于进入前的已读事实；遇到未读文本且限制开启时停止快速并正常呈现。
- 跳过按钮首先确认，再沿真实剧情路径追帧，停在未读文本、选项或剧情结束；当前已是未读文本时不越过该句。
- 追帧执行必要的变量、条件分支、解锁及场景逻辑；压缩中间等待和呈现，到达目标后同步最终展示。
- 向前追帧与存档历史恢复区分：不能照搬旧 replay-save 的“变量已恢复，跳过写入”规则。
- 跳过使用固定的未读/选项停止边界，不受“快速模式允许未读”偏好解除限制。
- 自定义外部动作和不可跨越边界具有明确语义；不能无声明地丢弃动作或强行完成。
- 长路径与循环执行可取消且不会冻结 UI；确认提示及进度/错误展示使用主题与本地化资源。

### 分类设置契约

- 设置服务提供只读的设置分类列表；分类包含稳定 ID、名称 key 和设置项列表，组合完成后结构固定。
- 设置项具有稳定 ID、名称/说明 key、类型化值访问、默认值、验证与变更通知；类型信息从实际值类型推导。
- 内置整数、浮点、字符串、布尔、Choice 和操作项，并提供自定义编辑项。
- 整数/浮点设置包含最小值、最大值、Step、编辑方式及必要的单位/格式；Step 不参与合法性校验。整数保持整数值，浮点拒绝非有限值。
- Choice 支持 enum 与动态候选项。当前值失效回退有效默认值；动态默认值失效的处理在设计阶段明确，禁止回写无效值。
- 开发者能增删/重排分类和设置项，并设置默认值、范围、固定策略和可修改权限。
- 隐藏或删除设置项只影响修改入口；开发者强制值应覆盖此前保存的玩家偏好。
- 设置项支持动态可见性、可用性和本地化原因 key；状态变化通知 UI，避免仅保存委托而没有刷新机制。
- 可采用状态计算委托并统一返回可见/可用/原因；具体依赖与通知 API 在设计文档确定。依赖源变化后自动刷新，解除订阅与会话销毁对应。
- 禁用原因通过可用的悬浮提示展示，触摸/键盘场景也可读取；隐藏项不占布局，不产生悬浮提示。
- 修改值经验证、应用、通知和持久化；应用失败不把尚未生效的值当作成功配置，提供本地化错误反馈。
- 玩家偏好独立于剧情存档；当前快速/自动开启状态属于运行会话，不持久化为偏好。

### 设置 UI 与宿主能力

- 每个主题根据设置类型和数值编辑方式提供 UI 模板；可复用设置行及编辑控件，并支持主题覆盖。
- 统一使用现有 GalNet 主题画刷、尺寸和本地化能力；分类切换是设置页局部状态。
- 普通设置模型不保存 Avalonia 控件；自定义控件工厂位于 Avalonia 展示边界，每次创建独立编辑控件并处理绑定及资源生命周期。
- 主题统一承载自定义项的名称、说明及验证错误；工厂支持主题/服务上下文，不能绕过配置验证与保存。
- 未知设置类型或缺失模板应提供明确诊断，不静默漏项。
- 游戏分类提供语言、文本速度、仅已读快速、快速间隔、自动间隔。
- 画面分类由宿主能力提供窗口、无边框全屏、支持时的独占全屏，以及适用的窗口尺寸/分辨率；不支持的功能按能力隐藏或禁用。项目设计分辨率与窗口/显示分辨率区分。
- 音频分类提供实际生效的主音量、BGM、音效、语音和静音设置，正确组合玩家音量与内容/轨道增益。
- 设置依赖变化应刷新可用性，例如全屏模式下窗口尺寸的可修改状态。

## 非目标

- 2026-10-11 用户已授权继续直到实现；阶段与验证见 [phase-plan.md](phase-plan.md)。
- 不恢复或改造 replay-save 存档格式；正式完整快照模型继续保留。
- 不实现快捷键编辑、冲突检测和控制映射；仅为未来控制分类留扩展能力。
- 不引入 AutoSettingUI，不要求使用 Ursa；可借鉴 enum selector 的交互逻辑，具体依赖需设计时评估。
- 不实现运行期主题切换，不把 Avalonia、窗口或原生媒体类型引入 Core/Runtime。
- 不对所有平台承诺相同的全屏/分辨率能力，也不以失效控件冒充已实现功能。

## 验收标准

1. 快速与自动互斥，左键取消和模式按钮启动均有效，无迟到计时推进、重复推进和跨旧会话推进。
2. 快速文本完整显示、间隔有效，已读限制开启时第一次遇到的文本不会因 dispatch 标记变为可跳过。
3. 文本与语音同时播放时，在两者及当前单元其他等待完成后才开始自动间隔；媒体失败/停止不造成永久等待，长期播放不阻止推进。
4. 跳过必须经过确认，沿实际条件路线推进，变量和解锁结果正确；在未读文本或选项处停止并呈现正确场景，可取消长路径执行。
5. 已读包含 ADV/NVL，跨会话和读档保留；条目位置变化不导致把另一句错误识别为已读。
6. 三个主题提供分类设置、所有内置编辑类型和自定义项承载；开发者可追加分类、删除配置项或覆盖模板。
7. Step 只改变调整步长，合法范围内不符合步长倍数的值仍能接受。Choice 失效后回退有效默认值并同步运行值与 UI。
8. 可见性/可用性依赖改变时自动刷新；禁用原因可本地化并由鼠标、键盘或触摸用户访问，隐藏项不占布局。
9. 玩家偏好恢复、应用、保存和错误反馈一致；强制值不会被旧偏好绕过。画面/音频配置在支持的宿主实际生效。
10. Runtime、Builtins、设置、主题及宿主集成的关键行为得到比例适当的验证；Sample 与 Editor 预览保持可用，正式文档在实现验证后同步。

## 约束、假设与设计阶段待定

- 需求校验没有必须先向用户追问的冲突；详细设计见 [design.md](design.md)，状态进入 design，下一阶段为 Phase Plan。
- 已确认无需音文配对；阅读边界 metadata 只用于未读前停止，BatchId 继续表示手动 skip 分组。
- 设计选择：剧情区域点击取消旧模式并执行一次手动推进，工具栏仅执行按钮操作；无效默认 Choice 明确禁用/诊断，等待候选/default 提供者修正；旧数字已读格式明确拒绝，不迁移、不修改旧文件。
- 其余时序、原语默认回退、媒体 ticket、追帧状态同步与设置生命周期边界在 design.md 中说明，属于设计选择而非已实现事实。
- 当前工作树中已有用户对 `src/Samples/GalNet.Sample.Avalonia/App.axaml.cs` 的修改，本 feature 建立时未触碰。
