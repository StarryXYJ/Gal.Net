# Group 直接编辑修订（2026-10-26）

用户确认删除、换类型、移动不再逐次弹窗；临时引用问题集中在 Problems，确定的作者错误由编译/构建拒绝。

## 实现

- Group 删除、换类型和待移动粘贴直接提交，删除影响确认窗口及页面确认回调。
- 保留作者快照/版本校验、单条历史、身份迁移、输入归档及撤销重做；可选影响报告延迟到显式读取时计算。
- Problems 在创建时即查询场景诊断，并随内容、资源和外部重载更新，不要求先执行检查；保留原消费者引用和稳定身份导航。
- 场景静态分析继续提供警告，不将未知扩展、条件/分支等不确定性变成编译错误。现有严格参数、契约及结构校验仍用于编译、构建和调试准备。

## 验证

- 本轮交互与引用核心用例 2 项通过：删除、换类型、跨 Group 移动、即时问题标记、Undo/Redo、保存重开，以及既有准备计划过期/重复提交拒绝。
- Shared 校验、契约编译及引用分析 34 项通过，包括无效参数不能编译或替换既有产物。
- Editor 全量回归 325 项通过，包含前述 2 项核心用例；加 Shared 共 359 项通过。原生 GUI 未执行，`git diff --check` 通过。
- 全量运行较慢，首次无超时上限的运行主动中止后，以 45 秒无进展超时重跑，最终 4 分 48 秒完成，未触发挂起保护。
- 默认输出目录因运行中的 Editor 锁定而构建失败，改用 `-p:OutputPath=bin/GroupNoDialog/` 完成编译。沙箱中的 testhost 连接超时，调整为允许本地测试进程通信后核心用例和 Shared 测试执行通过。
