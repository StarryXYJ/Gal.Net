- 当前帧查询描述当前 Timeline 第一次正向行程，先事件后轨道纯采样；不运行游戏、不调用 presenter。事件前对于已跟踪属性不猜测上一显示采样值。Additive 与事件基值存在未覆盖组合时明确清除该属性唯一值并提示不完整。

- 事件对象 Locator 使用所属 Group/Entry、输出槽位和事件身份（有 editorId 使用它，否则按声明输出槽位/不透明输出身份定位），不依赖数组下标；作者界面仅显示创建帧/资源/来源。尚未创建的候选明确显示未来帧、可能存在且没有当前数值。
- 属性新增的第 0 帧初值来自第 0 帧查询，当前显示值来自当前帧；不把中途事件之后的值误写为第 0 帧基值。未解析/不完整作者 JSON 保留，不因查询写回默认值。

## P6e4b：事件作者界面

状态：verified（2026-10-20，保留已独立复现的两项 Group 布局基线失败），依赖 a。独立事件行、有限类型选择器、添加/移动/多选/删除和同帧排序；详情复用 DTO 生成面板，字段 Locator 使用事件前位置；新增创建者身份、raw patch 和未知 JSON 保留、每次手势单历史及草稿/过期保护。这里才交付事件的 UI 新增和编辑，不将查询入口冒称事件编辑器。

事件行按帧及同帧作者顺序显示，每个事件占一行，复用共享画布的选择/框选/整帧拖动；与轨道共用缩放、横向位置和播放头。允许多事件位于同帧，不套用属性键的碰撞替换。右键提供编辑、同帧提前/延后及删除；未知事件可移动/删除并保留原 JSON，但不冒充受支持类型编辑。新增在当前帧、同帧末尾插入，输出身份和 editorId 在显式新增时生成。事件详情是可取消的 DTO 草稿，应用一次提交全部字段；切换源、帧、撤销或关闭使草稿失效，查询/打开不写内容。拖到末尾外自动延长且和移动合为单历史，拖到负帧拒绝。
