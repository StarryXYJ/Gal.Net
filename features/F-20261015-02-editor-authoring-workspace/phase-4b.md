# P4b：项目文件界面与文本页

日期：2026-10-17。状态：verified。

## 已实现范围

- 用户确认行为参考 Unity，采用左目录树/右当前目录网格；树懒加载，地址栏内目录块、相对路径、前进/后退、返回父目录共用导航状态。全项目文件名连续子串搜索和缩略图大小为视图状态；刷新复用未改变的网格对象，保留选择与改名输入。
- 原生 Ctrl/Shift 多选，F2 改名、Enter 打开、Ctrl+A/C/X/V/D、Ctrl+F 与 Alt+左右/Backspace。网格/树目录、地址栏目录块与当前目录空白接收项目内移动、Ctrl 复制和外部导入；剪贴板属于项目会话。改名失焦提交，避免 Enter 与失焦重复执行。副本自动生成唯一名称，资源分配新 ID，Gallery 冲突身份另行分配，保留其 type/title 和 metadata 扩展。
- 普通文件/目录创建、复制粘贴、移动、改名和删除共用 P4a 事务。删除显示路径/关联 Group/引用候选，关联节点删除及候选放行各自确认，确定引用仍拒绝。固定路径显示原因，隐藏 sidecar/内部目录；Output/Temp 默认隐藏，可通过相对路径查看。
- managed Group 双击进入原专属页，settings/graph 进入对应界面。其他文件进入可关闭/浮动的文件页；同一会话 ID 复用标签。文件路径变动同步缓冲和页标题，页面关闭只释放视图，项目缓冲继续参与保存、关闭脏检查与撤销。
- 文本在项目作者聚合中持有稳定 ID/path/存在状态/字节，进入 Working/Saved、克隆、恢复快照及同一次作者文件事务。提交输入只改变工作版；保存后撤销移动保留最新保存文本。删除分别保留两版字节，已删除内容不产生虚假的 dirty，撤销恢复正确两版。
- 严格 UTF-8（有/无 BOM）与带 BOM 的 UTF-16/32 LE/BE；限制 2 MiB，先核对逐字节往返，保留 BOM 与输入换行。二进制、未知编码、大文件、固定入口及孤立 Raw 源只读，提供路径/大小与外部打开。外部变更保留缓冲并显示错误，保存/移动/Undo 核对基线和目标占用；没有三方合并或热重载。
- 项目 index 捕获固定根，watcher/timer 排队事件在关闭后不再读取全局 Current。首次打开新缓冲与发布互斥，拒绝把新文件身份加入正在保存的旧捕获。新的菜单、历史与错误四语均接入。

- 地址栏空白处切换手输，Enter 导航、Escape/失焦退出；创建与导入使用右键，新建为二级菜单，底部滑条右侧刷新。文件 tooltip 显示全名。搜索非空时显示圆形 ×，清空后进入首个选中结果的父目录（保留选择），无选择则回原目录；类型接口保留但不解析 t:。
