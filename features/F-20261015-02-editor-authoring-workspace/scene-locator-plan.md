# 场景定位器复用与 Timeline 对象入口

日期：2026-10-18。状态：planned。用户要求确认场上目标定位器复用时间，并补充 Timeline“＋”选择目标/属性、新增动画对象及更换定位器的交互。本记录调整依赖顺序，不声称控件已实现。

当前 P6e1 已提供 SceneLocator（Group/Entry/输出槽位）、SceneTarget 和 ProjectSceneTargets.Before 查询，没有可复用的作者场景目标选择控件。资产选择的数据源是文件/资产，场景目标是某次创建的实例；同一图片创建的两个对象必须可区分。候选展示可复用，身份和查询域分别适配。

## P6e2b：场景定位器与对象选择

**前置**：P6e2 及交互简化 verified。先于 P6e3 曲线编辑，从 P6e4 提前提取当前已支持目标的选择闭环，不等待 Timeline 事件或全部自定义语义。

**目标与模块**：统一候选选择与解析服务，共享 Avalonia 候选展示控件不依赖 Editor 业务服务；普通字段 binding 与 Timeline 适配器提交同一种选择结果。通过特定 DTO 成员的语义注册接入，不能给所有 string 注册目标选择器。首批覆盖现有查询支持的层/粒子/效果及目标字段；新增播放实例与 Timeline 帧内查询仍留 P6e4。

**选择行为**：可搜索资源名/对象名、类型和创建来源，显示一定/可能存在；查询当前条目执行前的状态。内部以 Locator 识别创建者输出并解析 handle，作者无需看到或输入 handle。不同创建实例分开列出；未解析引用保留并允许重选，刷新不清空参数；不支持语义显示候选可能不完整。

**Timeline“＋”**：打开“添加动画对象”弹窗，目标字段复用该定位器，可在弹窗内换目标；下方勾选支持的属性及必要初值/模式。确认后一次创建所选属性轨道，父对象行由轨道分组形成；至少选一个属性，不新增无轨道对象的运行时数据结构。取消不写内容，重复对象/属性不重复创建。树默认展示已添加对象/轨道，可用属性通过“＋”及现有显示选项进入。

**更换对象**：父对象行提供入口，复用同一定位器；一次更新该组轨道目标，保留帧、值、插值、切线与未知字段，一次撤销整体恢复。候选需支持全部已有属性，且不产生重复目标/属性；不静默删轨道或合并数据。新增/替换取消旧手势，提交检查原目标身份和作者版本。

**验证**：普通 DTO 字段与 Timeline 共用组件/查询；同资源多实例、跨 Group、两类存在性、搜索/四语、未解析引用、生产者删除/重排/复制、候选更新/过期确认；真实“＋”/取消/批量创建/更换对象/重复防护、单历史及保存重开。按变更运行 Editor/Shared/Presentation/Architecture/Integration 回归和解决方案构建。

**风险与退出**：避免把资产文件当作场上实例，或仅换输入框外观仍要求作者理解 ID。至少一个普通 Entry 字段和 Timeline“＋”/更换对象完成真实选择→提交→撤销→保存重开的同一服务闭环；共享层无 Editor 依赖，旧引用无静默丢失，并有验证证据。

后续顺序：P6e2b → P6e3 曲线/切线 → P6e4 事件/剩余语义 → P6f animate 曲线 → P7 验收。实时游戏预览不纳入。
