# 演出库扩展与通用文本卡

## 用户目标与授权

用户要求通过 feature 实现前文讨论的 Effect、SEffect、转场和预设，并在 GameTestCase 加入案例。翻页与描边明确延期。已完成需求讨论，用户授权设计、计划、代码、测试及必要文档修改。

## 范围

- Shader：位移/波纹/热浪、径向/缩放模糊、胶片、色差/故障/扫描线、像素化、局部聚光。
- 遮罩：矩形/圆角矩形/椭圆/眼睑/图片、反向、羽化、颜色、不透明度、位置、尺寸与旋转；覆盖式与目标裁切区分。默认只覆盖场景，可显式覆盖对白和提示卡；系统确认弹窗在最上层。
- SEffect：Delay/Echo、Pan、峰值 EQ、轻度失真、Bitcrusher、Compressor；配套参数动画、Timeline 音频事件、语音期间压低 BGM。
- 转场：曝光闪光、缩放、像素化、故障。
- 预设：显式图层说话人强调并组合文本/可选语音、闪光/闪电、眨眼、回忆/梦境进出、天气（雨雪/樱花/尘埃/萤火虫）、呼吸/摇摆、心跳/紧张/受伤、电影黑边、多层视差推拉。
- 通用文本卡：九宫格位置、App 样式名、默认样式回退、时长覆写、可等待；同位置替换，不同位置独立；音乐提示复用，保留真实 Started 和恢复抑制规则。
- GameTestCase 中英文案例、编辑器参数及资源安装、存档/停止/快进边界和正式使用文档。

## 非目标

翻页、描边、真实 3D 相机/深度图/散景、粒子碰撞/拖尾/GPU simulation、VST/卷积 IR/完整侧链路由。上述高级能力在此前讨论中作为另行研究项，非本批候选。

## 确认的约束

- 强调的参与者和活动图层显式指定，保留到下次切换/解除，仅管理自身效果。
- 优先现有 Layer、Effect、Timeline、Particle 和 PCM 链，不引入通用调度框架。
- 文本服务由应用表面提供、随游戏会话绑定和清理；旧退场/延时不得清除新实例；解绑、取消和读档必须清理。
- 遵守仓库 AGENTS.md：现有工具/默认 bin/obj，额外输出仅 output/；遇文件占用或环境冲突先告知用户等待决定。
- 保护本轮开始前已有 animation-curves 等未提交改动，GameTestCase 案例采用独立组避免覆盖。

## 验收

1. 新资源可由编辑器新项目及显式 visuals install 部署，资源 GUID 显式保存。
2. 公共契约、执行、默认宿主均接线；Headless 可完成逻辑收尾。
3. 视觉像素、DSP 信号、文本卡替换/取消及预设编译有针对性验证。
4. GameTestCase 能校验、编译并提供可运行案例；不以编译代替原生视觉/听感验收。
5. 总结明确记录实测、未测和任何未完成项。
