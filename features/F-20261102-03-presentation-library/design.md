# 设计

## 边界与复用

默认 shader 继续作为项目资产，经 metadata 提供参数与动画属性。扩展默认用途字典，旧项目使用显式安装补入，不覆盖已有资源。程序效果保持 effect.apply/stop，不为每个 shader 新增执行原语。

覆盖遮罩使用独立颜色 Layer 与 shader；裁切遮罩直接附加目标 Layer。场景外覆盖必须有显式呈现面，不能靠场景 Z 覆盖 Avalonia 对白。保持系统弹窗最上层。参数使用归一化几何与可动画标量，羽化 0 为硬边，严格处理完全开/闭端点。

预设是纯编译，将作者显式基准与资源引用展开成 Timeline。持续演出沿用 UntilStopped 和完成事件，临时身份使用 playback 命名空间。强调使用稳定的作者指定强调身份及显式参与目标，只替换自身 effect。多层移动接受各层基准，不在编译期读取运行场景。

## 文本卡

中立请求包含文本、九宫格位置、样式名称、可选停留时长、等待语义。呈现接口与 Primitive 解耦；Avalonia 负责六侧/中心动画和按位置替换，App 提供主题/模板。保持单一服务实现，无额外队列/频道框架。每个位置使用对象身份判断完成；取消旧请求不会删除替代项。语义文本进入现有本地化路径。

曲名事件保持现有 AudioRuntime Started -> 宿主解析资源名 -> 通用文本服务，不提前弹出，不因循环、恢复或鉴赏重放重新提示。退出/解绑清空，系统弹窗在其上层。

## 音频

SEffect 在现有 PCM 有序链上执行，保持参数快照发布与单音频线程 DSP 状态，回调不新增 I/O/锁/分配。Delay 尾音可在空输入继续，reset 清空；Pan 使用明确的 stereo balance；EQ 为 RBJ peak；动态压缩 stereo linked；限制反馈/增益防止数值发散。

作者时长动画应与 Timeline 共享暂停/快进和终态语义，而非额外墙钟任务；音频事件使用已有 authoring/Runtime 语义并定义瞬时声音在追赶时的抑制。Duck 基于真实活跃语音，剧情/玩家音量与临时压低乘法叠加，不把临时压低写入剧情存档。

实施取舍：音频使用独立的 audioTracks DTO，通过现有 beforeFrame 回调调用 AudioRuntime，不为每个音频参数制造 Scene 对象或呈现层 binding。一次性音频动画保留最新已提交参数，不保存时钟；循环沿用 LoopAnimationState。作者当前直接配置 Timeline 数据，专门的音频曲线面板不在本批增加。

强调最终使用单 Timeline。新 startFromCurrent 在注册 Replace 轨道时读取当前呈现值，只替换本次播放的首键副本，逻辑状态仍按末键提交；effect.ensureOnly 确保切换不会重建已挂载的自身效果。这样复用原播放身份和停止机制，不添加强调管理服务。

## 兼容与风险

优先增量契约，新增字段显式默认；新增 state 或范围必须同步源生成 JSON、校验、查询和恢复。重采样 shader 成本由固定采样预算限制；CPU/GPU 各自检查，不声明未经测量的帧率。视觉和 DSP 测试覆盖 neutral、边界、停止、恢复，不用源码字符串断言代替行为。
