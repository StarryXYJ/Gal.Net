# Sample 布局与自适应整理

日期：2026-11-02。用户授权：保持现有风格，总结讨论并尝试优化布局、尺寸与排版。

## 当前范围（用户复查后的修订）

- 最新收敛：保留极简风格，只整理排版并精简布局逻辑；页头在普通页面间保持一致，设置正文独立限宽，继续沿用集中字号和现有缩放。
- 仅首页随横竖屏切换左对齐/居中，保持纵向构图和按钮尺寸关系。
- 普通页面参考初始画布比例整体有界缩放，其他页面只根据内容空间自适应；移动端低 DPI 适度放大。
- 设置页整体居中，标题与分类、表单和页脚共用左边界，保留分类单行和正文独立滚动。
- 设置分类无额外左缩进；一级分类选中半粗体且无持续底色，操作页设备切换用较小字号、常规字重和浅灰选中底。两层不使用下划线；游戏工具栏仍只通过背景反馈，不加粗、不切字色或按压缩放。
- 保持页面、编辑器和玩家设置实例；游戏页与场景鉴赏仍采用实际视口。
- 保留配色、按钮外观、菜单顺序、已有字号档位；不覆盖用户演出改动。

## 当前验收

- 横竖切换仅改变首页水平对齐，菜单大小和同一组按钮不变。
- 320×480 到 3840×2160 的截图与实际坐标检查，控件比例协调，设置列对齐。
- 小屏与低 DPI 移动端仅适度放大，不重新叠加系统 DPI。
- 分类切换记住滚动位置；缩放和旋转保留编辑器/设置；实际鼠标、键盘导航及启动/清理回归通过。
- 首版 P1/P2 虽然 148 项几何回归通过，但视觉被用户否定，只保留历史证据，不作为当前验收。
