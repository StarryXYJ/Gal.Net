# 内置内容封装与外置翻译入口

- 状态：implemented-with-follow-up。范围内实现、回归与发行载荷已验证；两种玩家部署均有实际初始化成功证据。组合桌面 smoke 中的偶发字体原生崩溃另保留跟进，不宣称完整桌面验收全绿。
- 授权：用户确认整理后的六项范围，并要求先提交上一轮再开始；上一轮提交为 86cc021b。
- 目标：玩家内容目录不分发内部 JSON；game.pak 为固定入口，localization.pak 按语言封装内置文本；I18n 仅供外置覆盖；始终提供空补丁/翻译目录。
- 范围：导出/安装/运行加载/profile 身份/发行脚本及兼容、相关测试和文档。
- 非目标：BSON、加密、防提取、资源裁剪、AOT、热更新、通用版本升级协议。
- 验收：直接目录导出、galpak 普通解压和安装得到同样可运行布局；即使无补丁也存在 StoryPatches/<buildId>、ResourcePatches、I18n；内置语言按原排序语义合并，外置部分覆盖/新增语言/损坏跳过，外置不能补足缺失的内置默认语言；损坏包拒绝且旧安装和用户翻译保留；旧 v1/v2 布局仍可读取。
- 无待确认问题。设计见 design.md，阶段见 phase-plan.md。
