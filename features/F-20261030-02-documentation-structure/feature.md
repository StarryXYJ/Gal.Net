- 创建日期：2026-10-30。

## 目标

1. 以当前源码、测试和可追溯验证记录核查并修正文档。
2. 正式文档在 `docs/` 单处维护，按阅读任务和技术职责组织。
3. Wiki 发布完整正文，并呈现与 `docs/` 一致的分类、顺序和交叉链接。
4. 保留历史及未验收边界，不把旧方案、待办或 agent 私人经验混入正式规范。
