# 实现自审

日期：2026-10-30。此文件是实施者自审，不冒充独立 reviewer 或线上验收。

- 旧 36 篇文档均有明确迁移归属；新 72 页包含分类入口，未按设计创建空壳页。新增 spec/editor/debugging.md 的归属差异已记录。
- manual 分开 Editor/Sample 使用、扩展、发布和开发；spec 按架构、运行时、内容、呈现与 Editor 分类。术语和理念继续单独保留。
- 核查修正过时 Sample/模板所属、Dock 非公开示例、已落地功能的旧阶段说明、资源引用和文档包行为；不将待验收平台或旧候选写成完整发布支持。
- 主题正文的具体操作与内部行为分开，通过稳定导航/交叉链接连接；删除旧文件前有迁移映射与原 Git 历史。
- Wiki 正文、侧栏、页脚和来源链接由同一导航生成；生成后再检查页面 ID/fragment，避免只验证 Markdown 输入而遗漏转换错误。
- 来源正文及导航必须与实际 Git commit 相同；工作区未提交内容不能冒用旧 commit。远程可访问性仍在正式推送时确认。
- 同步仅操作管理清单拥有的文件，拒绝手工改动、已知远程分叉、非受管同名文件、目录穿越和 Git 元数据路径。重复生成保持一致。
- CI 的 PR 校验不接触发布凭据；可选发布限 master，需要独立 Wiki 权限。预览 artifact 明确选择正文、附件和管理清单，不上传 .git。
- 生成器测试和 CLI 烟测通过；未因文档修改重跑整个解决方案或平台实机矩阵。宿主及资源性能的其他任务源码仍由原任务负责。
- 提交采用路径限制与混合 Markdown 的引用专用补丁，避免将其他任务的状态、代码和测试一并提交。

远程发布与线上 Wiki 实际显示仍按用户选择延后；本地页面与链接验证不替代浏览器中的线上验收。
