# 原版风格的移动端玩家 UI 适配

- 日期：2026-10-30。
- 状态：deferred / design-draft，仅整理方向，尚未开始实现。
- 当前指令：先保存设计想法，由用户后续重新设计，再启动实施。本记录不构成本轮代码修改授权。
- 设计：[design.md](design.md)。

## 目标

在保留原版视觉风格和桌面布局的前提下，改善手机上的对白阅读、底栏操作和窄屏设置体验。核心是放开必要 UI 的可用边界，而不是把整套界面放大。

## 用户约束

- 桌面端应与原来的设计、视觉密度和排版基本一致。
- 游戏页保持原有构图，优先研究对白和下方操作按钮越过固定分辨率画布边界；不能据此重做整套页面。
- 移动端只做局部、适度调整，拒绝大字号、大按钮、大块背景和过厚留白造成的整体膨胀。
- 此前本轮 UI 改造已经全部撤回，不作为后续实现基础或验收结果。
- ComboBox 文本消失修复独立保留在 `671bc6c2`，不依赖本设计。

## 首轮范围

先制作 Classic 游戏页的桌面原版、手机普通横屏、手机超宽横屏对照稿。使用同一场景、人物和对白，确认比例与观感后，才决定实现参数和模块边界。

设置页、其他主题及竖屏完整布局后续分别设计，不自动并入首轮实施。

## 非目标

- 更换主题、配色或把玩家界面改造成新的应用式布局。
- 全局增加字号、按钮最小高度或统一乘一个移动端放大系数。
- 更改剧情坐标、存档格式、输入绑定、设置持久化或媒体合成语义。
- 用自动化测试通过代替用户的视觉确认和真机触屏验收。

## 完成判定

桌面基线不退化；手机对白更易读、底栏更易操作；场景不拉伸、不裁剪；跨画布的 UI 不被裁切且不遮挡其他控件。具体数值和实施计划须在对照稿确认后补齐，目前没有 verified 阶段。
