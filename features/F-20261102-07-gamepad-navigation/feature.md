# 玩家全流程手柄导航

状态：implemented；自动化导航验证通过，真实手柄专项尚未执行。用户已授权实现、验证并提交。

用户目标：菜单键进入工具栏，再次菜单键或当前确认布局的取消键返回剧情；方向导航循环；设置上下切控件、左右调整、下拉框显式提交；覆盖玩家完整流程。首页按钮数量、卡片列数和布局未来可变化，不能硬编码。移动端原生手柄源本轮暂缓，共用导航不限制桌面布局。

范围：首页与普通页面、剧情分支、工具栏和更多菜单、存读档、鉴赏、设置及绑定捕获、历史、跳过/退出/返回标题确认、截图覆盖层。复用既有输入配置、会话命令和 SDL 设备生命周期。

非目标：Android/iOS 原生设备接入、系统文件选择器的手柄模拟、手柄软键盘、Editor 工作区导航。

验收：可见/可用控件动态参与；方向循环、自动滚动；确认只执行一次；分支高亮不提交；模态不穿透；取消恢复编辑或返回；失焦/断连/卸载停止连发；键鼠和触摸仍可用。真实手柄专项验收与自动化证据分开记录。
