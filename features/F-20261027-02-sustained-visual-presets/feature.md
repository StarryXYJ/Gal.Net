# 持续演出预设与停止收尾

用户于 2026-10-27 授权实现。震屏和集中线可选择定时播放或持续到停止；持续模式不阻塞且不随对白点击跳过。统一通过 animation.stop / CompleteImmediately 停止，震屏归零，集中线移除其 Effect 和临时图层。人物动作、冲击和转场保持单次。

验收：定时行为不退化；持续震屏不衰减；集中线循环不重复创建/删除对象；主动停止、正常结束、跳过及恢复后的停止均完整清理；无关效果和人物基础变换保留；停止完成后同标识可以重用。

范围不含淡出停止、人物中途姿态保留、新的停止 Entry 或自定义复杂演出编辑器。保留已有三处无关工作树修改。
