# 第二十九轮：音频总线与轨道的嵌套列表

用户确认按预览图实现，并再次要求按“列表套列表”推进。项目设置现在只有一个音频入口，内含总线列表，每个总线有自己的属性及轨道列表；轨道常用字段与进阶字段分开。表单宽时两列、窄时单列，名称、ID、摘要、计数和更多菜单分层展示；独立主题背景和轻量边框区分两层。逐字段重置沿用既有 Forms，增益保留实际允许的数值范围。

界面由普通集合与 IsExpanded 绑定驱动。总线改名同步更新轨道引用；删除总线保留轨道并清除其归属；新增生成可用 ID，轨道复制保留配置并生成唯一 ID，可在同一总线内排序。未分配或失效引用保留可见入口。音频嵌套输入草稿由项目设置持有，视图关闭/重开及语言切换不丢输入；保存沿用项目事务与历史。后台仍使用当前两份配置字段，此为复用现有保存机制，并未加入旧格式迁移或兼容层。
