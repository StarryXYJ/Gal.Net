# 第二十六轮：项目设置展开布局

按用户要求只调整音频列表及默认视觉、天气映射的展开排版，沿用现有编辑和资源选择逻辑。音频条目使用轻量边框和对齐的操作区；映射在宽窗口并排显示键和资源，窄窗口换行；资源选择按钮填满可用宽度。共享结构控件调整了列表及映射的布局，项目设置单独提供卡片样式。
