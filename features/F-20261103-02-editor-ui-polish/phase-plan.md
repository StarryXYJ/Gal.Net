# Editor UI 优化阶段计划

状态：planned。依据 [设计草案](design.md) 制定；用户已确认每项及全部快捷键重置、全部重置需确认、Problems 单击详情和双击跳转、沿用 Inspector 锁定。除这些明确事项外，设计中的方案仍按实现前后证据修订；本计划不是实施完成的证据。

## 依赖和公共约束

P0 先建立基线与入口清单。P1–P3 以 P0 为前置，可以独立验证；P4 依赖 P0 的结构清单及数据保全规则，P5 依赖 P4；P6 汇总前述结果并做真实视觉验收。具体实现按实际依赖排序，不以并行或重构本身为目标。

- 使用现有 SDK、默认 bin/obj；额外证据放 `output/`，遇文件占用或环境冲突按仓库约定先停下询问。
- 对项目设置保留项目草稿、历史、失焦及关闭/保存语义；编辑器快捷键是独立偏好，其即时更新不扩展成项目设置的逐字提交。
- 项目 JSON 和扩展内容不得静默丢字段、覆盖损坏原文；不改变 Runtime/CLI 契约或任意拦截普通文本。
- 只在有实际回归或边界需要时新增有意义的测试；每阶段记录执行结果与未覆盖范围，正式文档只同步已验证事实。

## P0：界面与配置入口基线

**状态：in-progress。** 静态结果见 [基线](baseline.md)，GUI 和动态扩展盘点尚未完成。 前置：feature/design。模块：窗口和主题、设置、Forms/Registry、Inspector、文件和菜单、音频配置及相关文档。

- 盘点窗口模板/平台、主题、设置入口及已有尺寸持久化；记录实际宽度、选择/焦点、常见和窄尺寸的现状。比较历史音频界面和当前音频契约，提炼可复用交互。
- 逐项登记可见 JSON 入口：项目设置各 section、Entry/Inspector 和修复按钮、Timeline、资源 sidecar、普通文件入口、扩展、自定义与无效值；列出 schema、可编辑性、草稿/历史和无损保护。区分源码可达与 GUI 实际可达。
- 盘点各右键菜单、单选/多选作用对象及常用顺序；核实现有快捷键默认值和 Global/局部路由交集。
- 验证：静态核对加可行的真实桌面观察；无法访问的窗口、语言、主题和平台明确记录。证据及清单随阶段记录保存，不修改正式 spec。
- 风险：仅凭文本搜索漏掉动态注册；不能将待调查结构或任意坏文件声称已支持。
- **退出条件：** 有逐项清单、复现场景和 P4/P5 的覆盖及异常分流；识别需修改共享 Forms 的其他消费者，未确认项保留具体后续动作。

## P1：设置布局、标题栏和快捷键

**状态：in-progress。** 见 [第二轮](round-2.md)，真实桌面及捕获交互尚待验证。 前置：P0 中窗口与快捷键盘点。模块：Editor 设置窗口/VM、窗口样式、快捷键服务、本地化、设置持久化。

- 统一设置页分类和表单排版；增加首次默认窗口尺寸，适应屏幕与窄宽，保留有效用户布局；常态标题栏按钮无独立背景，hover/pressed 保留清晰反馈。
- 按键捕获立即保存，单项 icon 重置；全部重置采用确认弹窗，取消不修改。定义清除键位交互；阻止捕获时命令误触发，保证冲突和失败保留旧绑定。
- 按真实执行上下文核实并统一冲突、单项重置及持久化的边界，不破坏合法组合。保留现有四语与键盘可访问性。
- 验证：捕获、Escape、清除、冲突、重置、全部重置确认/取消、保存失败、搜索/切语言及重启；窄窗口、字号、主题与实际窗口交互。测试依据既有设施，必要时补充针对性用例。
- 文档：确认后更新 Editor 设置及快捷键操作说明；记录跨平台标题栏无法验证部分。
- 风险：默认快捷键相互冲突、设置持久化失败后内存/磁盘不一致、捕获期间路由和焦点处理。
- **退出条件：** 目标控件行为和持久化回归通过；窗口默认/用户尺寸行为有证据，页面实际可读且无溢出；未验证原生平台明确记录。

## P2：文件预览与菜单

**状态：in-progress。** 文件菜单静态盘点后先处理文件页；其余菜单及真实桌面验证仍待完成。 前置：P0 中菜单清单。模块：文件视图、缩略图状态、各纳入范围的上下文菜单。

- 缩略图可用时隐藏类型图标；加载中、失败及无图保留可识别状态，确保透明图片不叠图标。
- 依据盘点调整文件及其他相关菜单顺序、分组和启用状态，统一单选、多选与空白区域作用对象；保持快捷键与现有文件事务。
- 验证：透明图、失败/无图、视图切换、缩略图异步更新；空白、单项、多选、未选项右键以及删除等实际作用对象。检查资源释放与撤销语义不退化。
- 文档：涉及用户操作改变时同步文件手册/契约。
- 风险：右键重选改变多选或意外对旧选择执行；缩略图透明区仍透出图标。
- **退出条件：** 实际显示及菜单行为按场景核验，清单每项标记已处理或有理由的遗留。

## P3：Problems 与 Inspector

**状态：in-progress。** 见 [第三轮](round-3.md)，真实桌面和多个 Inspector 综合验证待完成。 前置：P0 和现有 Dock/定位机制。模块：Problems、Inspector contribution/coordinator、导航及草稿会话。

- 单击/键盘选择显示问题详情；双击/Enter 定位。移除行内详情 expander，保留问题消息、来源和草稿恢复/丢弃。
- 仅明确选择问题时跟随；沿用 Inspector 锁定，无额外提示。核实双击导航导致的焦点与详情切换；无目标、过期目标可查看信息而不错误跳转。
- 验证：可定位/不可定位/过期/草稿项，鼠标及键盘，锁定/多个 Inspector，过滤和问题刷新，按钮不误触导航；保留 Group 稳定身份定位和草稿回归。
- 文档：更新 Problems 和 Inspector 交互说明与 Dock 契约。
- 风险：辅助面板改变 Inspector 跟随、异步问题列表刷新导致陈旧目标、双击触发两次导航。
- **退出条件：** 双击/单击、锁定、详情与现有定位及草稿功能均经验证，未发现误定位或生命周期泄漏。

## P4：结构化设置与音频

**状态：planned。** 前置：P0 清单、配置 schema/历史约束。模块：配置 section、共享 Forms 的适当扩展、音频设置与项目历史。

- 对可遍历配置移除不必要的强制 JSON 回退；优先既有 schema、字段/扩展 editor 与 patch 机制，保持未知成员、null/缺省及原项目数据格式。
- 结合历史 UI 和当前契约设计 Bus/Track 的列表及字段操作；验证选择引用、添加/删除和字段约束，不发明不受契约支持的行为。覆盖清单中其他内置复杂设置。
- 验证：有效/无效值、未知成员、扩展 editor、输入草稿、外部修改冲突、关闭、保存/重开、Undo/Redo；以真实项目检查排版与音频可操作性。若更改共享 Forms，验证 Player 和其他使用方。
- 文档：同步已验证的设置与扩展字段能力，不把未实现兜底写成现状。
- 风险：对非标量盲目反射导致数据丢失；局部写入覆盖其他字段；扩展类型与过期上下文。
- **退出条件：** 已盘点正常内置设置不依赖直接 JSON 编辑，音频常见操作完整且数据保全与草稿/历史回归通过；未覆盖扩展和异常逐项转入 P5。

## P5：其余结构与异常处理

**状态：planned。** 前置：P0 的入口清单、P4 的结构编辑与数据保护能力。模块：Entry/Inspector、Timeline、资源 sidecar、通用字段/扩展回退与文件入口。

- 按清单替换正常创作中的直接 JSON 编辑，优先复用专用控件和 schema 结构；对无 schema 的可解析值评估安全类型化树，只支持有明确无损语义的操作。
- 为无效类型、重复键、超限、坏文件、未知扩展设计可理解提示与无损恢复路径；可安全替换的局部值才允许显式重置并可撤销，不能安全解释时保留原文、不自动写回。核实图集和普通文件入口，避免移除唯一恢复路径却没有可用替代。
- 验证：各清单入口的正常与异常路径，保留未知字段/原始数据、撤销重做、过期绑定与超限；检查不同消费者、项目关闭及编辑器释放；标注不可安全结构化的真实限制。
- 文档：更新扩展、属性编辑和资源异常修复契约及手册；不能保证的能力明确陈述。
- 风险：任意 JSON 不一定可无损映射到结构；重复键和格式损坏无法通过普通模型往返；共享修改可能影响 Player。
- **退出条件：** 清单中每个用户可达入口有已验证的结构化路径或明确、可用的数据保全/恢复边界；不能将“隐藏编辑器”计为完成，也不能静默丢弃数据。

## P6：整体验收与收尾

**状态：planned。** 前置：P1–P5 完成或各有明确未完成说明。模块：整体 Editor、主题/本地化与相关文档。

- 按真实工作流复核窗口、设置、音频、文件、菜单、Problems/Inspector 的颜色、文字层次、焦点、密度与状态；覆盖已有主题、四语、常见和窄窗口，确认颜色克制且可辨。
- 运行与最终变更相称的构建和回归；记录环境、截图/证据和无法验证的平台。检查本地化、扩展兼容、数据保全与文档一致性。
- 形成实现总结和遗留清单；按结果更新 feature、正式 spec/manual，整理值得复用的经验。对未完成事项保持准确状态。
- 风险：自动控件测试不能证明真实颜色、透明叠图、原生窗口与人工可用性。
- **退出条件：** 需求逐项有证据或明确未完成；视觉和实际交互验证通过，所需构建/回归及文档同步完成，未验证范围透明记录。
