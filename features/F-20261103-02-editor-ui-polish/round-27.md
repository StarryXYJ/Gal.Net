# 第二十七轮：映射对齐与音频分组方向

用户指出映射行实际控件未垂直对齐，并提出将音频设置组织成 Bus 及其轨道。映射的资源表单包含诊断区空白，不能以整个表单外框的中心作为可见按钮中心。本轮对齐键、资源选择及删除操作的可见输入行，并用控件实际坐标验证。

音频的原始配置是两个独立数组，Track 的 busId 可为空或指向不存在的 Bus。拟在一个音频设置入口内按 Bus 分组，并保留未分配及失效引用轨道的可见入口；增加、删除、重命名 Bus 和变更轨道归属时必须遵循现有草稿及项目历史，保留未知字段和数组顺序。此分组尚未实现，不视为 P4 完成；需补充上述场景、草稿及撤销测试，并以真实主题检查布局。

验证：使用 `out/editor-ui-verification` 运行天气映射及历史、音频轨道草稿引用、共享列表重排 3 项测试通过。映射测试检查键输入、资源按钮、删除按钮实际中心位置；真实桌面和暗色主题仍待验证。
