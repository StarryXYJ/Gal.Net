# 第九轮：无 schema 对象的结构化编辑

2026-11-03。Editor 的通用 JSON editor 首先尝试将可安全识别的对象及嵌套对象投影到现有 StructuredFieldEditor；支持字符串、布尔和 decimal 范围内数值，保留字段名，通过原有绑定提交局部修改。最多 8 层、每对象 200 项，不对数组、null、重复键、空白键或无法安全处理的数字推测 schema；这些情形仍使用原有 JSON 路径，保留修复能力。

挂载控件回归验证编辑一个字段并保留嵌套对象及 9007199254740993 原始值；同时运行现有结构修复和列表失效保护，共 3/3 通过。此能力只影响 Editor 的 JSON 注册，未改变共享 Player 默认 registry；直接 JSON 修复入口和不支持的结构仍待 P5。
