## 实现与修订

- GameTextBox 内容横向伸展，单行输入最小 32、文字居中；分支主输入、拖动柄和删除按钮使用相同主行，提示和错误向下增长。
- 变量与角色分别使用项目级纯数据状态服务；不缓存控件，不修改作者格式或保存语义。角色身份使用 ID+姓名文本组合；共享姓名不能推断成同一角色。
- 角色异步应用只清理其提交的草稿快照；等待历史队列时切到另一角色、关闭重开后编辑，以及保留独立新建草稿均有交错回归。完成回调不抢回其他选择，应用/还原已有角色不放弃新建草稿。
- 变量新增仍立即创建声明，工具栏固定在详情顶部，窄 Dock 下也能直接应用。类型输入适配仅接受当前类型控件回写，避免隐藏数字/布尔输入改变字符串草稿，空文本规范化为空字符串。
- AssetInspector 属性与预览拆分，ImageVariantsEditor 仅编辑配置/JSON，ImageVariantsPreview 使用同一模型展示预览，无额外加载器或播放器。
- 本地化保持单套虚拟化行；上下文与表头共享横向位移补偿，不复制第二套列表。键盘聚焦单元格后将其显示到固定上下文旁，避免输入框藏在固定区域下。分类窄屏降为下拉框。搜索/目标语言状态筛选不改变单元格身份，导入应用期间仍禁用目标语言切换。
