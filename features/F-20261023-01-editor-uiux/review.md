# 实现复核

日期：2026-10-24。范围：本 feature 的需求、设计、实际变更、测试输出与规范同步；同一实现者自查，未声称独立审核。

结论：`pass-with-follow-up`。没有发现阻止代码交付的已知问题；真实桌面 DPI/IME 人工验收仍保留为后续项。最终构建及格式退出状态见 [阶段证据](phase-plan.md)。

## 重点检查

- 常用筛选只由 Editor 行内显式开启，共享表单默认完整；继承字段、手写 metadata 与旧 EditorHints 构造入口有回归。
- 行内与 Inspector 不借用同一个控件。页面旧绑定继续按既有规则失效；Inspector 拥有自己的绑定，项目拥有草稿。失效、类型和根结构冲突阻止旧输入提交。
- 双处输入、关闭重开、未完成组合输入及有效/无效混合草稿有实际挂载测试。项目拥有面板关闭后不被误销毁；辅助工具不清空 Inspector。
- Save All 复用作者意图及事务，不因捕获版发布成功而把更晚编辑标记已保存。Problems 检查内存作者快照；导航解析稳定 ID，重复跳转复用未锁定 Inspector。
- 预设及最大化不写作者历史，保留文档/选择/草稿；Dock 容器被移除后可重建。Timeline 分隔条不会覆盖 frame 0 点击区。
- hover 中间帧使用真实框架插值复现作为回归对照，新实现检查透明合成结果及反向过渡。主题、图标按钮尺寸/透明度/焦点和实际字段尺寸均有挂载证据。

## 已修复的复核发现

1. 暗色背景在过渡中闪白：改用预乘透明度插值，保留动画。
2. 首版详情复用页面绑定破坏旧绑定失效：Inspector 改持独立绑定。
3. 关闭项目 scope 面板后重开解析已释放状态：关闭 Dock 不释放借用的项目面板。
4. Timeline splitter 默认最小宽度覆盖 frame 0：显式缩小 gutter 并设置最小宽度为 0；旧关键帧交互回归通过。
5. 保存途中新增编辑仍显示“保存中”：增加与发布快照的独立比较，补并发断言。
6. 新增补全控件测试漏装表单模板：补齐实际样式后验证可视树中的控件及混合草稿保存。
7. 草稿来源变更后撤销恢复相同 JSON 可能重新匹配旧签名：在项目内容变更时保留已经发生的冲突，取消草稿才重置；来源检查读取实时 Source.Type，避免投影刷新顺序掩盖类型变化。
