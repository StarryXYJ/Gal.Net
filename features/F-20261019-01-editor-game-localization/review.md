# 默认开发语言创作与本地化审核

日期：2026-10-21。结论：pass-with-follow-up。

这是实现者按 feature 验收点进行的自审，未声明独立第三方审核。审阅当前交换/校验 diff、P1–P5 的阶段证据、正式规范与最终测试结果。

未发现阻止本 feature 交付的新增问题。发布前已知引用的包内默认语言、角色、来源与语言错误会阻止输出替换；未知范围明确 warning/Complete=false。模板项目身份不依赖目录名；角色 ID 与姓名文本 key 分离；外部行序与上下文不参与匹配。普通 UI 不暴露文本 key，模板中保留机器身份。

导入严格检查 JSON/重复/版本/项目/源语言、只接受受支持的非开发语言，未知/null/未允许空串不可写。当前原文与原始指纹分开，旧证据标待复核。预览证据在实际历史执行前重查，关闭及排队变更已覆盖；按文件批量写入并保留其他值，值与复核状态一次撤销。导出在项目外以临时文件替换，首次持久身份可能在输出失败后保留，这一例外已记录。

验收证据分布：角色匹配、同名/唯一 key、只增编号、引用与删除见 P3；原文/稳定 Entry/列表/分支移动与复制见 P4；分类、隐藏 key、语言与草稿见 P5；外部交换、保存重开、构建和运行双语言解析见 P6。依赖边界测试 45 项通过，Core/Runtime 未加入 GUI 依赖。

完整相关回归 1180 通过、2 失败。失败为此前 P6e3 已记录的 Group 工具栏尾部留白和属性行宽度，不归因于本 feature，也未修改相关控件掩盖失败。原生文件选择/IME 的人工测试、大项目性能阈值和自定义运行指令内部解析不在已验证结论内；后者仍由 ITextResolver 接入契约负责。视频环境 6 项跳过。

后续跟进：既有布局断言、上述平台人工验证与性能验收。没有以向后兼容或迁移入口作为交付依赖。
