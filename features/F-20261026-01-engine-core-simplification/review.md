# 核心精简自审

结论：pass-with-follow-up（代码与当前可运行回归）；完整平台验证仍待 P6。

检查范围：实际 diff、Core/Runtime/执行与呈现抽象、Builtins、GameHost、Editor/CLI 接口迁移、参数生成器、生命周期和正式文档。此次为同一实施 agent 的自审，未声称独立审核。

## 已修正的问题

- 检查点观察者异常和重入：统一锁外通知，逐订阅者隔离并复制快照。
- 无阻塞循环取消：每批让出，重查代次/阻塞，调用方取消不转 Faulted。
- 不合法恢复位置/状态：先验证候选，再取消和替换；宿主也在释放旧运行前预检。
- 旧取消回调异常：P6 自审补充 CancelDetachedScope 与正式回归，避免合法恢复半提交。
- 可变变量泄漏与图共享：读取隔离，运行持有私有图副本；场景活记录保留明确模块边界。
- 作者/运行条目和选项双轨：JSON 权威、独立类型、单一 enum 约束；当前消费者和契约夹具已迁移。
- 职责边界：IGameContext 不暴露游标/恢复，执行端口与 presenter 区分；通知协作者不拥有执行门。
