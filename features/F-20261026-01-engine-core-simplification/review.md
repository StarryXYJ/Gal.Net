# 核心精简自审

结论：pass-with-follow-up（代码与当前可运行回归）；完整平台验证仍待 P6。

## 已修正的问题

- 检查点观察者异常和重入：统一锁外通知，逐订阅者隔离并复制快照。
- 无阻塞循环取消：每批让出，重查代次/阻塞，调用方取消不转 Faulted。
- 不合法恢复位置/状态：先验证候选，再取消和替换；宿主也在释放旧运行前预检。
- 旧取消回调异常：P6 自审补充 CancelDetachedScope 与正式回归，避免合法恢复半提交。
- 可变变量泄漏与图共享：读取隔离，运行持有私有图副本；场景活记录保留明确模块边界。
- 作者/运行条目和选项双轨：JSON 权威、独立类型、单一 enum 约束；当前消费者和契约夹具已迁移。
- 职责边界：IGameContext 不暴露游标/恢复，执行端口与 presenter 区分；通知协作者不拥有执行门。

没有发现本次改动中尚未修复的 P1/P2 行为问题。回归与环境失败详见 [summary](summary.md)，不把相关失败算作通过；原生桌面、符号链接和 Browser 包哈希限制仍需补验，P6 保持 in-progress。

## R1 自审

结论：pass-with-follow-up。此次仍为实施 agent 自审，不声称独立审核。

检查了七个迁移类型、生产/测试引用、Runtime 编译产物、默认接口释放语义及 34 个锁图差异；没有新增兼容层、执行门或后台推进逻辑。核心执行接口与 Choice/快进/播放协议只依赖 Core 数据，Runtime.Audio 通过 Core.Audio 后端协议工作。运行管理接口和恢复候选不再由 Core 拥有。最小自定义分发器可执行、保存并恢复，Runtime 程序集没有呈现或内置实现依赖。

发现并修正调试测试夹具原先借助 Runtime 获取的隐式呈现引用；显式引用仅加到测试项目。强制还原产生的 WebAssembly 包哈希与 iOS 框架键无关变化均已撤回，只保留项目依赖变化。新夹具的稳定快照初始化时机也已修正。

893 项相关回归通过，集成中 1 项已知符号链接权限失败；普通桌面构建、locked restore、格式和架构门禁通过。未发现尚未修复的 R1 行为问题；R2–R8 的设置/领域重构仍未完成。R2R 缺包、Browser 哈希与原生平台条件详见 summary，不将发布验证计为通过。
