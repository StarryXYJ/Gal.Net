# 新建项目选择游戏 App

用户授权：2026-10-29 确认开始实现。

在 Editor 新建项目契约目录上方提供可选 App EXE。契约目录为空时，识别当前普通构建的 EXE 同级契约和当前发行布局的 lib 契约；不支持历史布局。已有契约输入保留，取消选择保留输入。自动发现失败或存在多份入口时提示手动选择，不静默使用默认契约。

创建时部署契约及非平台托管依赖，保持 DLL 字节身份，不复制整个 App 或运行时。所选 EXE 保存为项目外部调试 App。未选 App 且契约为空时保留 Editor 默认契约行为。

验收：两种目录发现、依赖闭包、手动覆盖/取消、无效来源阻止创建、默认/自定义原流程、调试配置重开保留与四语资源验证通过。开发输出默认具有调试能力，玩家发行包能力仍由原构建开关决定。
