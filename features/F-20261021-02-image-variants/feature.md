# 多维图片差分图集

日期：2026-10-21

状态：P1–P5 技术阶段已 verified，整体自查 pass-with-follow-up；本轮未完成全部人工扩展矩阵，Editor 既有布局失败和释放抖动保留。详见 [实现总结](summary.md)、[P5 验证](phase-5.md)和[自查](review.md)。用户要求每完成一阶段提交一次 Git。

## 目标与来源

用户希望用一个描述文件指向包含一组图片的文件夹，通过 `xxx_xxx_xxx` 文件名表达数量不限的有序维度，独立显示图集并切换某个维度。示例为 `smile_coat`、`smile_skirt`、`idle_coat`、`idle_skirt`、`weap`。组合不存在时，从后向前逐个削减未修改的维度，最终回退默认图，方便立绘和场景差分创作。

讨论后采用的方向：文件名自动识别、可命名维度、保留用户选择状态、确定性回退、显式默认图、底层复用图层显示与资源系统。

## 范围

- 描述文件与目录导入、维度/选项识别及校验。
- 图集显示与单维切换；请求状态和实际图片分离。
- 纯解析规则及可解释的回退结果。
- 编辑器图集配置、选择和预览；稳定资源引用与打包。
- 游戏状态、读档恢复、CatchUp 和现有图层能力的接入边界。

## 非目标

分层纸娃娃、贴图合并/纹理 atlas、序列帧动画、任意标签查询、相似度评分、手写逐图映射和回退树、CG Gallery 自动解锁、维度值连续动画。

## 验收

1. 用户示例可导入，段数不同合法，无需准备所有组合。
2. 单维切换保留其他选择；经过 `weap` 后仍能恢复之前服装。
3. 回退逐步、稳定且可诊断，不依赖目录枚举顺序，不自动替换成其他选项。
4. 不同显示实例的选择独立；换差分不改变图层身份和变换。
5. 发布包无需原始文件夹；资源移动保留正式 ID，坏引用和重名不会静默被忽略。
6. 存读档和 CatchUp 保留完整请求状态及实际显示结果。
