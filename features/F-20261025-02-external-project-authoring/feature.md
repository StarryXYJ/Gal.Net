# 外部项目创作与 Editor 热重载

状态：implemented；验证证据见 [实现总结](summary.md)。

## 目标

用户通过 Codex、Claude 等外部工具及项目创作 Skill 使用 GalNet CLI：纯文本剧本转 Raw Group、给既有对白补演出、导入立绘/差分并关联剧情。Editor 保持打开，识别任意来源的项目文件变化并刷新；成功变更的跨会话回退使用 Git。

用户已授权：整理设计，确认技术上可行后开始实现。本记录承接本次对话，不引入模型提供商或 MCP 依赖。

## 范围与验收

- CLI 对外提供可发现、结构化、可预览的项目修改能力，复用当前契约与事务。
- 普通作者文件和已打开文本发生外部变化时，无需关闭项目即可采纳；文档/资源索引和打开视图一起更新。
- 文件尚未写完、损坏、发生本地编辑冲突时，不覆盖当前内容；显示原因并允许重试。
- 采纳外部版本建立新的保存基线并清除旧 Undo/Redo，Git 负责回退外部修改。
- 外部 CLI 的批量发布不能让 Editor 采纳其中间状态。
- 提供可交付给外部 AI 工具的项目创作 Skill、Git 工作流程及三类创作示例。
- 已有本地化改动保留；功能只依赖 Editor 层，不进入 Core/Runtime。

## 设计决策

- 首版以项目会话为冲突单位：有已应用未保存内容或未提交输入时，自动采纳暂停。这样可以保留本地 Undo 与草稿，避免为局部自动合并增加一套版本合并机制。
- 用户可明确放弃当前作者修改并从磁盘刷新；执行前保留作者恢复材料。未应用的角色/变量面板输入沿用既有来源冲突规则。
- Contracts DLL 变化单独报告，需重建契约 scope；普通内容热重载不替换正在使用的契约。
- 文件监听只提供变化提示；哈希核对、候选结构校验和发布门内复核决定能否采纳。
