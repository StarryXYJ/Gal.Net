# 实现自审

结论：pass-with-follow-up。本记录是实现后的自审，不宣称独立 agent 审核。

审阅范围：目标/设计/阶段记录、CLI 路由和 manifest 校验、候选磁盘读取、项目保存基线、历史捕获门/发布门顺序、输入草稿、打开 Group/文本页面、资源刷新与项目 scope 关闭。

已核对的关键边界：源文件/载荷过期拒绝；新增目标不存在条件；批次中途发布失败补偿；外部坏 JSON 不改变活文档；自动采纳不覆盖本地编辑；显式放弃不跳过输入法/异步输入；取消草稿后当前字段仍能继续提交；自己的保存不清空历史；外部删除/恢复 Group 不遗留旧投影；外部采纳后继续保存不会使用旧 Repository/settings/文本基线。

审阅中修正：引用查询正常返回的 `references.partial` warning 不能以诊断数量判断为错误；文本编码变化应重新判断可编辑性；内容会话初始化失败应释放已创建 scope；资源通知也必须等待外部文件事务结束。

验证证据见 [summary](summary.md)。后续事项：大型项目性能、原生 IME 人工验收、可选契约 scope 无关闭重建，以及需要时的更细粒度冲突合并。它们不属于当前普通内容热重载已实现路径。
