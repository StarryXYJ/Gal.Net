# 阶段计划

## P1：通用外部内容热重载 — verified

依赖：现有项目会话、文档服务与历史。

任务：候选快照/源哈希核对；会话安全采纳；项目级监听/周期复核；外部冲突与显式重新加载入口；四语状态反馈；Group/Graph/settings/本地化/受管理文本刷新；CLI 已有事务边界识别。

退出：干净项目外部修改自动反映在当前打开页面；坏文件和本地草稿不丢失；创建/删除/改名可刷新；旧历史清除；关闭/保存交错不复活旧 scope；相关回归与构建通过。

证据：Shared 回归 417 项、热重载/批次最终定向 19 项通过；Editor 相关最终 36 项通过，包含 5 项本次新增场景与项目 schema 生命周期回归，最后的文件面板/资源通知 4 项通过。实际 Headless 窗口中的文件监听、结构插入后的选中条目/行号、文本编码与二进制变化、组字保护及继续保存已验证。Editor 隔离输出构建通过，保留 4 项既有 Nullable/XAML 警告。

退出：单次批次可创建 Group 并导入资源、修改引用；预览无项目写入；过期来源拒绝；中间状态不被 P1 采纳；实际 CLI 验证通过。

证据：原生场景经真实 CLI dry-run/apply，包含角色、开发语言对白、等待演出及图片/sidecar；Group 定向 dry-run 编译通过。来源哈希、目标哈希、资源配对、静态删除引用和第二个文件发布失败补偿均有通过用例；CLI 自带 Skill 文件已在输出目录验证。
