# 默认项目视觉内容清单

本清单区分本 feature 实施内容与后续候选；最终验证状态以 phase-plan / summary 为准。

## 第一批实施（P1–P4 已验证）

| 分类 | 内容 | 行为 |
|---|---|---|
| 效果 | Bloom | 亮部阈值、半径、强度 |
| 效果 | 高斯 / 方向模糊 | 可动画半径，组合横纵两遍 |
| 效果 | 暗角 | 中心、半径、柔和度、强度 |
| 效果 | 调色 | 曝光、饱和度、对比度、暖冷色 |
| 效果 | 图层 Z 景深 | 明确选定参与图层，每次绘制读取当前 Z，焦点与范围可动画 |
| 程序图层 | 动态集中线 / 速度线 | 时间、速度、密度、中心、方向、闪烁、颜色 |
| 转场 | 柔边擦除 / 径向开合 / 噪声溶解 / 百叶窗 | 图层 shader 遮罩，进度可动画 |
| 转场 | 图片遮罩溶解 | 作者提供遮罩图；通用 shader texture 参数绑定已实现 |
| 转场 | 模糊交叉淡化 | 双层淡化与模糊包络 |
| 演出 | 震动 / 跳跃 / 点头 / 摇头 / 颤抖 | 相对叠加并以零偏移结束 |
| 演出 | 定向推近 / 推拉 / CG 缓移 | 锚点与方向分开，可保留终态 |
| 演出 | 淡入淡出 / 滑入滑出 / 弹入 | 接受目标图层及明确参数 |
| 演出 | 集中线闪烁 / 冲击组合 | 自建程序图层，时间线驱动并清理临时实例 |

已有 crossFade、slide、blinds、fadeBlack、fadeWhite、fadeColor 保留。

## 后续候选（此次不宣称完成）

- 效果：径向与缩放模糊、胶片噪点/划痕、色差/故障、波纹/热浪、局部聚光/轮廓光、像素化/反相/色阶化。
- 转场：缩放切场、曝光闪光、像素化、故障、翻页/幕布。
- 编排：说话人强调、镜头跟随、心跳、回忆/梦境、章节标题、多段黑场演出。
- 氛围：雨雪、樱花、尘埃、萤火虫的粒子与调色配方。
- 进阶景深：单张图片深度图、遮挡边缘处理、散景、真实相机参数。

后续项有些可用已有 Entry 手动组合；需要独立验证其产品参数和生命周期后才成为默认预设。
