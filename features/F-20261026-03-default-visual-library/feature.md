# 默认视觉效果与演出库

状态：implementation（P1 已验证，P2–P4 待完成）

## 原始目标

默认项目提供更多 SkSL 效果（Bloom、模糊、暗角、按 Z 景深）、转场与通过组合 Entry 编译的动画预设。集中线必须动态，优先 shader 图层；整理候选内容到文件并按 feature 流程实施。

## 范围与验收

- 提供可随默认项目部署、可编辑、按需启用的效果资源，不能只在 GameTestCase 可用。
- 集中线由时间动画驱动，支持径向与定向运动、闪烁，不依赖静态贴图。
- 第一批实现上一轮明确推荐的 Bloom、模糊、暗角、调色、Z 景深、柔边擦除、遮罩溶解、模糊转场、震屏、定向推近、集中线、登退场、冲击组合，并扩展复用同一基础能力的预设。
- 完整候选清单见 [catalog.md](catalog.md)，明确实现与后续范围；不将列表中的全部研究项视为已实现。
- 组合编译为现有 animation.play 时间线及 effect/layer 等原语；保持 Core/Runtime 平台无关。
- 每种 shader 不单独新增 Entry，效果统一使用 effect.apply / effect.stop；具有编排价值的转场与演出提供复合 Entry。
- 初始化部署项目 shader 资产及用途绑定；编辑器创作时将实际资源 ID 填入预设参数，作者可覆盖。编译使用已保存的显式引用，不依赖隐藏默认 shader 或固定 GUID。
- 校验替换 shader 与配方所需 stage、参数类型和动画能力匹配，确保资源依赖检查及导出识别生成时间线中的引用。
- 校验 shader 编译、像素行为、时间变化、组合展开与清理、项目创建部署；更新用户手册。

## 约束与假设

- 用户本轮已授权实现代码，无需再次确认。
- 默认有资源不等于默认开启强后处理。
- Z 是图层排序；景深按图层 Z 计算，不承诺单张图片内部的真实几何景深。
- 不覆盖当前编辑器作者一致性工作区修改。
- 不引入来源不明的第三方 shader；复用本仓库示例或原创实现。
