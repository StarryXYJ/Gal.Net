# 桌面发行目录与统一 pak 内容根

- 状态：verified（本地实现与范围内验证完成）
- 授权：用户确认目录、galpak 外层 pak、开发/玩家构建方案后要求开始实现。
- 目标：应用根只含入口 EXE 和目录；依赖置于 lib，说明/许可证/发行清单置于 docs；Sample 双击加载同级 pak。
- 范围：galpak v2 的 pak/ 外层、v1 读取兼容、安装器、Sample 参数编译开关和用户 profile、Windows 发行脚本与验收、开发包。
- 非目标：体积优化、裁减媒体能力、AOT、移动端发行、自动迁移或删除旧存档。
- 验收：新包普通解压与安装得到一致内容；安装不产生 pak/pak，不覆盖不同内容；两种 .NET 部署均能从不同工作目录启动；开发包能解析参数并编入调试，玩家包默认固定 pak；项目 profile 不依赖安装位置或 buildId；契约字节身份保持。

- 无待用户确认阻塞；旧包兼容读取，旧用户数据保留，新布局不自动覆盖已有内容。
