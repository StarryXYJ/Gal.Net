# 天气与通用粒子：待设计方向

状态：方向记录，部分已由 2026-11-04 用户确认替代。天气仅为普通粒子参数预设，不新增粒子生命周期能力；旧天气条目由普通粒子与现有编排替代。以下关于新增生命周期的内容仅保留为历史讨论。

实现记录：默认契约项目在 `Buildin/Presets/entries.json` 保存五种普通粒子预设，固定 ID、可编辑且禁止删除；发布包不包含此作者数据。原 `preset.weather` 已移除，GameTestCase 改为 `particle.play` / `particle.stop`，无自动迁移旧项目。验证包括粒子渲染 11 项、内置 Entry 448 项、样例集成 8 项、编辑器预设 4 项。运行期粒子生命周期未修改。

## 目标

把雨、雪、花瓣、尘埃、萤火虫作为普通粒子的创作预设；粒子发射与生命周期能力应可用于其他效果，不依赖单独的天气 Entry。选择预设后生成可继续编辑的普通粒子参数，运行时不依赖天气类别。项目默认贴图的独立资源目录另见 [内置资源设计](../F-20261026-03-default-visual-library/builtin-resource-design.md)。

## 已有能力和待设计问题

- 当前 `preset.weather` 编译为 `timeline.play`，通过普通 `particle.play` / `particle.stop` 创建和停止发射器；持续模式、指定时长、实例 ID 和结束时自然排空属于现有可观察行为。
- 普通粒子已有多种形状、速度范围、随速度朝向、重力、噪声、径向运动、生命周期曲线、停止后排空，以及部分发射器属性动画。径向雨已直接使用普通粒子。
- 需设计持续和定时发射、跳过与取消、独立实例交叠、同 ID 替换、发射量与最大数量的预算；是否需要新增发射器状态或可复用现有时间线，须先比较实现及存档语义。预算如果会调整有效速率，应明确向作者展示，不得静默改变全部普通粒子。
- 粒子当前尺寸等比缩放，独立宽高缩放可使雨加粗而不变长；需设计动画、贴图翻转及既有参数含义。
- 现有存档恢复发射器定义但不保存每颗粒子的实时位置和年龄。定时发射是否恢复剩余时间、快进后保留什么状态，必须在设计中明确，不能默认声称已有该能力。
- 预设应生成确定的普通参数；画面尺寸、风速等何时取值需要明确。按内置资源设计的用户确认，默认纹理使用跨项目固定 ID，作者可在单条预设改选，不通过项目级用途绑定填充；改变默认预设不应悄悄追改已创作条目。
- `preset.weather` 的既有作者数据、生成的时间线和存档兼容/迁移方式尚未决定；GameTestCase、Editor 选择器、引用分析、正式文档和回归须覆盖。

现有天气回归 `PresentationLibraryTests.Weather_owns_one_emitter_until_stopped_and_has_a_valid_particle_definition` 的 Rain 宽度断言仍使用放大前上限；2026-11-04 运行结果为 4 通过、1 失败。后续实施应按最终视觉契约修正并验证，不应以删除断言掩盖尺寸变化。
