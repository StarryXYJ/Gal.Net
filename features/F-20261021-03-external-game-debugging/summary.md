# 外部游戏调试实现总结

状态：verified-with-follow-up，2026-10-22。核心用户范围已实现；没有把既有测试失败或固定预计算延期写成完成。

## 交付行为

- “测试”菜单与项目级调试 Dock：本地应用路径/参数、保存校验编译后启动、IDE 等待连接、可选开始回调、暂停/继续/作者单步、停止/重开/断线。开发者显式启用，标题页连接与 Engine 生命周期独立。
- Player/Save 当前实例变量面板：权威刷新、手工提交、草稿保留、类型/原值/身份冲突校验；不产生作者历史。Player 修改同步桥接服务，默认宿主停止/释放后刷新测试 profile。
- Graph 与作者 Entry 独立运行高亮、Group/Entry 右键定位、唯一完整多选链优先、有界边/出口路线选择。SourceMap 保留作者映射，不能用 compiled 数字 Id 猜 raw 序号。
- 定位通过忽略 Entry/Graph/Choice 条件的场景追帧实现，保留当前变量并跳过持久副作用；回跳恢复最近自然入口，前跳先收束活动呈现。目标前暂停，显式执行只豁免目标作者展开范围一次。任意断开的 Group 可显式从初始场景独立测试。
- 每 Group 最多一份最近自然入口，默认总预算 256 个 Group / 64 MiB 序列化 payload，LRU 淘汰；普通读档失效。提供追帧耗时/指令数与缓存统计；不预跑所有路线。
- `SkipToGroupEndAsync` 提供普通玩家当前 Group 末尾追帧底层功能，保持默认条件/副作用；停在出边前，下一次 Advance 才跨组。

## 边界

Runtime 不依赖网络/Editor/Avalonia；可选 GalNet.Debugging 依赖 Runtime，提供 TCP 与默认 Engine 适配；Avalonia 宿主只提供中立可选绑定回调。IGameRun/IGameRuntime 未为调试增加庞大接口。项目组合根决定是否启用、模块重放策略和开始/停止回调。

协议使用 loopback、随机邀请、内容/项目/可选契约指纹、运行身份与执行代次；有帧/并发上限，超大响应明确报错。测试 profile 与正式玩家目录分离。断线默认清断点并解除暂停，不终止 App。

## 验证与保留项

完整命令、初轮失败、修复与隔离基线见 [phase-6.md](phase-6.md)。Runtime 112、协议 10、存储 22、Editor.Shared 384、架构 47 项通过。Editor 排除两项在旧提交 `40ae34d` 同样失败的布局用例后 255 项通过；Integration 排除一个既有图像变体 Assets fake 失败后 111 项通过。真实原生 Sample 显式跨进程闭环通过，正常退出码 0；解决方案构建 0 errors。

首版为 150ms 全量轮询，没有增量事件流。热点前缀和固定入口预计算缺少全状态证明而延期；存在性 Definite 不被当作完整场景固定。单次合成逻辑测量中，入口缓存将目标前重放从 2151 条减为 150 条，最终模块状态相同；不代表真实媒体耗时。

尚未逐一人工检查文件选择器、多路线弹窗视觉、音视频/特效全部组合；流程暂停不完整冻结媒体时钟，没有专用重复环次数编辑器。相关局限均在手册中说明。
