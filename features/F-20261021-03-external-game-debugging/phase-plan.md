# 外部游戏调试阶段计划草案

状态：in-progress；新增先行 P0 完成 Runtime 边界追帧，P1–P6 按依赖继续。依赖与语义以 [design.md](design.md) 为准。

修订：用户明确跳转为“选定路线、忽略条件追帧”；原 P4 历史回溯/P5 历史分叉方案被本版替代。P4 先保证无缓存正确性，P5 再优化，避免将优化当成定位的必要前提。

## 通用规则

- 每个实施阶段完成适用测试/构建、记录结果和已知限制后，提交一次 Git，并向用户报告 commit。
- 只提交本阶段所属改动，不混入其他 feature；不以接近预算或只有单元测试通过伪报 verified。
- 阶段记录写明实际变更、测试命令/结果、未执行检查与偏差；已验证行为再同步 spec/manual。
- 阶段大小可因执行门/恢复机制的实际耦合调整，保留原因；不让未交付定位能力显示为可用。

## P0：Runtime 当前 Group 末尾追帧

- 记录：[phase-0.md](phase-0.md)。独立提交在本阶段完成。

- 记录：[phase-0b.md](phase-0b.md)。后续 P2–P4 复用此基础；尚不宣称 UI 已验收。

- 状态：in-progress。前置：设计范围明确。
- 拆分：P1a 独立协议与真实 loopback 连接；P1b Sample/Editor 的启动与连接交互。先做 P1a，再让 UI 复用同一通信模型，避免临时内嵌协议。

- 退出：真实 Editor→外部 Sample 的连接/开始/停止闭环通过，相关构建与架构检查通过，阶段记录及独立提交完成。

## P2：当前运行变量 Dock 与同步

- 状态：in-progress；核心面板与同步已验证，见 P2a。前置：P1。
- 模块：Runtime 受控查询/写入、宿主变量适配、调试客户端模型、Editor Dock。
- 任务：Player/Save 全量及增量，独立 DTO，类型化编辑与手动应用，每变量冲突版本、运行代次校验，草稿保护和事件回显；测试 profile 隔离。
- 验证：实际游戏修改刷新面板，面板修改影响后续条件；两作用域及服务缓存一致；类型/数值边界，旧运行/同值/冲突，关闭重开、增删恢复和断线重同步；作者 dirty/历史不变。
- 文档：实例变量与作者变量区分、同步/持久化语义、默认测试数据目录。
- 风险：现有查询返回内部引用；直接改服务导致当前 Runtime 不变；前缀归一化误写。
- 退出：真实面板双向修改闭环和生命周期回归通过，记录及独立提交完成。

## P3：执行边界、位置、暂停与断点单步

- 状态：planned。前置：P1；集成回归包括 P2。
- 模块：Runtime 执行门/控制流、编译映射交付、调试组件、Editor 高亮与操作。
- 任务：作者/primitive 双向映射，当前展示与下一执行位置分离，Group/Entry 实时高亮与控制流事件；流程暂停/恢复、作者断点、单步和 Choice 操作。
- 验证：Composite 一次命中、条件跳过、循环访问、阻塞自然完成与暂停交错；Choice 结果过期；自动推进不绕过暂停；暂停不持门等待 Editor；内容版本不一致禁用错误映射。
- 文档：暂停与媒体冻结边界、推进与单步区别。
- 风险：暂停只拦玩家 Advance 而遗漏内部 continuation；引入第二个执行调度器。
- 退出：各执行入口共用门禁，真实高亮与断点/Choice/步进验证通过，记录及独立提交完成。

## P4：指定路线、忽略条件的场景追帧定位

- 状态：planned。前置：P2、P3。
- 模块：纯路线规划、Runtime 有界执行策略、调试定位协调、宿主场景重建和 Editor 右键/路线列表。
- 任务：合法完整多选链优先；边/出口级路线及歧义选择、循环边界；Entry/分支/Choice 条件只在本次追帧中忽略；同组较早/较后及跨组定位；无缓存时从明确基线构建；目标前暂停与一次目标执行语义；变量/副作用策略确认后落实。
- 验证：B→C→D→E 选中链、选中集合乱序/分叉/断链、平行边、非 Group 中转、多路线候选上限；false 条件仍追帧、非法参数仍拒绝；同组倒退不残留后续图层；目标定位不跳过 Composite 开头；变量保持策略与未知插件；取消/停止、旧 Choice/事件失效。
- 文档：基线、路线、忽略条件边界、变量策略、目标落点和合成场景含义。
- 风险：把忽略条件扩展到忽略参数错误；默认拿当前场景向过去重放；候选全路径指数爆炸；永久修改原内容条件。
- 退出：不依赖缓存的 Graph/Group 跳转闭环通过，普通执行条件不受污染，记录及独立提交完成。

## P5：按需缓存、固定场景锚点及性能验证

- 状态：planned。前置：P4。
- 模块：调试场景缓存、独立 IgnoreConditions 分析策略/证明结果、纯状态 reducer 和宿主恢复适配。
- 任务：按需缓存合法 Group 入口和热点 Entry 前缀；内容/资源/契约/模块/变量输入/基线/路线前缀 cache key；LRU 字节预算；仅对白名单、证明完整且一致的域预计算共享固定锚点，其他使用路线专属缓存；后台预算/取消。
- 验证：命中/未命中语义等价；相同对象不同资源/位置/音轨不能错误合流；未知对象、部分分析、循环不收敛不授予固定性；变量/资产/模块变更失效；不同条件策略不串缓存；大型分支图、长 Group 的首次/重复定位耗时、缓存字节与 UI 响应。
- 文档：缓存范围/失效/内存预算，固定与部分固定的证据边界，性能测量结果。
- 风险：将只有 Definite 候选等同完整快照；离线运行自定义 Entry；预计算拖慢项目打开；缓存媒体句柄。
- 退出：P4 无缓存基线回归保持通过，缓存等价与内存上限通过，有性能测量证明收益；不能证明的固定预计算明确延期，记录及独立提交完成。
