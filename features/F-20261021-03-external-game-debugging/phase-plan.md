# 外部游戏调试阶段计划草案

状态：proposed；P1–P6 均为 planned，尚无业务代码实施。依赖与语义以 [design.md](design.md) 为准。

## 通用规则

- 每个实施阶段完成适用测试/构建、记录结果和已知限制后，提交一次 Git，并向用户报告 commit。
- 只提交本阶段所属改动，不混入其他 feature；不以接近预算或只有单元测试通过伪报 verified。
- 阶段记录写明实际变更、测试命令/结果、未执行检查与偏差；已验证行为再同步 spec/manual。
- 阶段大小可因执行门/恢复机制的实际耦合调整，保留原因；不让未交付定位能力显示为可用。

## P1：最小跨进程连接与运行绑定

- 状态：planned。前置：设计范围明确。
- 模块：可选调试组件、传输、游戏组合根/宿主适配、Editor.Shared/Editor。
- 任务：协议/能力/身份，显式启用，App 与运行生命周期分离，启动配置与等待外部连接，可选开始回调，停止运行，基本日志与连接状态。
- 验证：未启用不连接；有/无开始回调；标题页连接后进入游戏；重开旧请求拒绝；断线、错误项目、指纹和协议不符；默认宿主与最小自定义适配。
- 文档：接入示例、启动配置与协议约束；按实际依赖更新架构测试。
- 风险：调试服务越过宿主生命周期直接拥有 Engine；机器路径进入发行设置。
- 退出：真实 Editor→外部 Sample 的连接/开始/停止闭环通过，相关构建与架构检查通过，阶段记录及独立提交完成。

## P2：当前运行变量 Dock 与同步

- 状态：planned。前置：P1。
- 模块：Runtime 受控查询/写入、宿主变量适配、调试客户端模型、Editor Dock。
- 任务：Player/Save 全量及增量，独立 DTO，类型化编辑与手动应用，每变量冲突版本、运行代次校验，草稿保护和事件回显；测试 profile 隔离。
- 验证：实际游戏修改刷新面板，面板修改影响后续条件；两作用域及服务缓存一致；类型/数值边界，旧运行/同值/冲突，关闭重开、增删恢复和断线重同步；作者 dirty/历史不变。
- 文档：实例变量与作者变量区分、同步/持久化语义、默认测试数据目录。
- 风险：现有查询返回内部引用；直接改服务导致当前 Runtime 不变；前缀归一化误写。
- 退出：真实面板双向修改闭环和生命周期回归通过，记录及独立提交完成。

## P3：执行边界、位置、暂停与断点单步

- 状态：planned。前置：P1；集成回归包括 P2。
- 模块：Runtime 执行门/控制流、编译映射交付、调试组件、Editor 高亮与操作。
- 任务：作者/primitive 双向映射，当前展示与下一执行位置分离，Group occurrence、控制流事件；流程暂停/恢复、作者断点、单步和 Choice 操作。
- 验证：Composite 一次命中、条件跳过、循环访问、阻塞自然完成与暂停交错；Choice 结果过期；自动推进不绕过暂停；暂停不持门等待 Editor；内容版本不一致禁用错误映射。
- 文档：暂停与媒体冻结边界、推进与单步区别。
- 风险：暂停只拦玩家 Advance 而遗漏内部 continuation；引入第二个执行调度器。
- 退出：各执行入口共用门禁，真实高亮与断点/Choice/步进验证通过，记录及独立提交完成。

## P4：调试检查点与历史回溯（包含跨 Group）

- 状态：planned。前置：P2、P3。
- 模块：调试历史协调、Runtime 安全恢复、GameHost/展示恢复、测试 Player/进度适配。
- 任务：完整性标记的 DebugCheckpoint、沙箱 Player/必要宿主状态、预算与回溯范围；历史输入和访问身份；从兼容检查点重放到已访问目标；同组/跨组统一定位、历史编辑分叉与旧事件失效。
- 验证：后面取得的 Player 值不泄漏回过去；普通存档不回滚 Player；跨 Group 场景继承；A→B→A 循环访问区分；变量手改分叉；旧检查点、缺状态、淘汰、恢复失败/取消与停止交错。
- 文档：检查点格式与能力、历史语义、可恢复逻辑范围和媒体限制。
- 风险：将稳定快照误认为任意瞬间检查点；只恢复 Save；副作用重放；未知插件能力误判。
- 退出：受支持能力上的历史正反定位与跨 Group 回归通过，无完整上下文时明确拒绝/降级，记录及独立提交完成。

## P5：未访问目标定位与测试预设

- 状态：planned。前置：P4。
- 模块：目标追帧策略、重放能力/输入边界、宿主预设、Editor 目标菜单。
- 任务：沿实际条件定位、明确 Choice 路径、预算与不可达结果；从预设开始、保留逻辑状态强制定位并标记合成上下文；最小模块/宿主重放屏障适配。
- 验证：拓扑可达但条件不可达、未选 Choice、循环预算、外部副作用屏障、目标之前停下、合成基线后可正常调试和回溯；取消结果可解释。
- 文档：三种目标定位方式、预设作用域与插件接入义务。
- 风险：自动猜分支导致测试错误；CatchUp 重复外部写入；尝试为任意插件伪造确定性。
- 退出：明确路径/预设下的未访问目标定位通过，屏障和能力不足可行动，记录及独立提交完成。

## P6：集成验收、独立审核与收尾

- 状态：planned。前置：P1–P5。
- 模块：跨进程集成测试、接入文档、相关架构规范与 feature 记录。
- 任务：默认宿主与最小自定义宿主真实接入，跨进程断线/重开/旧事件，较长历史预算，变量面板和定位交互验收；整理 review/summary 和稳定文档。
- 验证：适用测试与解决方案构建、UI 实际交互、人工媒体/文件选择检查；报告环境跳过与遗留项。
- 风险：只测进程内 fake、未测真实传输/UI；将人工未验收项写为已通过。
- 退出：需求逐项对照、未完成事项明确，文档与代码一致，独立提交并报告 commit；满足范围后才标记 feature 完成。
