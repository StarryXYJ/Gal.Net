# 调试面板 UI 整理

日期：2026-10-23。状态：verified。

## 需求和方案

用户希望参考 VS 使用无背景图标按钮，改善游戏调试面板 UX，将当前状态放在下面并保持整齐。本阶段复用已有调试命令及可用性，不修改协议、游戏行为和变量同步策略。

- 顶部工具栏按启动/连接、运行控制、步进/跳转/断开分组，统一 30px 透明图标按钮；保留悬停/按下/键盘焦点/禁用反馈、四语提示与无障碍名称。窄 Dock 按功能组换行。
- 启动配置继续默认折叠，字段使用独立标签，参数文本区域有高度上限。
- Player/Save 共用两行变量模板，显示名称、类型、当前值和草稿，应用与重置改为图标；已有冲突状态增加文字提示。
- 底部固定连接指示与当前状态；错误限制最大高度、支持滚动和复制，不挤占整个变量区。空变量/Choice 与处理状态提供四语提示。
- ViewModel 仅增加 HasError 展示通知，命令实现不变。
