# P0b：可选 Runtime 调试控制与入口场景

状态：verified。阶段提前原因：外部 App 运行适配必须调用受控调试端口，不能把 Runtime 对象/字典直接交给协议层；先验证核心，再接 UI。

AttachDebugging 显式创建借用会话；不引用 Editor/网络。InspectAsync 在执行门内复制变量、活动位置和 Group 编译身份。变量提交检查代次、UID、类型与观察到的原值，Float 限有限数；当前实现采用原值比较，并非每次写入都有独立 revision 的事件日志。

每 Group 仅保存最近一次自然进入时的入口逻辑场景；组内重建不覆盖它。场景缓存不存变量、Task 或平台句柄。回跳替换场景状态根，保留当前变量；显式路线验证真实后继后无条件追帧，未知指令必须声明 Scene/Ignore，否则预检拒绝。调试写入隔离器阻止重建条目通过 Runtime 写变量，不重复标记已读。

Pause 阻止普通推进、自动播放与自然完成后的继续；Choice 结果可延后至 Resume。普通 Restore 使缓存/代次失效；Stop/Restore 取消并清理正在进行的调试定位，旧操作不回写新状态。宿主须先停止 Engine、再释放借用调试 binding。

验证：Runtime.Tests 全部 104 项通过。新增 8 项覆盖重复回跳不覆盖入口、自然重进覆盖单份入口、跨 Choice 指定路线且忽略条件/变量写入、非法路线/未知模块预检、自然完成暂停、变量复制/类型/代次，以及 Stop/Restore 打断定位。尚未声明真实媒体或跨进程 UI 验收。
