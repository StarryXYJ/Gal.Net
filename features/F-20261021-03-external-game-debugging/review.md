# 设计审核

结论：pass-with-follow-up，用户已授权按阶段实施。此结论针对当前设计，不表示 P1–P6 已实现。

- 已补齐：每 Group 只保存最近自然入口；恢复/重建不覆盖入口；同组回跳恢复场景但保留当前变量。
- 已补齐：Group 末尾不能通过 Stop 实现；必须在出边前停下，Manual，后续显式推进才跨组。
- 已明确：普通玩家追帧执行原有条件/逻辑写入；调试场景定位独立控制条件和副作用，不能默认共享语义。
- 后续验收重点：跨 Group 非阻塞呈现的清理/恢复，缓存真实完整性与独立 DTO，恢复代次、路线预算及真实跨进程 UI 验收。
- 无需阻塞 Runtime 基础阶段；完整功能仍须完成后续各 Phase，不能用 P0 测试代替交付验收。
