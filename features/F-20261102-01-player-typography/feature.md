# 玩家字号档位与富文本相对字号

日期：2026-11-02。状态：实现与自动化验证完成；移动真机观感未验证。

用户要求从移动端可用性讨论进入 fast feature，四档“小、较小、较大、大”分别对应一套可配置的语义字号，移动端默认较大、桌面默认较小；富文本支持比例和加减相对字号。

因需要扩展 Core 的公开富文本 token，按 fast-track 入口规则转为普通分阶段流程，保留设计、兼容性与测试证据。

范围：默认玩家设置、Sample 源码中的四套字号/平台默认值、页面标题/分组/正文/强调/操作/辅助字号、ADV/NVL/历史及富文本字号渲染。玩家选择持久化，恢复不写回默认值。较小档保持桌面现有设计字号。

非目标：底栏跨黑边、触摸区域、外部页面响应式重排、竖屏布局、Editor 字号、Logo 与品牌画面调整。固定场景坐标和画布比例不变。本项提供字号机制，不声称解决全部移动适配。

验收：四档能切换且重启恢复；项目可独立修改各角色的字号与平台默认档；标题/对白/姓名/历史等应用资源更新；字号变化不重启打字或改变完成状态；相对比例、正负偏移、嵌套恢复、非法输入均有回归；已存在的粗斜体、颜色及打字指令不受影响。移动端实际阅读大小仍需真机确认。
