# 项目内置资源目录

状态：implemented。2026-11-04。

## 目标与范围

新项目将默认视觉 Shader 和现有天气纹理放在项目根 `Buildin/`，与作者 `Assets/` 分开，统一扫描、预览、编辑、构建、运行和发布。内置资源在各项目有固定 ID；预设直接选择相应固定 ID，单条可改选；删除项目级默认映射。Editor 内禁止删除、移动或重命名内置资源，允许编辑内容及复制；外部破坏须报告。用户明确不要求旧项目迁移或兼容，不能静默改写已有项目。

不推进天气粒子通用化，不改变天气玩法、预设或渲染效果；只调整其当前内置纹理的资源归属及固定引用。保持现有其他用户改动。

验收：新项目内置文件和 ID 稳定；两根资源和引用在 Editor、预览、构建、导出及运行一致；项目内全局 ID/逻辑路径冲突被拒绝；固定资源删除/移动保护及外部损坏诊断有效；真实目录和 galpak 测试通过。验证限制与失败必须如实记录。
