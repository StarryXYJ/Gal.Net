# 实现总结

默认契约新项目将 16 个视觉程序和 5 个天气纹理及其 sidecar 写入 `Buildin/Effects/Default/`。这些资源跨项目使用固定 ID，预设使用固定默认引用，单条 Entry 可以改选；项目配置不再保存默认用途映射。GameTestCase 已迁移到新目录，旧项目不自动迁移。

项目资源提供器合并 `Assets/` 与 `Buildin/`，拒绝全局重复 ID 和逻辑路径。编辑器浏览、资源选择、资源 metadata、变体、预览、调试、构建及发布使用两根；构建和项目校验检查必需的内置资源及固定身份。内置资源内容可修改和复制，文件事务禁止删除、移动和改名固定资源及其父目录，副本分配新 ID。安装命令显式补入完整缺失资源，不覆盖作者内容。

验证覆盖多项目固定 ID、默认及自定义引用、双根冲突、文件事务保护、外部损坏、编辑器选择、GameTestCase 目录和 galpak 导出与读取、中英文剧情路径。共享编辑器测试 625/625、样例集成 8/8、编辑器定向测试 2/2、双根提供器 2/2。仅验证本机 Windows/.NET 环境；未进行其他目标平台的实际发布或人工 GUI 逐项验收。天气粒子机制和参数不在本 feature 范围内。

测试中发现手工拼装的默认契约发布夹具缺少必需资源，已补齐新项目结构。工作区中并行存在的其他更改未纳入此 feature 的实现范围。
