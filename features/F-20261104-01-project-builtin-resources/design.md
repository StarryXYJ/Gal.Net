# 设计

以 [内置资源提案](../F-20261026-03-default-visual-library/builtin-resource-design.md) 为设计基线。确认 `Buildin/` 可查看、内容可编辑；固定 ID 由单一目录声明，预设直接持有默认 ID 且可逐条改选，不再提供项目级映射；不提供旧布局迁移。天气粒子行为不变。

`Assets/`、`Buildin/` 分别是物理根，汇入同一资源集合，保持根内相对逻辑路径，项目范围内拒绝重复 ID 和路径，不依靠 provider 优先级覆盖。新建/安装、查询、预览、开发运行、打包及调试必须看到同一集合。输出仍使用现有 PAK 规则。内置文件内容属于项目，固定 ID 不表示跨项目字节相同。

在文件事务边界保护固定资源及包含它们的目录，不仅禁用 UI；外部删除、移动或更改身份、类型明确诊断，不自动补写。其副本使用新 ID。作者自定义项目无需隐式注入默认资源；使用内置默认引用但缺少资源时报告缺失。

依赖、检查、状态和发布实现以实测代码为准；若与现有管线约束冲突，先记录偏差再实施，不假设仅新增 provider 已解决 ID/路径碰撞。正式规范只写入经过验证的实现。
