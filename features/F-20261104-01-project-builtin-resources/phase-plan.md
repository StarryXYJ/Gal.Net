# 阶段计划

## P1 固定身份与默认创作 — complete

声明固定资源身份，将新项目默认资源写入 Buildin，预设默认选择固定 ID，移除项目用途映射与 UI。验证多项目身份一致、显式覆盖、缺资源诊断及不覆盖作者文件。

## P2 统一资源读取与发布 — complete

与 P1 交叉推进：固定模板落盘至 Buildin 后，需要双根 provider 才能验证项目创建与校验。将两根纳入一致的索引、构建、预览、导出、运行、调试与资源依赖，检测跨根 ID/路径碰撞。以真实资源、目录导出与 galpak 验证；保留资源租约和缓存所有权。

## P3 编辑器保护与交互 — complete

基础保护与 P2 并行接线，最终验证依赖 P2。显示两根并支持选择、编辑、复制；共享文件事务禁止删除/移动/改名固定资源及父级。验证历史、外部变更、异常与 GUI/CLI 一致性，保护现有并行工作区修改。

## P4 整体验证与收尾 — complete

前置 P1–P3。验证新项目端到端、资源依赖、固定默认 ID、发布与冲突，并同步正式规范、手册及总结。失败、未验证平台和偏差保留记录，不伪称完成。

验证：共享编辑器测试 625/625；样例集成 8/8（包括目录与 galpak 导出）；编辑器相关测试 2/2；双根提供器测试 2/2。新资源缺失、跨根冲突与受保护事务均有定向测试。未进行跨平台实际发布或人工 GUI 逐项验收。
