# 通用资源名称与四类鉴赏

本次按对话确认的范围直接实现，未采用单独的前置 feature 设计流程。

## 实现结果

- 任意资源的公共 `AssetMeta` 支持可选 `displayNameKey`、`galleryUnlockId`。名称与鉴赏资格独立；ID 是全局唯一正整数，也是分类内排序依据。
- 编译与加载只取应用已实现的鉴赏类型和带 ID 资源的交集；不保留旧 `gallery` 数组或音频 Entry 的直接名称字符串。
- 资源 Inspector 编辑开发语言名称，内部稳定 key；i18n 资源名称子面板集中翻译。Group 从 Graph Inspector 配置，支持可选图片封面。
- 名称、ID、导入选项和翻译共享待保存作者状态与撤销；移动/删除包含受管理 sidecar，复制读取待保存内容并生成独立身份。复制先共享名称 key，修改共享名称时分离。
- 三套布局支持图片、视频名称与卡片提示；音频行只显示曲名、进度、播放/停止，长名称省略并保留完整提示，窄窗口改为两行。
- 场景回放提取单个 Group 并截断后续边，复制变量和进度写入环境，隐藏主游戏工具栏且禁止存档页导航；不要求原 Graph 中该 Group 孤立。任意自定义 Entry 的外部副作用仍由其模块实现负责。
- 音频提示采用资源名称和 `announceName` 开关；鉴赏试听与场景回放不显示音乐提示。
- GameTestCase 提供图片、视频、音频、场景各两个条目，含中英文名称；第二段视频为短片段，场景可独立完成并返回鉴赏。

## 后续调整：鉴赏导航与视频控制

- 三套布局的分类入口统一为水平居中的竖排按钮。
- 未解锁条目的标题统一为 `???`，音频列表及图片/视频/场景卡片均不暴露实际名称。
- 视频详情增加播放/暂停、进度跳转与时长；拖动时抑制后台位置回填，退出停止计时器和播放器，窄布局换行显示时长。
- 三套布局专项 9 项及两个真实样例视频的原生播放/暂停/暂停中跳转/恢复/退出测试通过；新增窄布局检查通过，完整展示层 349 项通过。Minimal 入口保留左下角返回按钮位置，与主题其他页面一致。

## 后续调整：聚合卡片标题与音乐预览

- 图片、视频、场景聚合卡片的标题独立于禁用预览按钮渲染，明确采用主题正文色；锁定标题 `???` 不再受按钮禁用样式影响，锁定预览仍不能进入。保留整张已解锁卡片的点击区域。
- 音乐使用一个播放器与按条目保存的预览位置/时长，切歌后其他条目显示原位置；播放/暂停互切，拖动未播放条目也可直接从所选位置开始。
- 各曲目预先解析总时长，进度条右下角、按钮左边显示主题次级色小字时长，宽窄布局共用同一个控件。
- 首轮真实音频在解析时长时原生崩溃，定位到 LibVLCSharp Parse 的内联完成回调中释放 Media；加入异步完成转发后，两个音频及解析中退出测试通过。未使用延时绕过。
- 界面专项 16 项、原生音频/取消/视频回归 5 项通过；完整展示层最终 358 项通过，文档与 diff 检查通过。
