## 已处理发现

| 发现 | 影响 | 处理和证据 |
| --- | --- | --- |
| 图集保存的是原 sprite 派生结果 | 安装兼容衣服覆盖后旧档被拒绝 | 候选恢复按逻辑选择重算，覆盖来源标记支持移除；真实 PAK 到呈现的双向读档集成通过 |
| 内部 debug replay/精简存档丢构建身份 | 原生打包 Sample seek 失败 | 当前引擎标记内部基线、复制源身份，原生显式用例通过；保留外部不匹配拒绝 |
| 映射 JSON 往返丢字典比较器 | 大小写变体可能分裂原资源映射 | DTO setter 恢复 OrdinalIgnoreCase，索引使用文件规范 ID，增加回归 |
| 默认切片未有实际内存观测 | 可能把阈值误写为内存预算 | 对比报告及文档明确整片缓冲限制，最终默认 32 MiB |
| 跨层安装夹具放在 Editor.Shared.Tests | 完整架构门禁失败 | 迁移到已有 IntegrationTests，移除 Storage 直接引用，保持白名单不变并重验 |
| FieldDescriptor 增加可选参数改变 CLR 签名 | 已编译的旧契约调用构造函数失败 | 保留旧八参数签名并转发；使用既有“编译旧 API/装载当前 Core”测试复验 |
| 资源相同但物理分片布局变化未进入指纹 | 可能向同一不可变目录写入不同分片集 | buildId 纳入格式标记和实际布局，重复导出稳定性与独立安装夹具复验 |

## 边界核对

- 项目唯一 Graph，章节命令只传初始变量；Graph/Group 资源身份没有变成多图产品。
- 依赖未知时拒绝不完整构建，显式声明不能自动增加根；编译不回写 sidecar。
- 剧情闭包只减本体，所有安装组合有执行夹具；整包缺席与部分/损坏严格区分。
- 覆盖包明确来源，priority/hash 稳定，一次映射不串联，夹带资源不隐式改本体；缺席剧情不被覆盖包激活。
- 资源面板与导出复用共享服务，作者定义进入项目历史，导出先私有快照，挂载控件验证实际操作。
- PAK payload 校验与索引区分，资源补丁准备期逐项验证；没有用排序 hash 冒充预期完整性校验。
- 正式文档保留文本整文件、本体 Gallery、保守剧情包存档和整片内存限制；未承诺 Gallery 补丁、热装卸或自动旧格式迁移。
