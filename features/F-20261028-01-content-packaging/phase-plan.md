# 单 Graph 资源化与内容分包阶段计划

状态：P1–P3 `verified`，P4–P6 `planned`。根据已确认的 [设计](design.md) 拆分；各阶段测试段落为计划，已执行证据见阶段记录。

范围和需求见 [feature 清单](feature.md)。用户已明确授权开始实现，并要求每完成一个阶段提交一次 Git；仅将已有验证证据的阶段标记为 verified。

## 1. 交付顺序

```text
P1 资源依赖与 PAK 用途契约
  → P2 单 Graph / Group 资源化与章节启动闭环
  → P3 本体及剧情补丁分包、安装与执行
  → P4 独立资源补丁导出和运行时覆盖
  → P5 编辑器作者工作区与资源补丁矩阵
  → P6 集成、格式策略与正式文档收尾
```

每个阶段完成后记录具体构建、用例和已知限制，再推进后续。中间阶段可以由低层集成夹具或现有无 GUI 入口验证，不要求先做完 GUI 才证明包可运行。仅为验证需要补充共享入口，不额外扩大成新一套 CLI 产品。

核心约束：项目只有一张 Graph；本体先收集该图的全部非补丁 Group；章节采用入口条件分支与新游戏初始变量；剧情补丁之间不扣除共享资源；资源补丁独立导出；优先级和 hash 决定覆盖；不做语言选包和 Gallery 补丁。

## P1 — 依赖 metadata 与 PAK 用途（verified）

2026-10-28：实现和验证完成，见 [P1 记录](phase-1.md)。资源层 89 项、图集/导出回归 12 项通过；反射关闭独立程序通过；完整 Release 解决方案构建通过（250 个 warning、0 error）。本阶段不启用未引用资源裁剪或剧情/资源补丁装载，分别在后续阶段接入。

### 目标与前置

前置：现有设计。形成后续资源化、分包和覆盖共用的协议，并以现有图集证明协议能实际贯通本地编译与 PAK 往返。

涉及 Core.Assets、Contracts.Builtins、Assets 的资源编译与 Archive/PakBuilder；沿用注册时的冻结目录和 JSON resolver。

### 工作

- metadata 的 `IAssetDependencies` 与直接依赖、预期类型、完整性结果；类型注册显式区分叶资源和未知依赖。
- 为图集等结构化资源注册适当 DTO。图集 payload 与依赖 metadata 同步生成，仅更新有效编译快照，不写回源 sidecar。
- 共用 PAK 格式增加版本化控制描述，区分 `base`、`story`、`override`，定义各自必需字段与合法组合。
- 统一资源 ID 规范化、依赖闭包和来源诊断。闭包不负责包归属，必需资源缺失/错误类型明确失败。
- 处理新增 metadata 的源生成序列化，明确新旧格式识别与错误，不默读旧格式为新包。

### 验证与文档

测试图集的直接依赖与递归收集、重复引用、未知依赖与显式叶资源、循环终止、缺资源/错类型；本地编译和 PAK 读取依赖一致；源 `.meta` 字节不变；metadata/payload 不一致拒绝。验证三种 kind 往返、未知 kind、非法字段组合和取消/坏归档。用实际反射关闭路径验证新 DTO。

在本阶段记录实际协议/API与格式决定；只有经验证的事实才同步 `docs/spec/assets.md` / `file-formats.md`。

### 风险与退出

风险：共用 AssetMeta 的注册迁移丢扩展字段或默认值；依赖遗漏被误判为空；PAK 格式变化影响现有导出器和 fixture。

退出：现有图集通过同一协议编译、打包、读取和验证，源文件不被修复写盘；三种用途合法性可独立验证；受影响旧入口已适配或明确拒绝不支持的旧格式。

## P2 — 单 Graph / Group 资源化与章节启动（verified）

2026-10-28：见 [P2 记录](phase-2.md)。唯一 Graph/Group 资源寻址和初始章节参数闭环已实现；完整构建、Runtime 123 项、GameHost 8 项、相关集成 18 项、最终编译/导出 23 项及反射关闭 smoke 通过。剧情分包与覆盖装载尚未接入。

### 目标与前置

前置 P1。先完成“唯一 Graph 与 Group 位于基础 PAK，Sample 自动启动并支持初始章节参数”的垂直闭环，本阶段可暂不拆物理包。

涉及 Graph/Group 文档与编译、Editor.Shared、开发/安装内容 provider、GameHost、默认 Sample、存档入口和 Editor Preview。

### 工作

- 固化 Graph/Group 的作者身份与 sidecar 布局，使 Graph ID、Group 资源 ID、节点 ID 明确分开；更新现有作者结构校验和源生成 DTO。
- 保留唯一 Graph 的作者结构，新增 Group 剧情包标记的作者真源；清单保存唯一 Graph 的资源 ID，不增加 Graph 列表、defaultGraphId 或选图 API。
- 将编译后的 Graph/Group 作为资源产出 metadata 和 payload，按资源 ID 加载，移除发行加载对固定 graph.json/Group 文件路径的依赖。
- Group 依赖按展开后的指令 schema 收集；Graph 引用携带包标记。动态引用不完整时保留可处置诊断。
- Sample 按清单自动加载唯一 Graph；Preview 与开发源使用同一有效编译事实，不改变项目只有一图的约束。
- 补齐新游戏初始 save 变量参数：初始化默认值后、开始执行前整批验证应用；读档不套用新游戏参数。章节由图入口条件分支选择。
- 存档仅补充内容包/版本兼容所需信息，不增加跨图身份字段或按图变量存储层；节点、游标和 save 变量继续在项目唯一 Graph 中恢复。

### 验证与文档

从开发目录、导出目录、安装后的 galpak 分别启动唯一 Graph，Sample 无需选图参数；清单缺失或引用错误明确失败，不扫描猜图。Graph 重命名/源文件移动保持资源身份，raw 不进入运行包。沿用现有自定义契约、未知作者内容保留和 Preview 流程回归。

验证同图重复新游戏不泄漏上次 save 值，初始章节参数在第一次分支前可见，整批参数无效时不执行入口，读档不被当前启动参数改写；player 解锁数据仍跨 Run 保留。

经验证后同步 Graph/Group 资源格式、初始变量启动/自定义 Sample 手册；保留本阶段尚未支持分包的事实。

### 风险与退出

风险：资源化改动破坏现有单图作者历史/文件操作；运行仍暗中读取 loose graph.json；初始章节参数应用晚于第一条分支；新 Run 的初始化与旧 save 值混用。

退出：唯一 Graph 在三种内容来源中均可按资源 ID 运行、保存和恢复，章节初始参数正确生效，源文件身份稳定，默认 Sample 与无 GUI 集成夹具均通过；不存在发行 loose Graph 回退掩盖缺失资源。

## P3 — 本体与剧情补丁闭环（verified）

2026-10-28：见 [P3 记录](phase-3.md)。分包、四种安装组合、损坏/部分安装、ZIP 发布和读档校验均通过。文本/人物留在基础完整文件；存档保守要求准备时安装的全部剧情包。大资源峰值观测交给 P6。

### 目标与前置

前置 P2。正常导出一次生成基础 galpak 和外部剧情 PAK；可独立安装任一剧情包，不依赖其他可选剧情包。

涉及构建规划器、GamePackageExporter、包目录/安装发现、GameHost 内容准备与运行调度。

### 工作

- 本体根覆盖唯一 Graph、全部非补丁 Group、UI/启动/额外资源及现有基础 Gallery 所需资源；不只扫描当前打开的 Group 或运行可达路径。
- 实现 `B` 与 `C(P)-B`，每个剧情包独立计算；复制资源同 ID 的内容及 metadata 必须一致。
- 明确 Group 引用的包边界，Graph 留节点描述、补丁正文只进入 story；普通必需依赖不能绕过此边界。
- 稳定排序、按未压缩编译载荷目标切 PAK、超限单资源独占，输出布局报告。阈值默认值依据实际内存验证选择。
- 同一次私有快照生成基础与剧情包、文本及人物贡献；目录导出与 galpak 共用准备/校验流程，失败不发布半包。
- 根据 `kind` 与清单发现完整 story 分片，验证项目/基础构建/资源闭包。安装器保留基础受管内容与额外包边界。
- 未安装剧情节点沿唯一正常出口跳过；坏包不得变成未安装。连续跳过、结束和空推进循环具备明确行为。

### 验证与文档

建立一张 Graph、多个普通/补丁 Group、两个剧情包、基础共享资源与补丁间共享资源的集成项目，验证：

- 本体用 X 时 A/B 均不带 X；仅 A/B 使用 X 时各自带 X；交换遍历顺序不改变结果。
- 仅安装 A、仅安装 B、全不装、全安装均执行正确路线；缺单分片、坏哈希、错基础构建、坏正文明确失败。
- 未安装剧情不要求其文本；已安装剧情缺默认语言文本仍失败；Gallery 沿旧基础路径运行，不新增补丁聚合。
- 删除当前存档必需的剧情包不能通过跳过恢复；分片重命名不改变包类型与完整性判断。
- 切包边界、超大单项、取消/故障输出和最终产物复验；用代表性项目观测加载峰值内存。

同步已验证分包算法、输出目录、包安装与跳过语义；操作手册不引入独立剧情补丁面板。

### 风险与退出

风险：Gallery 原基础聚合意外拉入补丁独有内容；本体递归越过可选 Group；包目录只认文件存在而不认完整性；补丁发布失败仍留下可挂载分片。

退出：一份正常导出产物可按上述四种安装组合独立运行；资源归属、文本和恢复检查成立；失败输出不会被识别成新完整包。

## P4 — 独立资源补丁服务与覆盖（planned）

### 目标与前置

前置 P1/P2/P3 的内容会话和包来源模型。先以共享服务和集成夹具完成独立导出与运行验证，再连接矩阵 UI。

涉及 Editor.Shared 导出、Assets 查询/Acquire/缓存、Storage 包发现、GameHost 会话和媒体实体化。

### 工作

- 定义每列的稳定身份、整数 priority 与 A→B 映射；默认 priority=0。每列导出一个 override PAK，带齐 B 的递归依赖，不依赖先导出 galpak。
- 来源明确的目标绑定，补丁携带资源不隐式替换其他 ID。Graph/Group 和控制描述不接受此面板覆盖。
- 固定 `(priority, finalPakSha256)` 顺序，较大者胜；hash 取完整文件字节，ordinal 比较，同 hash 去重，不引入语言条件、冲突阻断或手动冲突流程。
- 每次引用仅映射一次，嵌套依赖作为独立请求处理；类型和图集变体兼容性继续验证。
- 统一 ID 文件查询、Acquire、媒体实体化的有效视图，保留源文件定位视图。缓存隔离实际来源与版本，现有 handle/媒体租约所有权不变。
- 包集合冻结；首版在重启或重建相关会话时采用启停变化。剧情包缺席时，其资源映射不能使剧情被视为已安装。

### 验证与文档

独立导出衣服 A→B 图集并运行；覆盖单张 sprite、音频、视频的有效来源一致。验证 B 的完整依赖、未映射依赖无副作用、不同 priority、同 priority 的已知 hash 顺序、相同文件去重、文件名/目录枚举无关、多映射正常覆盖、语言切换不影响解析。验证 A→B/B→C 不串成链，旧 handle 安全释放，重建会话采用新包。缺目标、坏包及不兼容类型明确诊断。

同步覆盖解析和独立导出 API/手册；不写 Gallery 新语义或语言自动选包说明。

### 风险与退出

风险：只覆盖 Acquire 但 raw/media 仍走旧 provider；hash 包含不稳定导出元数据导致相同优先级重新导出改变胜者；夹带 B 依赖形成意外全局覆盖；缓存命中旧版本。

退出：无矩阵 UI 也能独立制作、导出和加载资源补丁；排序和来源全链路一致。确保不必要时间戳/随机序列不进入资源补丁文件，使同内容重复导出 hash 稳定；实际变更导致 hash 变化按既定规则接受。

## P5 — 编辑器作者入口与资源补丁矩阵（planned）

### 目标与前置

前置 P2/P3/P4 共享能力已验证。提供完整作者操作，不在 GUI 再实现一套依赖或打包逻辑。

涉及 Editor 的项目/Graph 文档、Inspector、文件面板、资源引用查询、项目历史/保存和本地化。

### 工作

- 保留单图作者工作区；项目级资源扫描覆盖该图全部 Group，包括未打开的正文和补丁 Group，不增加多图管理 UI。
- 默认应用模板的章节按钮示例共用带初始章节变量的启动能力。首页替换继续复用现有 DI/VM→View 注册，不重复实现既有扩展机制。
- Group 包名编辑、已有名称候选及正常导出整合；不提供额外剧情补丁面板。
- 资源矩阵行聚合唯一 Graph 及其全部 Group 的引用，包括补丁；显示使用位置、展开间接依赖、允许补充动态原资源。
- 原资源定位到编辑器文件管理器；新建/重命名/删除补丁列，单元格复用资源选择器并校验类型，显示/编辑包内 priority，独立导出当前列。
- 作者补丁定义随项目保存并进入现有 Undo/Redo/恢复机制；工作版与保存版明确，导出捕获一致作者快照，避免后台导出混入之后编辑。
- 删除/复制资源、Graph/Group 变化和外部项目修改更新矩阵引用；保留现有身份/事务边界，不把补丁面板状态藏成唯一真源。
- 面板文案进入现有编辑器语言资源；无语言条件列、Gallery 配置或冲突处理页。

### 验证与文档

验证单图内切换 Group 不串文档/草稿/历史；创建列、选资源、撤销、保存、重开和恢复得到同一映射；删除/复制目标资源后的引用诊断；定位原资源而非运行替换资源。实际挂载控件验证资源选择器、矩阵编辑/滚动和导出，避免仅靠 VM 赋值证明 UI 可用。覆盖后台导出快照、取消及失败提示。

发布面向作者的单图章节启动、剧情分包和资源矩阵操作手册；共享服务/API 文档指向真实实现。

### 风险与退出

风险：全部 Group 的资源引用扫描成本过高；项目草稿与保存版混淆；矩阵复用失效绑定；将打开的 UI 作为后台任务唯一数据源。

退出：用户可在编辑器完成单图的 Group 包名→正常导出，以及新建资源补丁列→选择替换资源→独立导出的两条流程；章节按钮示例使用初始变量，保存重开不丢定义，运行结果与共享服务集成夹具一致。

## 2. 当前决策与剩余工程选择

设计没有等待用户回答的产品阻塞。PAK 二进制具体字段顺序、作者 sidecar 布局和默认大小阈值是实现阶段根据现有结构及验证确定的工程选择，不需要为它们重新发起需求确认。

工程实现不能删去的边界：补丁部分安装不等于未安装；缺少依赖不等于空依赖；包的 kind 与资源 typeId 独立；覆盖不改变作者资源 ID；项目保持唯一 Graph；Gallery 不扩展。

范围修正记录：按用户明确要求移除原计划中的多 Graph 管理、默认/显式选图、跨图存档身份与按图变量隔离，P2/P5 及所有集成验收均改为单图；Graph/Group 资源化和初始章节变量保留。

若实施时发现与上述已确认行为冲突，记录原因并修订计划，不通过增加语言条件、共享包依赖或手动冲突流程绕开问题。
