# 设计

项目 `Presets/entries.json` 存版本、按类型过滤的预设列表、稳定 ID、名称和原始参数 JSON。它是作者文件，不属于 Assets 或运行时，保存前校验、立即事务发布；历史用前后字节及哈希检测外部冲突，不发布其他未保存的作者内容。已有托管文本与预设写入不能互相覆盖。

Field DTO 通过 `ExcludeFromPreset` 标记字段，生成器传递到不可变字段描述；应用时保存目标字段值。已有场景输出定义处理输出身份；嵌套 Timeline 重映射内部输出及相关引用。普通资源、场景目标与文本键保持原值，使用现有作者诊断；对未知字段原样保存。类型、条件、Entry 稳定 ID 与顺序不变。

Group 行和 Inspector 共用面板；先提交有效输入，加号成功后聚焦全选名称；名称 Enter/失焦提交、Escape 撤销输入；右键删除，应用使用现有 Entry 参数历史。预设文件结构及契约扩展保持简单，不自动生成或同步实例。
