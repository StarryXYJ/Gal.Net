# 移动布局适配：实现总结

日期：2026-11-02。实现与自动化验证完成，原生移动设备观感和系统安全区未验收。

## 最终行为

- 仅 Android/iOS 默认使用移动布局；桌面仍保留原外层固定画布，缩小桌面窗口不会切换成手机布局。Sample 借用原 GameShell 挂入移动实际视口，可见性跟随启动状态，解绑恢复局部资源并清理订阅，不复制 VM/presenter。
- 游戏内部场景、对白、NVL、选项使用 1920×1080 设计空间；历史是全页阅读覆盖层。对白仅补足底栏必要净空，场景坐标、横向构图和字体配置不变，隐藏工具栏的回放不预留底栏空隙。
- 底栏居中，内容足够时完整显示，不够时保留快进、自动、历史与更多，极窄情况历史亦可收纳。仅按钮实际需要时伸入黑边，宽度不超过安全视口。
- 48×48 约束透明命中区；可见标签居中使用自然尺寸，工具文字折算为 12–18 逻辑单位，菜单 14–18。紧贴文字的底色/选中反馈保持可读，整条工具栏背景透明，不出现大底板。
- 设置与绑定行按宽度重排原有控件，不重建编辑器或清除输入；分类标签换行。存档自适应 1–4 列，Gallery 填满可用列宽并保留卡片比例。页面边距、页头、滚动内容和返回/确认按钮适配移动视口。
- 更多菜单直接绑定原命令，系统返回先关闭，切页/卸载清理；打开按钮 Flyout 时阻断设备剧情动作，不临时改写共享交互阻塞标志。触摸 UI/滑块清理待判定单击，避免延迟推进。
- 场景 PNG 保持 1920×1080，存档预览 480×270；移动含 UI 截图使用当前安全内容视口逻辑尺寸，包含黑边和工具栏，预览继续限制 720×405。沿用平台安全区，不重复扣边。

## 用户反馈与改正

用户明确否定了首版大按钮。首版把设计字号直接用于视口工具栏，并给整个命中条绘制底色，视觉明显偏大。最终拆开透明命中容器与自然尺寸标签；补充可见内容高度、透明背景和桌面像素回归。没有修改用户现有 PlayerTypography 数值；该文件原有工作区修改不属于本轮提交。
