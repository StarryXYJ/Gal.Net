# 实施阶段

## P1 固定游戏画布与独立工具栏（verified）

前置：用户已允许共享工作区并行实施，提交时分开。沿用现有 presenter、输入和导航命令；游戏内部保留设计空间，移动工具栏使用实际视口空间。默认居中，优先不超出场景宽度；必要时为触摸目标加宽至安全视口上限，再收纳低频命令。默认桌面路径保持原布局。

退出：普通/超宽横屏布局测量、场景/对白位置、点击互斥、自动/快进状态、更多菜单返回与回放隔离验证；确认包含 UI 与仅场景截图的分辨率/裁切策略，没有隐式改变导出语义。

证据：MobileLayoutTests 覆盖普通/超宽/320–360 窄视口、完整/收纳工具栏、必要时跨黑边、菜单返回/切页、回放独立状态、挂载清理、场景/含 UI 截图尺寸及触摸互斥。用户否定首版大按钮后，新增实际视觉高度与透明背景断言；进一步去除文字底色、将工具栏高度收紧至 32、贴底并验证横屏对白净空 3–5，修正后 21 项布局/播放交互验证通过；桌面 PNG 和工具栏几何与原基线完全一致。

## P2 普通页面自适应（verified）

依赖 P1 的移动视口承载。标题维持原主次关系，设置不足宽度时标签与编辑器纵排，存档/Gallery 按卡片可用宽度减列，控制外边距和嵌套滚动。保留同一页面/控件状态，不通过重新创建 VM 或编辑器切换布局。

退出：手机普通横屏与较窄视口无水平溢出；返回和弹窗可见；旋转/切换布局不丢设置值或绑定草稿；桌面间距、列数和布局保持。

证据：真实挂载标题/设置/存档/Gallery/确认按钮、设置编辑器身份与值、录入中的输入绑定跨宽度变化保持；分类和设备标签换行；卡片列宽/比例测试通过。所有平台尺寸变化测试为 Headless 视口/容器测试，不等同 Android Activity 真机旋转。

## P3 回归与收尾（verified）

相关布局/输入/设置/截图回归、桌面前后视觉对照与可执行的移动验证；同步 spec/manual、summary 及稳定上下文。明确区分 Headless、原生桌面、Android 真机的证据。不将静态布局测试等同真机触摸验收。

规范、手册、总结与 lesson 已同步。最终测试及已知验收限制见 summary/execution；未进行原生 Android/iOS 安装和完整竖屏阅读验收。

## P4 跨平台统一自适应（verified）

用户要求桌面也使用自适应，替代 P1–P3 的桌面专用固定外层画布要求。所有平台挂载实际视口 shell，按宽 <1000 或高 <600 切换紧凑间距，工具栏按内容宽度收纳，存档/Gallery 按宽度排布。固定游戏画布与平台字号默认保留。

退出：默认桌面无需移动标记即可重排，连续窄→宽保持同一 shell、页面、编辑器和设置值；标题列定义及资源覆盖恢复，恢复完整工具栏关闭更多菜单；场景截图仍 1920×1080，含 UI 截图为实际视口。

证据：143 项相关 Integration 全部通过，含默认桌面实际视口、360→1280→800→1280 标题/资源恢复、工具栏展开关闭更多、固定场景截图、设置编辑器及输入录入保留。文档校验 72 页、316 仓库引用通过。见 output/responsive-layout/regression/。

## P5 UI/UX 全面复查与密度修正（verified）

用户继续指出 hover 缺失、对白间距、弹窗按钮和桌面密度问题，要求参考成熟项目全面检查。参照 Ren’Py 快捷菜单状态区分和 Windows 有效逻辑像素原则；外部 UI 增加有上下限的字号折算，保留固定画布字号。收紧工具栏和表单间距、统一按钮模板与主次操作，合并尺寸资源来源。设计发现与屏幕范围见 [审查记录](ui-audit.md)。

退出：实际宿主五种视口、三种配色及全部玩家页面渲染，hover/pressed/focus、连续缩放、编辑状态/回放和截图语义验证通过；明确区分 Headless 与原生设备验收。

证据：整体相关回归 173 passed；最后固定画布字号/三配色补充 13 passed；标题背景比例修正后 46 项视觉/页面专项 passed，均零失败。Docs 72 页/316 引用与 diff check 通过。全部为 Headless 渲染及交互，不代替原生设备验收。
