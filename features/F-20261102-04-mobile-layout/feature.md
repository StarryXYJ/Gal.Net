# 保持构图的移动端布局适配

日期：2026-11-02。状态：实现与自动化验证完成；真机观感/系统安全区验收待补。

用户在字号功能后明确要求继续实现移动适配，并表示字号问题已基本解决。本项沿用确认方向：游戏内容、对白、选项等保持固定画布；底栏居中，必要时可使用黑边，宽屏时尽量贴合场景宽度；外部页面按实际可用空间自适应。桌面保留现有构图、字号层级及完整工具栏。

范围：移动端游戏底栏布局与触摸命中、标题/设置/存档/Gallery 等普通页面的间距和网格适配、滚动/弹窗边界及安全区域，相关桌面回归。保留用户当前调整的 PlayerTypography 数值，不重新调字体档位。

非目标：剧情画布坐标和图像裁切、存档格式、播放或设置状态机、Editor 布局、完整竖屏游戏构图设计、演出库功能。窄宽度可以收纳低频工具操作，不能移除命令或只提供隐藏手势。

验收：桌面默认布局不进入移动模式；普通/超宽手机横屏保持场景及对白的构图；底栏最终点击范围不随场景缩小，居中且不超出安全宽度，点击工具或滚动不能误推进；设置布局变化保留当前值和编辑状态；存档/Gallery 按可用宽度减列；弹窗和返回可操作。自动化与真机验收分别记录。

用户反馈修正：首版工具字号直接使用设计值、整条底色填满命中区域，被明确指出按钮过大。最终区分透明命中区与自然尺寸视觉标签，限制工具视觉字号，并移除整条底板。结果见 [summary.md](summary.md)。

工作区协调：实施入口发现 F-20261102-03 正在改动相同播放器根布局、呈现状态和资源。用户明确允许在同一工作区并行实施，提交时分开。本项保留另一任务全部改动，不修改其新增演出语义；根布局借用现有 shell，在独立的 PlayerView code-behind 接入，避免覆盖另一任务的 XAML/PlayerSurface 修改。

历史参考：[延期的旧移动方向](../F-20261030-03-mobile-player-ui/design.md)、[已完成的字号功能](../F-20261102-01-player-typography/summary.md)。本轮用户的新指令授权本项实现，旧三主题方案及整套 UI 放大方案不恢复。
