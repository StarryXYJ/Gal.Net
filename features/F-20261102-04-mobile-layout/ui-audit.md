# UI/UX 全面复查与密度修正

日期：2026-11-02。范围为玩家 UI；不包含 Editor、调试工具及项目自行创作的演出美术。

## 参考与原则

- [Ren’Py GUI 定制](https://www.renpy.org/doc/html/gui.html)：快捷菜单、导航和普通按钮分开设计，文字的 idle/hover/selected 有独立反馈。借鉴文本菜单的轻量反馈，保留本项目无文字底色的要求，没有复制其美术。
- [Windows 响应式断点](https://learn.microsoft.com/en-us/windows/apps/design/layout/screen-sizes-and-breakpoints-for-responsive-design)：根据应用窗口的有效逻辑像素调整布局；物理屏幕分辨率本身不能决定 UI 密度。Avalonia 已处理 DPI，不能重复乘缩放。

## 发现与修正

| 区域 | 发现 | 当前处理 |
| --- | --- | --- |
| 桌面标题与菜单 | 脱离固定画布后仍直接使用设计字号，菜单宽约 400 | 外部字号 0.75–1 受限折算，宽屏标题菜单列 320、有效按钮宽约 304，边距收紧；装饰背景按原设计比例缩放 |
| 工具栏 | hover 与默认前景相同；原 70 设计单位底边距导致桌面留白；竖屏工具栏远离场景 | hover 主题色与下划线，pressed 独立颜色；工具栏锚定场景底部，对白净空约 2，背景仍透明 |
| 确认弹窗 | 强制 48 高，字体与按钮比例失衡，主题模板状态层不统一 | 统一项目按钮模板，36 高、主次操作、固定边线与焦点反馈；弹窗标题/正文至少 16/13，跳过确认同样统一 |
| 普通页面 | 窄桌面被当作全部 48 高的触摸布局，间距资源存在重复覆盖 | 紧凑页 40 高；尺寸资源集中到 Dimensions，页面边距/内边距/页头间距收紧 |
| 设置与绑定 | 长英文标签截断，分类字号大于正文过多，表单行偏松 | 标签换行、宽排标签列 220，分类跟随操作字号，行底间距 16；无校验错误时不保留空错误行，保留原编辑器与录入状态 |
| 截图弹窗 | 页面缩放与独立弹窗脱节 | 使用所属 TopLevel 逻辑尺寸折算，保留自身预览/窗口限制 |
| 游戏固定画布 | 外部 UI 缩放可能再次影响选项字号 | Dialogue/Speaker/SceneBody 不参与外部缩放，选项显式使用 SceneBody |

## 检查覆盖

标题、语言选择、游戏对白/NVL/选项/历史、工具栏与更多、设置/分类/输入录入、存档、鉴赏入口及图片/音频/视频/场景页面、关于、加载、截图、退出/返回标题/跳过确认均纳入现有回归与渲染截图检查。三种配色渲染复查；实际宿主另覆盖 360×800、800×360、1280×720、1920×1080、2560×1440 及默认小/较大档。连续缩放、真实鼠标 hover/点击、焦点、返回、弹窗互斥和输入草稿保留继续验证。

证据位于 output/ui-audit/：before/ 为修改前样本，after/ 为修正截图，complete/ 为最终相关集成回归，scene-fonts/ 为最后的固定画布字号补充检查。截图夹具包含空场景和示例媒体，不代表完整 GameTestCase 真机流程。最终计数见 execution.md。

仍需原生设备验收真实安全区、屏幕物理尺寸/观看距离与手指触感；未运行全解决方案 CI，未生成新 APK。此次处理建立统一比例与状态反馈，不能替代最终游戏美术和实际设备验收。
