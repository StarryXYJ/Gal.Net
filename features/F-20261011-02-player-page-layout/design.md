# 设计

## 2026-10-11 用户修订

原先七页共享 View 的方案只提供资源变化，现改为三套布局各自拥有全部普通页面 XAML View（仅 InitializeComponent 构造），业务/媒体生命周期全部留在共享 ViewModel。页面 XAML 有意作为可复制修改的参考，不复制 code-behind 业务。Classic 顶部页头、Minimal 侧栏与底部返回、Paper 居中标题与左侧返回；同一主题内各页返回位置一致。页面与媒体容器取消描边；内容卡和按钮仍有自己的状态视觉。对白 Classic/Paper 正文22、名字26，Minimal正文20、名字24，中性回退正文18、名字22。以下保留上一轮设计记录。

保持普通 View + 共享 ViewModel，使用玩家根 Styles 内的 page-frame、back、settings-card、media-stage 视觉类，不引入新的公共控件或页面基类。

七个页面共用铺满可用高度且限制最大宽度的面板：同一主题外边距/内边距、页头、分隔线和可滚动/受限内容区。返回固定右上角，点击区域至少 120×48；长标题截断，不压缩返回按钮。设置项在页头下的内容卡中滚动，Gallery 列表继续按媒体种类呈现。图片使用 Uniform 保持比例，位于页头下的独立边框中；视频原生控件也被安排在独立内容区。

共享语义配色和主题圆角/字体继续生效。新增 PageMaxWidth、BackMinWidth、BackMinHeight 资源供外层覆盖。图片不会扩展页面到标题栏以外，不增加自动放大或全屏入口。
